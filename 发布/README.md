# EdRV32 决赛正式版（m2-final-release）

| 项 | 内容 |
|---|---|
| 版本 | `m2-final-release`，2026-11-21 |
| 硬件 | 本仓库 `rtl/`、`fpga/`，与决赛演示用的比特流（顶层 `edrv32_fpga_board_full_top`）为同一份 RTL |
| 器件与工具 | PG2L200H-6 FBB676，PDS 2022.2-SP6.1 |
| 开发分支 | 完整开发历史（验证、设计记录、测量报告、上板任务卡）在分支 `zc100116/b3`，对应标签 `m2-final-dev` |

## 文件

| 文件 | 内容 |
|---|---|
| `showcase.elf` | 演示程序，决赛现场使用的版本，启动后 HELLO 显示构建提交 `dc24b2533`。经调试工具网口加载 |
| `ip_rom_boot.dat`、`ip_ram_sram.dat` | Boot ROM（BIOS）和 SRAM 初始程序的 IP 初始化文件，生成 PDS 存储类 IP 时选用 |
| `演示App.apk` | Android 演示 App 1.7（versionCode 8）。平板显示端：动态街景、工地、智慧农场等场景；手机遥控端：场景切换、前处理档位、板上界面控件镜像、NES 手柄 |

比特流由 PDS 生成，不入库；按根目录 README 的“FPGA”一节生成。

## 主要功能

- 现场演示应用：首页最上方进入，6 章 11 个场景按顺序串联，手机一键切换，平板自动跟随。
- 识别前处理：快捷档（原始、暗光增强、降噪、增强 + 降噪）和高级调节（自动色阶、自动 gamma、亮度、对比度、滤波、传感器曝光目标）。
- 落地应用：工地安全帽检测（跟踪投票防闪烁）；智慧农场（稳定计数、走失 3 s 报警、人员闯入 0.5 s 报警）。
- 体感交互：手势抓取物理积木、弹弓打靶。
- CPU：现场 CoreMark 跑分；NES 模拟器内置 30 款游戏。
