# 卡 91：同步显示、分部位贴纸、游戏 R2 上板（卡 75 比特流）

## 1. 目标

按卡 90 的反馈改完后，再在板上看效果。重点有四项：
1. **贴纸是否贴得住**：改为同步显示，画面和贴纸一起上屏，不再落后；
2. **分部位贴纸**：头饰、眼睛、鼻子、嘴巴、脸颊、套装；
3. **游戏改进**：首页卡片入口、中央安全区、调速、切图形判定放宽；
4. **补测卡 90 没测到的项目**：弹弓打靶、石头剪刀布、接物篮、安全帽 v2。

**每一项都请给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版改动（相对卡 90）

| 项 | 改动 |
|---|---|
| 同步显示 | 人脸贴纸页和体感页（抓取测试、体感游戏）只显示识别过的那一帧画面，和它的贴纸、光标同一帧上屏。代价：画面整体比真人晚约 80 ms，画面帧率等于识别帧率（约 25–28 fps） |
| 贴纸防跳动 | 滤波调得更跟手：600 px/s 移动时滞后 0.8 帧（原来 2.8 帧），静止抖动约 1.3 px |
| 分部位贴纸 | 第二行按钮"头饰""眼睛""鼻子""嘴巴""脸颊"各自循环切换，每个部位都有"无"；顶栏"套装"在猫咪、派对、酷、兔子之间切换。新增：爱心眼镜、星星眼、卡通大眼、猫鼻、小丑鼻、小狗鼻、八字胡、红唇、吐舌头、腮红、猫胡须 |
| 游戏入口 | 首页第 15 张应用卡片"体感游戏"，顶栏按钮已去掉 |
| 安全区 | 需要手去够的东西都放在画面中央：x 200–1080，y 120–600。弹弓叉口移到 x=400 |
| 调速 | 打地鼠、切图形、接物篮开局前选"慢 / 中 / 快"，可以点，也可以握拳停留选。默认慢：出怪间隔和停留时间是原来的 2 倍，飞行和下落速度减半 |
| 切图形 | 划动速度门限 800 → 350 px/s；命中半径 36 → 60 px；丢手 2 帧以内轨迹不断；按宝石在两帧之间的移动判定 |
| 串口 | 游戏输出 `game name=... event=start/end speed=... score=... dur_ms=...`，每秒输出 `draw_fps`、`cursor=x,y`、`lost`；切图形另有 segments、fast_segments、hits、near_misses |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261116-91-sync-games-board origin/zc100116/b3`，记录 HEAD。 |
| 1 | 用户（U） | 下载卡 75 比特流，复位进入 BIOS，经网口加载 `src/showcase-sync-hw.elf`，记录 HELLO。 |
| 2 | U + C | **人脸贴纸**，站在约 0.75 m 处：<br>a. 选"猫咪"套装，左右来回移动头部 10 s：贴纸是否贴在脸上、是否还落后（1–5 分），录慢动作视频；<br>b. 静止 5 s：贴纸是否跳动（1–5 分）；<br>c. 歪头约 20°：贴纸是否跟着歪；<br>d. 各部位按钮逐个切一遍，每个部位拍一张，说哪些好看、哪些位置或大小不对；<br>e. 两个人同时入镜：是否各贴各的；<br>f. 画面整体变晚了约 80 ms，能不能接受。 |
| 3 | U + C | **体感游戏**：从首页"体感游戏"卡片进入大厅，5 个游戏各玩 1 局。打地鼠、切图形、接物篮先用"慢"，再试一次"中"。每个游戏记录：<br>- 分数，手感 1–5 分，一句主要问题；<br>- 光标是否和画面里的手对齐；<br>- 弹弓：命中几发（满分 5）；<br>- 石头剪刀布：认对几局，"没看清"出现几次；<br>- 打地鼠：慢档速度是否合适；<br>- 切图形：慢档划过时大约几成能切开；<br>- 接物篮：跟手是否顺畅。<br>另外专门试一下：手移到画面四周，光标是否还失灵，大概在离边多远开始失灵。 |
| 4 | U + C | **安全帽 v2**：首页进"安全帽检测"。不戴安全帽站在画面中，"未戴"人数是否正确；有安全帽就戴上再看一次；两个人也看一次。拍照。 |
| 5 | U | 全程留意：有没有死机、复位、画面卡住或画面停住不动。 |
| 6 | C | 整理串口、照片、视频截图，填写 result.md，推送分支。 |

**第 6 步的串口统计**：
- 人脸页和体感页的 vision 行：`fps`、`shown`（同步页应接近 fps）、`e2e`，各给最小、中位数、最大值；
- 每个游戏的 `event=end` 行：分数、时长、速度档；`draw_fps` 中位数；
- 切图形：segments、fast_segments、hits、near_misses 的合计；
- 失灵时的 `cursor` 坐标和 `lost` 值：手放在画面四周时的那几秒，列出来。
