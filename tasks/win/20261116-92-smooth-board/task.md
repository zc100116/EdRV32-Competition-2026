# 卡 92：交互页面流畅度修复上板（卡 75 比特流）

## 1. 目标

卡 91 的问题按计划修改后，上板看两件事：
- 交互页面是否还"一卡一卡"；
- 快速移手的"断触"是否减轻。

同时补测卡 91 没测到的项目：石头剪刀布、接物篮、安全帽 v2。

**每一项都请给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版改动（相对卡 91）

| 项 | 改动 |
|---|---|
| 画面缓冲 | 人脸贴纸页和体感页的摄像头画面缓冲从 4 块增加到 6 块。卡 91 中，这两页的帧率从 25 fps 掉到 19–20 fps，推断原因就是缓冲不够 |
| 一个结果只上屏一次 | 这两页上，界面只在拿到新的识别结果时才重画，然后与对应的画面一起上屏。卡 91 中，抓取测试的方块动画按 30 Hz 走，识别结果约 20 fps，两者不同步，方块会一顿一顿 |
| 短暂丢手 | 手丢失不超过 200 ms 时，保持抓住状态，光标按原来的速度继续走。超过 200 ms 才算丢手 |
| 曝光 | 抓取测试顶栏新增"曝光 标准 / 短"按钮：<br>- 标准：最长曝光约 33 ms，与原来相同；<br>- 短：最长约 10 ms，增益提高，并固定 50 Hz 防闪烁。<br>目的：看快速移动时手的拖影是否减少、丢手是否减少。切到"短"后体感游戏也沿用，直到再切回来 |
| 脸颊贴纸 | 沿两眼方向向外移动 0.3 倍眼距 |
| 串口 | 视觉页面每秒多一行 `sched`，内容如下：<br>- 各任务占用；<br>- 各中断的次数和时间；<br>- VIN 丢帧数 `skip`；<br>- 上屏间隔分布 `pace`：相邻两次换画面之间隔了几个显示帧，分 1、2、3、4、≥5；<br>- 结果到上屏的分段时间：`gui_wait`、`render`、`rnd`、`sw`、`vsync` |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261116-92-smooth-board origin/zc100116/b3`，记录 HEAD |
| 1 | 用户（U） | 下载卡 75 比特流，复位进入 BIOS，经网口加载 `src/showcase-smooth-hw.elf`，记录 HELLO |
| 2 | U + C | **抓取测试，曝光"标准"**，站在约 0.75 m 处：<br>a. 抓起一个方块，左右慢慢拖动 10 s：方块是否还一卡一卡（1–5 分，和卡 91 比），录视频；<br>b. 快速来回挥手 20 s：光标和方块是否断触（1–5 分）；<br>c. **请 Codex 记下 b 的开始和结束时间**，用于对照串口 |
| 3 | U + C | **抓取测试，曝光"短"**：点"曝光"按钮切到"短"，串口应出现 `camera exposure=short`。然后：<br>a. 重复第 2 步 b，快速挥手 20 s，记下起止时间；<br>b. 画面是否变暗、噪点是否变多、有没有横向闪烁条纹；<br>c. 和"标准"相比，哪个断触少（1–5 分）。<br>**保持"短"进入第 4 步** |
| 4 | U + C | **体感游戏**：从首页"体感游戏"卡片进入：<br>- **石头剪刀布、接物篮**（卡 91 未测）：各玩 1 局，记录分数、手感 1–5 分、一句主要问题；<br>- 石头剪刀布：认对几局，"没看清"出现几次；<br>- 接物篮：用"慢"档，篮子跟手是否顺畅；<br>- **切图形**（慢）再玩 1 局，看画面是否比卡 91 顺 |
| 5 | U + C | **人脸贴纸**：<br>a. 选"猫咪"套装，左右移动头部 10 s：贴纸是否贴住、画面是否顺（1–5 分），录视频；<br>b. 切到有"脸颊"的套装（派对：腮红），看脸颊贴纸的位置是否合适，拍照 |
| 6 | U + C | **安全帽 v2**（卡 91 未测）：首页进"安全帽检测"：<br>- 不戴安全帽站在画面中，"未戴"人数是否正确；<br>- 有安全帽就戴上再看一次；<br>- 两个人也看一次。<br>拍照 |
| 7 | U | 全程留意：有没有死机、复位、画面卡住或画面停住不动 |
| 8 | C | 整理串口、照片和视频截图，填写 result.md，推送分支 |

**第 8 步的串口统计**，按页面分段：抓取标准、抓取短曝光、各游戏、人脸、安全帽。

1. **vision 行**：`fps`、`shown`、`e2e`、`gui`，各给最小、中位数、最大值。
2. **sched 行**：
   - `pace` 各档的合计次数和占比；
   - `skip` 合计；
   - `gui_wait`、`render`、`rnd`、`sw`、`vsync` 的中位数；
   - `comm`、`app`、`gui` 的占用中位数，以及 `*_max` 的最大值；
   - 各中断次数和时间的中位数。
3. **挥手对比**：第 2 步和第 3 步的挥手时段内，统计以下几项，标准与短曝光各列一列：
   - `hands=0` 的行数；
   - `lost` 的最大值；
   - 游戏行 `lost` 的合计。
4. **游戏**：每局 `event=end` 行的分数、时长、速度档；`draw_fps` 的中位数。
