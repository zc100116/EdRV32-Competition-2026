# 卡 98：平板农场演示、空中画板跳点修复（卡 75 比特流）

## 1. 目标

- 用平板农场网页试演智慧农场；
- 复测空中画板：笔迹不再下坠，跟手更快。

**主观项每项给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版内容（相对卡 97）

| 项 | 内容 |
|---|---|
| 平板农场网页 | `tools/demo/farm-sim/farm-sim.html`：单个离线文件，约 3 MB，平板浏览器全屏打开。<br>- 场景：三个栅栏，牛栏（2 牛 1 马）、羊圈（3 羊）、禽舍（2 鸡 1 鸭），写实动物在栏内走动。<br>- 拖动：手指拖到别的栏 = 串栏，拖出农场 = 走失。<br>- 按钮：右下角"演示"自动演一遍（羊离场 → 回圈 → 串进牛栏 → 回圈），"复位"让所有动物回到原位。<br>- 主机上已模拟拍屏，用板上同一个模型验证：26 只动物全部识别为正确类别，最低置信度 0.449。<br>- 使用说明见同目录的 `README.md` |
| 板端农场 | 看板抽屉中新增"栏位对齐"：左右两条分界线可调，默认 33% / 67%，用来对准平板上的栅栏 |
| 空中画板 | - **下坠**：手指划过脸前时，指尖会被误认到指节上。现在按食指长度一致性判断，不可信的帧用指节方向推算指尖，超过 300 ms 才停笔；另外用 3 帧中值剔除孤立跳点。<br>- **跟手**：笔迹落后于手指的时间，从 167–358 ms 降到约 127–140 ms |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261117-98-farm-draw-board origin/zc100116/b3`，记录 HEAD |
| 1 | 用户（U） | 下载卡 75 比特流，经网口加载 `src/showcase-r5c-hw.elf`，记录 HELLO |
| 2 | U + C | **智慧农场**，按 `tools/demo/farm-sim/README.md` 操作：<br>a. 平板放在摄像头前约 30–50 cm，占画面宽度约 65%；<br>b. 板上：智慧农场 → 看板 → 栏位对齐，把两条分界线调到平板的两条通道上；<br>c. 确认计数为牛 2、马 1、羊 3、鸟 3，按"盘点"；<br>d. 在平板上点"演示"，看走失告警和串栏告警是否出现、能否解除；<br>e. 再用手指拖一只到别的栏、拖一只出农场；<br>f. 评分：识别准不准（有没有漏检、错类）、告警及时、对齐是否方便、整体演示效果；录视频 |
| 3 | U + C | **空中画板**：<br>a. 手指在脸前横着画 5 条直线，看是否还会下坠；<br>b. 写 3 个字；<br>c. 评分：跟手、平滑、是否下坠或断线；录视频 |
| 4 | C | 整理串口、照片，填写 result.md，推送分支 |

**第 4 步的串口统计**：
1. `farm counts=`、`farm event=` 行原文，按时间列出。
2. `draw draw_fps=` 行：`draw_fps`、`strokes`。
3. 智慧农场、空中画板各段的 vision 行：`fps`、`e2e` 的中位数。
