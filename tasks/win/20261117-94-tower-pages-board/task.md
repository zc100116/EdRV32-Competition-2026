# 卡 94：积木塔、全部页面新部件、退出卡死修复、节奏对比（卡 75 比特流）

## 1. 目标

上板看以下内容的效果和稳定性：
- 积木塔；
- 全部页面换成新部件后的样子；
- 卡 93 的"正在停止"卡死是否修好；
- 上屏等待时间是否缩短；
- 两种画面节奏对比；
- 两种曝光对比；
- 贴纸位置。

**主观项每项给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版内容（相对卡 93）

| 项 | 内容 |
|---|---|
| 积木塔 | 首页"体感积木"大卡片和"体感互动 → 积木塔"进入：<br>- 左右积木架，6 种材质 × 6 种形状；<br>- 握拳抓起；抓着时比剪刀手转 90°（换回握拳才能再转）；张手放下；<br>- 积木会碰撞、堆叠、倒塌；玻璃从较高处落下会碎。<br>模式：教学、挑战一"盖高楼"（90 s 内达到目标线并稳定 3 s）、挑战二"地震测试"（搭 60 s，平台晃 5 s）、自由搭建。<br>进入时由 GEO 硬件生成积木各角度的画面，显示进度条 |
| 页面新部件 | 以下页面都改用 LVGL 专用部件和自动布局，计数和结果用大号粗体或徽章：<br>- 实时识别、图片识别、图像处理、图形引擎、经典游戏；<br>- 系统监控、芯片信息、调试助手；<br>- 姿态、手势、人脸贴纸、简笔画、安全帽。<br>设置页新增"调试叠加"开关，以及"抓取测试"入口 |
| 退出卡死修复 | 卡 93 中退出抓取后一直"正在停止"。根因是停止流程在新画面地址还没生效时就关了画面层，见 `docs/debug/2026-11-16-showcase-sync-stop-hang.md` |
| 上屏等待 | 离下一次换帧还有 1.7 ms 以上时，立即写入新画面地址。预计 `vsync` 从 20–25 ms 降到约 10 ms |
| 节奏开关 | 设置 → 抓取判定 → "抓取测试"页顶栏："节奏 自适应 / 均匀"，作用于人脸贴纸和所有体感页：<br>- 自适应：每个结果尽快上屏（约 25 fps，间隔 2、3 帧交替）；<br>- 均匀：固定约 20 fps，每帧停留时间相同 |
| 贴纸 | 爱心发箍放大 1.3 倍；八字胡移到鼻尖和上唇之间 |

## 5. 操作步骤

**每个步骤开始和结束时，请 Windows Codex 记下时间**，方便与串口对照。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261117-94-tower-pages-board origin/zc100116/b3`，记录 HEAD |
| 1 | 用户（U） | 下载卡 75 比特流，复位进入 BIOS，经网口加载 `src/showcase-tower-hw.elf`，记录 HELLO |
| 2 | U + C | **积木塔**，站在约 0.75 m 处：<br>a. 进入积木塔，记录进度条走完用了多久（串口 `tower atlas ... total_ms=`）；<br>b. 教学：照提示抓起、移动、放下、旋转，是否顺利；<br>c. 自由搭建：搭 5 块以上，试一下玻璃从高处落下会不会碎、搭歪了会不会倒；<br>d. 挑战一玩 1 局，挑战二玩 1 局；<br>e. 评分：好不好玩、积木跟手、旋转、倒塌是否自然（各 1–5 分），说一句主要问题；录视频 |
| 3 | U + C | **退出卡死复测**：反复做 10 次"进入积木塔 → 返回首页 → 进入另一个应用"，混用按键和画面上的返回按钮。记录是否再出现"正在停止"不消失 |
| 4 | U + C | **节奏和曝光**：<br>a. 设置 → 抓取判定 → 抓取测试；<br>b. 节奏"自适应"下拖动方块 15 s，再切到"均匀"拖动 15 s。哪个看起来更顺？<br>c. 曝光开关在设置页（设置 → 抓取判定 → 曝光）。先在"标准"下进入抓取测试，快速挥手 20 s；回设置页切到"短"，再进入抓取测试挥手 20 s。哪个断触更少？画面是否变暗、变噪、出现闪烁条纹？ |
| 5 | U + C | **人脸贴纸**：<br>- 派对套装：看爱心发箍大小；<br>- "酷"套装：看八字胡位置；<br>- 拍照 |
| 6 | U | **各页面**：首页逐个进入每个应用，看排版、对齐、字号、按钮。说哪里好看、哪里要改，问题页面拍照 |
| 7 | U | 全程留意：死机、复位、画面卡住或停住 |
| 8 | C | 整理串口、照片，填写 result.md，推送分支 |

**第 8 步的串口统计**：
1. `tower atlas` 行的全部字段。
2. 积木塔段的 `game name=tower` 行：
   - `event=end` 的模式、高度、块数、星级、时长；
   - 每秒行中 `draw_fps`、`phys_ms`、`late`、`awake` 的中位数和最大值。
3. 积木塔、抓取（自适应、均匀）、人脸各段的 vision 行和 sched 行：
   - `fps`、`shown`、`e2e`、`gui` 的中位数；
   - `vsync`、`render`、`gui_wait` 的中位数；
   - `pace` 各档的占比。
4. 曝光对比：标准段和短曝光段的 `hands=0` 行数，以及 `lost` 的最大值。
