# 卡 90：体感游戏合集、新人脸贴纸和安全帽 v2 上板（卡 75 比特流）

## 1. 目标

在卡 75 的比特流上看实际效果：
- 体感游戏：大厅加 5 个游戏；
- 新人脸贴纸：图片贴纸加防跳动；
- 安全帽 v2：补了普通场景里不戴安全帽的人头。

本卡以用户的主观评价和照片为主，串口数字为辅。**每一项都要给 1–5 分（5 分最好）和一句主要问题。**

## 2. 本版内容

| 项 | 说明 |
|---|---|
| 入口 | 首页顶栏"体感游戏"进入大厅，5 张卡片。进入方式：手停在卡片上握拳保持 1 s；也可以点卡片，或用板上按键。游戏内"返回"回大厅 |
| 共用操作 | 光标跟手。握拳或抓紧算"抓"，张开或四指算"放"，其他手势保持当前状态。画面镜像。右上角性能窗：识别 fps、延迟、CPU 空闲、游戏绘制 fps |
| 弹弓打靶 | 握拳抓住弹弓上的弹丸，往后拉瞄准（有预测虚线），张开手发射。每局 5 发，3 个木箱（100 分）、3 个气球（50 分） |
| 石头剪刀布 | 倒数 3、2、1、出！在"出"之后 0.6 s 内出拳：握拳 = 石头，剪刀手 = 剪刀，张开 = 布。5 局，先赢 3 局结束 |
| 打地鼠 | 6 个洞在画面中部。怪物冒出时，把手移过去握拳，算打中。金色 +30，炸弹 −20。每局 45 s |
| 切图形 | 手快速划过飞起的宝石就切开；切到炸弹或漏掉 3 个结束。每局最长 60 s |
| 接物篮 | 手左右移动控制篮子，接水果 +10，接到炸弹 −30。每局 60 s |
| 人脸贴纸 | 6 套原创贴纸：兔耳、猫耳、皇冠、爱心发箍、派对帽、墨镜。"换贴纸"按钮切换。画面镜像，随头部倾斜换角度（±12°、±24°）；"调试"按钮显示检测框和关键点 |
| 安全帽 | 模型换成 v2。离线结果：普通人物照中，未戴人头的检出数由 20 增至 40，误判为戴安全帽的由 31 降至 10 |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261116-90-games-board origin/zc100116/b3`，记录 HEAD。 |
| 1 | 用户（U） | 下载卡 75 比特流，复位进入 BIOS，经网口加载 `src/showcase-games-hw.elf`，记录 HELLO。 |
| 2 | U | **先检查硬件后处理**：这是关键点模型第一次在卡 75 上跑硬件后处理。进入"手势识别"页，举手 10 s，看手框、关键点、手势名称是否正常。<br>- 正常：本卡后续都用这个 ELF；<br>- 没有框、框的位置明显错误，或关键点乱飞：拍照，然后换成 `src/showcase-games-cpu.elf` 做后续所有步骤，并在 result.md 中注明。 |
| 3 | U + C | **体感游戏**：站在约 0.75 m 处，从大厅用握拳 1 s 依次进入 5 个游戏，每个至少玩 1 局。对每个游戏记录：<br>- 本局分数；<br>- 手感评分 1–5 和一句主要问题；<br>- 拍一张游戏中的照片，要能看清右上角性能窗；<br>- 弹弓：5 发中命中几发；<br>- 石头剪刀布：每局你出的和屏幕认出的是否一致，"没看清"出现几次；<br>- 打地鼠：明明握拳打中、却没算的次数（估计即可）；<br>- 切图形：快速划过时能不能切开，大约几成能切开；<br>- 接物篮：篮子跟手是否顺畅。<br>另外记录：大厅握拳进入是否顺利，返回大厅是否正常。 |
| 4 | U + C | **人脸贴纸**：6 套各试一下。对整体记录：<br>- 静止 5 s 贴纸是否还跳（与以前相比，1–5 分）；<br>- 慢慢左右移动时是否跟得上、有没有拖尾；<br>- 头左右歪约 20° 时贴纸是否跟着歪；<br>- 有两个人时是否各贴各的；<br>- 每套拍一张照片；<br>- 哪几套好看，哪几套要改。 |
| 5 | U + C | **安全帽**：不戴安全帽站在画面中，记录"未戴"人数是否正确（卡 84 时始终为 0）。有安全帽就戴上再看一次。两个人时也看一次。拍照。 |
| 6 | U | 全程留意：有没有死机、复位、画面卡住。 |
| 7 | C | 整理串口和照片，填写 result.md，推送分支。 |

- 5 个游戏各自的分数、评分和主要问题；
- 贴纸各项观察；
- 安全帽"未戴"计数；
- 死机或复位情况。
