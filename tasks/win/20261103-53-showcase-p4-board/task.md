# 任务卡 20261103-53-showcase-p4-board：演示程序 P4 版上板（卡 52 反馈修订）

## 1. 目标

在最终版 F CPU125 比特流上验收 showcase P4 版。本版修订了卡 52 中用户提出的全部问题（设计记录 `docs/design/2026-11-03-showcase-ui.md` 第 4.6 节），并测量各项性能数字，供技术文档和演示视频使用。

## 2. 输入

- **代码**：`origin/zc100116/b3` 上包含本卡的提交，拉出 `win/20261103-53-showcase-p4-board`，记录 HEAD。
- **比特流**：用户最近完成的**最终版完整 F（CPU 125 MHz）**。在 result.md 中记录它的路径、生成时间和各时钟域的 WNS。
- **程序**：`src/showcase-p4.elf`（9670712 字节，构建自 b3 12ec599d）。
- **NPU 模型**：`tasks/win/20261029-09-b3-software/src/npu/`。
- **board_npu.elf**：卡 48 的 `src/board_npu.elf`。
- **调试工具**：本 checkout 的 `tools/debug_tool`（关闭旧进程，重新启动）。

## 3. 环境

同卡 52。本卡不运行 PnR。

## 4. 需要的 IP

无。

## 5. 操作步骤

**注意**：showcase 会覆盖 SRAM 中的 monitor。复位时按住 KEY1 进入 BIOS；需要 monitor 时重新下载比特流。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | 拉分支；从本 checkout 重启调试工具 |
| 1 | 用户（U） | 下载最终版 F 比特流，KEY1 复位进入 BIOS，记录启动信息 |
| 2 | U + C | board_npu.elf 跑 **3 次**，每次 39/39，D 组 CRC 一致（卡 51、52 的遗留项） |
| 3 | U + C | 网口烧录 `src/showcase-p4.elf`，保存全程串口日志到 `artifacts/uart/showcase.log` |
| 4 | U + C | 按第 6 节矩阵逐项执行；某项失败时保存原文和照片，继续下一项 |
| 5 | C | 整理 result.md，推送分支 |

## 6. 测试矩阵

| 编号 | 项目 | 操作 | 记录 |
|---|---|---|---|
| P0 | 启动与网口连接 | 程序启动后看串口 | 必须出现 `Showcase: EdRV32 showcase v2`、`ETH peer IP/port`；调试工具的虚拟输入通道显示"网口" |
| P1 | 光标与输入 | 在浅色页面移动鼠标；虚拟键盘、滚轮、中键、KEY1–4 | 光标为白底黑边箭头，任何背景下都清楚；**进入调试助手串口页后虚拟设备仍可用** |
| P2 | 返回层级 | 游戏中返回 → 回到游戏列表并停在原游戏；检测设置返回 → 视觉识别；每页左上角"‹ 返回"可用鼠标点击 | 是否符合 |
| P3 | 视觉识别 | 摄像头识别连续 **15 分钟** | 视频全屏、界面浮层；串口每秒的 `npu_ms`、`post_ms`、`display_fps`。**后处理目标 ≤ 35 ms**（卡 52 为 170 ms 以上）。画面是否流畅 |
| P3b | 检测设置 | 门槛 0.50 → 0.70；只选 2–3 类；全选 | 过滤是否生效 |
| P4 | 图片识别 | 上传模型 → 图 A → 图 B → 40 张批量 → 停止 → 单张 → 切回摄像头 ×3 | 串口每张的 `receive_ms`、`ch2_ms`、`npu_ms`、`post_ms`、`return_ms`、`upload_to_done_ms`（**目标 ≤ 300 ms**）；工具上的图和框是否对应本次发送 |
| P5 | 图像处理 | 15 个参数逐一调节，包括伽马、S1/S2 七种运算、二值化阈值、旋转、缩放、平移、镜像；"原图/处理后"切换；"恢复默认"；面板收起 | 每类拍一张照片；调节是否下一帧生效 |
| P6 | 图形引擎 | ① LVGL benchmark 跑完一轮应自动停止，右上角有性能监视器，中途按返回能立即停止；② 渲染器功能测试"全部运行" | ① 结果表照片（平均 fps 不能为 0）；② 22 项的硬件/软件耗时、加速比、一致率（照片和串口原文） |
| P7 | 游戏 | 超级马里奥、魂斗罗各玩 2 分钟，分别用**网口**和**串口**两种虚拟输入（工具里切换） | 串口输出的输入延迟 `max_ms` / `avg_ms`，两种通道分别记录（目标最大值 ≤ 16.7 ms）；手感是否灵敏 |
| P8 | 性能浮窗 | 在首页、视觉识别、NES、benchmark 中分别打开浮窗，换角 | 照片；串口的 `overlay_cpu`（目标 ≤ 2%）和 `max_us`；DDR 各端口带宽是否随应用变化 |
| P9 | CoreMark | 芯片信息页运行 **3 次** | 每次的 Iterations/Sec、CoreMark/MHz、两轮 16 个计数器、IPC、每千条指令缺失数（照片和串口原文） |
| P10 | 调试助手 | 串口页收发；网口页 ECHO 100 次 | 板端计数；工具上的往返时间和丢失数 |
| P11 | 调度统计 | 静止 30 s；视觉识别、NES、benchmark 运行时各 30 s | 串口每秒统计中，三个任务的 CPU 占用和最长单次耗时（通信 ≤ 1000 us，应用 ≤ 5000 us） |
