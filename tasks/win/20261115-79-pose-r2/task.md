# 卡 79：人体关键点检测单独上板（卡 68 R2 比特流，CPU 后处理）

## 1. 目标

在卡 68 R2 现成的比特流上运行 showcase 新增的"人体姿态"页，确认 YOLOv8n-pose 在板上能正确输出骨架，并测量帧率、延迟和静止抖动，同时观察举手指示是否可靠。这些数据用来设计决赛的体感游戏。

背景：
- 决赛演示方向：人体关键点识别手势，操控自研游戏（`docs/design/2026-11-14-finals-demo-pose-game.md`）。
- 离线评估（`docs/reports/2026-11-15-pose-int8-eval.md`）：INT8 关键点 mAP50-95 为 40.4%；上半身关键点偏差平均 7.5 px（1280×720）；NPU 估算 36.9 ms/帧（180 MHz）。
- 卡 68 R2 没有 NPU 硬件后处理，本卡用 CPU 后处理构建。帧率会低于最终版本，正式版本等卡 75 布通后再测。
- 程序同时内嵌检测模型和 pose 模型，进入"人体姿态"页时 NPU 切到 pose 模型，离开时切回。

**不需要 PDS 综合或布线**，可以和卡 75 的 PnR 同时进行，只要占用开发板。

## 5. 操作步骤

串口每秒输出一行：

```text
pose fps=… npu=… wait=… decode=… kpt=… gui=… e2e=… period=… persons=… idle=… npu_gap=… jit_lw=… jit_rw=… jit_ls=… jit_rs=…
```

`jit_*` 是画面中最大那个人的左腕、右腕、左肩、右肩在这 1 秒内的位置抖动，单位 px，按 1280×720 计。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261115-79-pose-r2 origin/zc100116/b3`，记录 HEAD。 |
| 1 | 用户（U） | 下载卡 68 R2 的比特流，按 KEY1 复位进入 BIOS，记录 `CLK_SYS_HZ`。 |
| 2 | U + C | 经 BIOS 网口加载 `src/showcase-pose-cpu.elf`，方法同卡 68。记录 `showcase first frame` 和 HELLO 中的版本，应为 `095b17d4`。 |
| 3 | U | 在启动器中进入"人体姿态"页，或由 PC 工具选择该应用。 |
| 4 | U + C | **单人骨架**：一人站在约 2 m 处，正对摄像头，上半身完整入镜。拍一张照片，检查 17 个点和连线是否贴合身体：鼻、眼、耳、肩、肘、腕、髋、膝、踝。 |
| 5 | U + C | **静止抖动**：同一人站着不动 30 s，保存这段时间的全部 `pose` 行。 |
| 6 | U + C | **举手指示**：同一人依次举左手、放下，举右手、放下，双手同时举起、放下，每种 5 次，动作约 1 s 一次。记录：<br>- 每次指示是否亮起；<br>- 是否亮错了手；<br>- 放下后是否熄灭；<br>- 是否有没动作却亮起的情况。<br>建议用手机拍一段 15–30 s 的视频，同时拍到人和屏幕，用来目测延迟。 |
| 7 | U + C | **距离**：分别站在约 1 m、2 m、3 m 处举一次右手，记录骨架是否完整、指示是否亮起。 |
| 8 | U + C | **两人**：两人并排站在约 2 m 处，拍照，确认两人的骨架都显示，并且没有连到对方身上。 |
| 9 | U + C | **连续运行**：一到两人在画面中自由走动、挥手，连续 3 分钟，保存全部 `pose` 行，要求不少于 170 行。 |
| 10 | U + C | **切换**：回到启动器，进入"实时识别"页运行约 10 s，确认检测框正常；再进入"人体姿态"页，确认骨架恢复，没有残留的旧骨架，没有卡死。 |
| 11 | C | 统计第 5、9 步 `pose` 行中各字段的最小值、中位数和最大值，填写 result.md，推送 `win/20261115-79-pose-r2`。 |

## 6. 产物

放在 `tasks/win/20261115-79-pose-r2/artifacts/`：
- `uart/boot.log`；`uart/pose-still.log`（第 5 步）；`uart/pose-3min.log`（第 9 步）；`uart/switch.log`（第 10 步）；
- `photos/`：单人骨架、两人骨架、1/2/3 m 举手（各一张）；
- `video/`：举手视频，可选，单个文件不超过约 20 MB。超过时在 result.md 中说明理由，或者只保留 Windows 本地路径。

## 7. 通过判据

- 骨架与人体贴合，两人时互不串连；
- 举手指示在 2 m 处每种动作 5 次中至少 4 次正确亮起，没有误亮；
- 连续 3 分钟无死机、复位、画面错乱；
- 切换页面后，检测与姿态都正常；
- 所有数字取自串口原文，找不到的写"未取得"。
