# 卡 100：画笔锁手、抓取甩出、农场卡顿、背包改回 OK（卡 75 比特流）

## 1. 目标

复测卡 99 的 3 条反馈，以及协调者从串口中发现的画笔换手问题。平板演示 APK 还在开发，完成后另出一张卡。本卡不需要平板。

**主观项每项给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版内容（相对卡 99）

| 项 | 内容 |
|---|---|
| 空中画板 | - **锁手**：卡 99 串口中，画面里有两只手时，画笔在两只手之间逐帧来回切换，画出 300–600 px 的连线。现在落笔期间锁定正在画的手，另一只手不再抢。<br>- 画板逐帧串口记录改为只在有变化时输出，加上每秒一行，不再冲满调试工具的缓冲区 |
| 抓取实验 | **甩出**：<br>- 抓着物体快速挥动后张手，物体沿挥动方向飞出并带旋转。速度取张手前 0.1 s 的平均速度，上限 1200 px/s；<br>- 慢速放下（低于 300 px/s）仍然轻放，不会飞 |
| 智慧农场 | **卡顿**：主机上查到，农场页每帧重复设置背景样式，看板隐藏时也在刷新，导致大面积重绘。修复后，静止时每帧重绘面积从约 7,200–12,600 px 降到约 460 px。串口每秒一行增加 `draw_fps=`、`ui_us=` |
| 方块工坊 | 背包开关改回 **OK** 手势，保持 0.8 s，有进度环 |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`；用 `git log -1 --format=%H origin/zc100116/b3 -- tasks/win/20261117-100-hand-throw-farm-board` 找到本卡的提交，从它拉出 `win/20261117-100-hand-throw-farm-board`，记录 HEAD |
| 1 | 用户（U） | 下载卡 75 比特流，经网口加载 `src/showcase-r5e-hw.elf`，记录 HELLO。**调试工具的串口记录在每一项开始前清空一次，每项结束后另存为一个文件**，避免缓冲区溢出 |
| 2 | U + C | **空中画板**：<br>a. 一只手画画，另一只手放在画面下方，画 5 条横线，看笔会不会跳到另一只手；<br>b. 写 3 个字；<br>c. 评分：锁手、跟手、平滑、V 形、断线 |
| 3 | U + C | **抓取实验**：<br>a. 抓起物体，朝左、右、斜上方各甩一次再张手，看能否甩出；<br>b. 慢慢移动后张手，看是否轻放；<br>c. 评分：甩出方向和力度、轻放是否稳定 |
| 4 | U + C | **智慧农场**：<br>a. 摄像头对着显示器上的农场网页，在页面停留至少 30 s；<br>b. 按"盘点"，拖走一只羊测走失，一个人走进画面测闯入；<br>c. 评分：流畅度（还卡不卡）、计数、告警 |
| 5 | U + C | **方块工坊**：<br>a. 比 OK 保持 0.8 s，看背包能否打开、关闭；<br>b. 正常搭建 1 分钟，看背包有没有误开；<br>c. 评分：好不好开、误开次数 |
| 6 | C | 整理串口、视频，填写 result.md，推送分支 |

**第 6 步的串口统计**：
1. 农场 `farm counts=` 行中 `draw_fps`、`ui_us` 的中位数和最小值；`farm event=` 行原文。
2. 画板 `draw f=` 行中 `hand=` 变化的次数，以及原文。
3. 各段 vision 行 `fps`、`e2e` 的中位数。
