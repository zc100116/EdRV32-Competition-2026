# 卡 108：《余烬群岛》第一个可玩版本（E1+E2）试玩

## 1. 目标

在 Windows 上试玩第一个可玩版本，反馈手感、画面和声音的问题，作为 E3 的输入。

## 2. 输入

| 项 | 内容 |
|---|---|
| 代码 | `zc100116/gpu-dev`，游戏代码 `16f6fc83d`（`sw/apps/ember_isles/`） |
| 程序 | `src/ember_isles.exe`：单文件，双击运行；加 `--half` 用 640 × 360 小窗口 |
| 截图 | `src/frame00172.png`（第 1 波）、`frame00749.png`（升级三选一）、`frame08283.png`（第 5 波开始）、`frame09500.png`（第 5 波战斗），由 3 分钟通关录像导出 |
| 声音 | `src/audio-music.flac`（海岸关音乐，20 秒循环）、`src/audio-cues.flac`（10 个音效，按编号顺序） |
| 设计 | `sw/apps/ember_isles/docs/gdd.md`、`tech.md`；数据表 `sw/apps/ember_isles/data/*.csv`；测量报告 `sw/apps/ember_isles/docs/report-e1e2.md` |

## 3. 内容范围

守火人；海岸关前 5 波（第 5 波为精英波）；4 把武器、3 种敌人、2 种精英词缀、6 件遗物、4 个铭文；升级三选一；有界岛、礁石、超时缩圈。没有祭坛、商人、金币、其他角色和关卡（E3）。

## 4. 按键

| 键 | 作用 |
|---|---|
| 方向键 | 移动；升级界面中左右选择 |
| Z | A：火焰冲刺；升级界面中确认 |
| X | B：布置火种 |
| Z + X | 终极：炉心爆发（充能满时） |
| Enter | START：开始、暂停/继续、结果画面返回标题 |
| Esc | SELECT：显示/隐藏性能信息 |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 1 | U | 拉取分支，运行 `src/ember_isles.exe`，至少完整打一局 |
| 2 | U | 听两个 flac |
| 3 | U | 把感受写进 `result.md`（可以直接口头告诉协调者，不必提交） |
