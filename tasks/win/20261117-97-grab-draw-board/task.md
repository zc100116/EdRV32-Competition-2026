# 卡 97：抓取实验和空中画板修复复测（卡 75 比特流）

## 1. 目标

复测卡 96 反馈的问题是否修好：
- 抓取实验：平台铺满全宽、松手不飞、木块旋转大小一致；
- 空中画板：指尖不跳、落笔抬笔稳定。

顺带测试智慧农场（卡 96 没有道具，未测）。

**主观项每项给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版内容（相对卡 96）

| 项 | 修改 | 卡 96 中的根因 |
|---|---|---|
| 抓取实验：平台 | 平台横跨整个画面，左右边缘有不可见的墙，物体不会掉出去 | 平台原来只占 x 280–1000，两侧没有墙 |
| 抓取实验：松手 | 松手时物体停在张手前的稳定位置，速度清零，自然落下 | 张手过程中指尖光标上移；松手帧仍在更新位置，且继承了光标速度，导致飞出 |
| 抓取实验：旋转 | 木块各角度大小一致 | 生成角度帧的正弦表余弦下标用错（`%24` 应为 `%64`），部分角度被压窄 |
| 空中画板：落笔 | 手势分类为"指点"，或手形为"食指伸直、其他手指弯曲"，任一成立即落笔。<br>- 连续 2 帧满足才落笔；<br>- 连续 4 帧不满足才抬笔；<br>- 丢手 ≤ 200 ms 时保持落笔，恢复后直线接上 | 卡 96 中"指点"分类时有时无 |
| 空中画板：平滑 | 指尖用 One Euro 滤波，笔迹按曲线插值，删除 < 10 px 的小点；橡皮使用同一套跟踪 | 指尖逐帧抖动，笔迹呈锯齿 |

## 5. 操作步骤

**每个步骤开始和结束时，请 Windows Codex 记下时间**，方便与串口对照。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261117-97-grab-draw-board origin/zc100116/b3`，记录 HEAD |
| 1 | 用户（U） | 下载卡 75 比特流，经网口加载 `src/showcase-r5b-hw.elf`，记录 HELLO |
| 2 | U + C | **抓取实验**：<br>a. 把物体推到画面最左、最右，看是否掉下去；<br>b. 抓起再松手 10 次，看是否还会飞；<br>c. 抓着木块，用剪刀手转几次，看大小是否一致；<br>d. 评分：跟手、松手稳定、旋转、好玩程度；录视频 |
| 3 | U + C | **空中画板**：<br>a. 写 3 个字，画一个圆、一个方框；<br>b. 选橡皮擦掉一部分；<br>c. 评分：跟手、笔迹平滑、落笔抬笔准确（是否断线、是否出现小点）；录视频 |
| 4 | U + C | **智慧农场**：<br>a. 手机图片放在三栏中，点"盘点"；<br>b. 拿走一张，等走失告警；<br>c. 把羊的图片移到牛栏，看串栏告警；<br>d. 打开"看板"；<br>e. 评分：识别、告警、界面 |
