# 卡 95：方块工坊、摄像头页紧凑界面、体感游戏 60 Hz（卡 75 比特流）

## 1. 目标

上板看以下内容的效果和流畅度：
- 方块工坊（取代积木塔）；
- 摄像头页紧凑界面；
- 5 个体感游戏改为固定 60 Hz 推进之后的效果。

**主观项每项给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版内容（相对卡 94）

| 项 | 内容 |
|---|---|
| 方块工坊 | 首页"体感积木"大卡片，或"体感互动 → 方块工坊"进入。没有挑战、分数和计时，只有自由搭建。<br>**进入**：先选场景：空地、小屋、城堡。<br>**网格**：每格 48 px，共 20 × 11 格。<br>**固定与掉落**：<br>- 经相邻方块连到地面的方块都固定；<br>- 连不到地面的部分整体落下；<br>- 沙子、碎石单独下落。<br>**手势**：<br>- OK 手势保持约 0.5 s：在画面中间打开或关闭物品栏，物品栏里握拳只用于选择；<br>- 剪刀手：转 90°，1×2 横竖切换，斜坡换朝向；<br>- 握拳 / 张手：抓 / 放。<br>**工具**：<br>- 空手：移动方块、举起小动物；<br>- 稿子：挖方块，8 级裂纹；敲小动物，它会晕一下再跑开。<br>**方块**：20 种，包括 1×2 的门、木梁、石柱和斜坡。<br>**昼夜**：物品栏切换白天、黄昏、夜晚，夜里灯和窗户照亮周围。<br>**小动物**：小兔、小鸭，有走路动画 |
| 摄像头页 | 实时识别、安全帽、姿态、手势、人脸贴纸、简笔画、图片识别、图像处理：<br>- 只剩 48 px 细顶栏，标题、性能和常用按钮都在这一条上；<br>- 结果在左上角的小卡片里；<br>- 设置收进右侧抽屉，点顶栏按钮展开；<br>- 贴纸套装改为缩略图按钮 |
| 体感游戏 | 弹弓打靶、石头剪刀布、打地鼠、切图形、接物篮：<br>- 游戏逻辑改为固定 60 Hz 推进；<br>- 开始、速度选择、结算画面换成新部件，结算有星级图标 |

## 5. 操作步骤

**每个步骤开始和结束时，请 Windows Codex 记下时间**，方便与串口对照。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261117-95-workshop-board origin/zc100116/b3`，记录 HEAD |
| 1 | 用户（U） | 下载卡 75 比特流，复位进入 BIOS，经网口加载 `src/showcase-workshop-hw.elf`，记录 HELLO |
| 2 | U + C | **方块工坊**，站在约 0.75 m 处：<br>a. 从首页"体感积木"进入，握拳停留选"空地"；<br>b. OK 手势打开物品栏，选"木板"，放 5 块以上；握拳不放、移动手，连续放一排；<br>c. 选"木梁"，用剪刀手在横竖之间切换后放下；选"砖斜坡"，换朝向后放下；<br>d. 选"空手"：<br>&nbsp;&nbsp;- 握住一块方块移到别处；<br>&nbsp;&nbsp;- 搭一个悬臂，把底下的支撑移走，看上面是否整体掉下；<br>&nbsp;&nbsp;- 在高处放一块沙子，看是否落下；<br>e. 选"稿子"挖几块方块，看裂纹和碎屑；挖空墙脚，看上面是否掉下；<br>f. 小动物：<br>&nbsp;&nbsp;- 空手握住举起，张手放下；<br>&nbsp;&nbsp;- 拿稿子敲一下，看晕眩和跑开；<br>&nbsp;&nbsp;- 看走路是否自然，脚底是否打滑；<br>g. 换场景"小屋"：物品栏切到黄昏、夜晚，看灯光；切换时画面是否卡顿；夜里放一盏灯、挖一盏灯；<br>h. 换场景"城堡"，自由玩 2 分钟；<br>i. 评分：好玩程度、光标跟手和放置准确、OK 手势开物品栏的成功率、挖掘动画、小动物、夜晚灯光，各 1–5 分；录视频 |
| 3 | U + C | **退出复测**：反复做 10 次"进入方块工坊 → 返回首页 → 进入另一个应用"，混用按键和画面上的返回按钮。记录是否出现"正在停止"不消失 |
| 4 | U | **摄像头页**：逐个进入 8 个摄像头页。每页看以下几点，并给出"画面可见度"和"信息是否清楚"两项评分：<br>- 视频是否看得清；<br>- 顶栏的标题和性能是否清楚；<br>- 点顶栏按钮展开、收起抽屉；<br>- 用板上按键能否走到抽屉中的控件。<br>人脸贴纸页：用缩略图换套装，再单独换几个部位 |
| 5 | U + C | **体感游戏**：5 个游戏各玩 1 局：<br>- 流畅度 1–5 分，与卡 94 相比如何；<br>- 开始画面、结算画面的意见 |
| 6 | U | 全程留意：死机、复位、画面卡住或停住 |
| 7 | C | 整理串口、照片，填写 result.md，推送分支 |
