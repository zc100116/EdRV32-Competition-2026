# 卡 102：把卡 75 比特流固化到配置 SPI flash

## 1. 目标

把演示用的卡 75 比特流写进开发板的配置 SPI flash，使开发板上电后自动加载，不再需要每次用 PDS 下载比特流。

板上程序仍按现有方式，经网口由调试工具加载到 DDR。我们的 SoC 没有 flash 控制器，程序约 40 MB，也放不进 16 MB 的 flash，所以程序不固化。

## 2. 输入

| 项 | 内容 |
|---|---|
| 代码 | 用 `git log -1 --format=%H origin/zc100116/b3 -- tasks/win/20261118-102-flash-bitstream` 找到本卡的提交，从它拉出 `win/20261118-102-flash-bitstream`，记录 HEAD。本卡不需要编译任何代码 |
| 比特流 | **卡 75 的比特流**，即卡 95–101 上板时一直在用的那个 `.sbit`。工程：`G:/codex_project/EdRV32-FPGA/EdRV32-B3F-POST/EdRV32-B3F-POST.pds`，比特流在工程的比特流输出目录下。<br>先记录文件的完整路径、大小和修改时间。不要重新生成比特流 |
| 板上程序 | 卡 101 的 `src/showcase-r5f-hw.elf`（HELLO `4525f7413`），只用于固化后的复测 |

## 5. 操作步骤

PDS 各版本的菜单名称可能不同。下面写的是操作的目的和大致位置，**以手册和实际界面为准**。遇到与本卡描述不一致、手册里也查不到的情况，停下来问用户，不要猜。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | 按第 2 节拉分支，记录 HEAD |
| 1 | C | **查资料**，记录到 result.md：<br>a. 配置 flash 的型号、容量；<br>b. 开发板的配置模式怎么设置：有没有模式拨码开关或跳线，主 SPI 模式应该怎么设；<br>c. Fabric Configuration 中"由比特流生成 SPI flash 文件"和"烧写外部 flash"两个操作的菜单路径。<br>任何一项查不到就停下来问用户 |
| 2 | 用户（U） | **确认配置模式**：按第 1 步查到的方法，把开发板设为从 SPI flash 主动配置（主 SPI 模式）。板子本身固定为该模式、没有开关的，记录"无需设置"。设置要在断电状态下进行 |
| 3 | U（GUI），C 指导 | **生成 flash 文件**：在 Fabric Configuration 中，用转换文件的功能把卡 75 的 `.sbit` 转成 SPI flash 文件（一般是 `.sfc`）。<br>- 器件选 PG2L200H；<br>- flash 型号、数据线宽度按第 1 步的结果填，拿不准时选单线 SPI（x1）；<br>- 其余选项保持默认，不开加密。<br>输出放在 `G:/codex_project/EdRV32-FPGA/flash/` 下，文件名含"card75"。记录全部选项和输出文件大小 |
| 4 | U（GUI） | **烧写**：开发板上电，接 JTAG 下载器。在 Fabric Configuration 中扫描 JTAG 链，找到 PG2L200H，再按手册的"外部 flash"流程：选择第 1 步查到的 flash 型号，加载第 3 步的 flash 文件，执行擦除、烧写、校验（Verify）。记录每一步的结果和用时。校验失败就停下来，把界面截图交给 Codex |
| 5 | U | **断电重启**：断开 JTAG 下载器，或者不做任何下载操作。开发板断电 10 s 后重新上电，观察：<br>- 配置完成指示灯（DONE）是否亮；<br>- 串口是否出现 BIOS 启动信息；<br>- 从上电到出现 BIOS 信息大约多少秒 |
| 6 | U + C | **功能复测**：用调试工具经网口加载卡 101 的 `src/showcase-r5f-hw.elf`，记录 HELLO。进入首页，再进入"安全帽检测"或"智慧农场"运行 1 分钟，确认画面和串口中的识别帧率 `fps` 与平时用 JTAG 下载的版本一致（约 27–29） |
| 7 | U | **重复上电**：再断电、上电 2 次，每次确认 BIOS 信息出现，并且能加载程序 |
| 8 | C | 填写 result.md，推送分支 |

**回退**：如果需要回到用 JTAG 下载的方式，照常用 PDS 下载比特流即可，JTAG 下载会覆盖 flash 加载的配置。

## 6. 产物

放在 `tasks/win/20261118-102-flash-bitstream/artifacts/`：
- `flash-settings.txt`：第 1、3 步的记录，包括 flash 型号、模式设置、转换选项、文件路径和大小；

flash 文件和比特流本身不提交。

## 7. 通过判据

- 第 4 步烧写和校验都成功；
- 第 5、7 步共 3 次上电，每次都不经 PDS 下载就出现 BIOS 信息；
- 第 6 步程序能加载，识别帧率与 JTAG 下载的版本一致。
