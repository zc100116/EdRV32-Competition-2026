# 卡 88：抓取测试页 R2 复测（卡 68 R2 比特流，CPU 后处理）

## 1. 目标

复测按卡 85 结果修改后的抓取测试页。确认以下三点：
- 镜像开关不再导致卡死；
- 模式 C、A 的抓取成功率；
- 手心朝镜头和手背朝镜头的差距。

本卡要用数字比较，**每次抓取都要记 ✓ 或 ✗**。

## 2. 本版改动（相对卡 85）

- **物体位置**：物体和地面线上移到屏幕中下部（地面 y=520），左右也往里收，手不需要伸到画面边缘。
- **模式 C**：
  - 握拳或抓紧算"抓"；
  - 张开或四指算"放"；
  - 爪形等其他手势保持当前状态，不会误抓、误放。
- **模式 A**：
  - 判断值做平滑；
  - "放"需要连续 4 帧满足条件才生效，"抓"仍为 2 帧；
  - 手的尺度改用手腕到四个指根的平均距离。
- **手丢失**：拿着物体时，连续 15 帧没有手才算松手（卡 85 是 10 帧）。
- **镜像**：卡 85 中点镜像按钮会卡死，原因是在摄像头出图时改了镜像。现在改为先停止采集，再改镜像，然后重新开始采集。

## 4. 环境、IP

PG2L200H-6 FBB676 开发板，PDS 只用于下载比特流。不需要新的 IP。

## 5. 操作步骤

**一次"抓取"的定义**：
1. 把手移到指定物体上，做出抓的动作；
2. 拖动约 30 cm；
3. 松开，物体落下。

满足以下全部条件才算 ✓：
- 抓到的是指定物体；
- 拖动途中物体没有掉；
- 在想松开的地方松开了。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261116-88-grab-r2-board origin/zc100116/b3`，记录 HEAD。 |
| 1 | 用户（U） | 下载卡 68 R2 的比特流，复位进入 BIOS，经网口加载 `src/showcase-grab-r2-cpu.elf`，记录 HELLO，进入"抓取测试"页。 |
| 2 | U | **镜像**：点"镜像"按钮关闭，等 3 s，再点一次打开，**重复 5 次**。记录有没有卡死、画面是否恢复，以及镜像开启时手往右移，屏幕上的手是否也往右移。 |
| 3 | U + C | **模式 C**，站在约 0.75 m 处：<br>a. 手心或侧面朝镜头，抓 **10 次**（0–5 号物体轮流），逐次记 ✓ / ✗；<br>b. 手背朝镜头，再抓 **10 次**，逐次记 ✓ / ✗。<br>两组之间口头报一次"手背"，由 Codex 记下时间戳。 |
| 4 | U + C | **模式 A**，按"模式"按钮切过去，同样做手心组 10 次、手背组 10 次，逐次记 ✓ / ✗。 |
| 5 | U | 两种模式各给手感打 1–5 分，5 分最好，并说一句主要问题。 |
| 6 | C | 统计并填写 result.md，推送分支。 |

**第 6 步的统计**：
- 用户的 ✓ / ✗ 记录，直接照抄到 result.md。
- 串口按模式和手心、手背两组统计：
  - `grab_evt` 中抓、空手抓、放的次数；
  - 每次抓住的时长（从抓到放）的中位数；
  - `hands=0` 的行数占比。

## 6. 产物

放在 `tasks/win/20261116-88-grab-r2-board/artifacts/`：
- `uart/session.log`；
- `uart/marks.txt`：手心组和手背组的分界时间；
- `notes/`：用户的 ✓ / ✗ 记录，照片或文字都可以。

## 7. 通过判据

本卡是测量卡，以下几项必须有数据：
- 镜像切换 5 次是否都正常；
- 模式 C 和 A 在手心组、手背组各自的成功次数（满分 10 次）；
- 手感评分；
- 串口统计；
- 有没有死机或复位。
