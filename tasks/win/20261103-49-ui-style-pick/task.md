# 任务卡 20261103-49-ui-style-pick：在 Windows 上看 showcase 风格样板并选定风格

## 1. 目标

用户在 Windows 上运行 PC 模拟器，看 3 套视觉风格样板，选定一套，并提出修改意见。设计依据：`docs/design/2026-11-03-showcase-ui.md`。

不涉及 PDS、ModelSim 或上板，可以在卡 48 布线期间进行。模拟器约占 50 MB 内存。

## 2. 输入

- **代码**：`origin/zc100116/b3` 上包含本卡的提交，拉出 `win/20261103-49-ui-style-pick`。
- **本卡 `src/`**：

| 文件 | 内容 |
|---|---|
| `showcase_sim.exe` | 模拟器，由 Linux 用 Zig 0.17.0 从 `83479423` 交叉编译。单个文件，不需要安装，只依赖 Windows 系统 DLL |
| `shots/*.png` | 7 张同一程序的 Linux 截图，可以先在 GitHub 上预览 |

## 3. 环境

- Windows 10/11 x64。
- 模拟器窗口是 1280×720 的逻辑分辨率，会随 Windows 的显示缩放放大：缩放为 150% 时，窗口是 1920×1080。
- exe 没有签名。SmartScreen 拦截时，点"更多信息 → 仍要运行"。

## 4. 需要的 IP

无。

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261103-49-ui-style-pick origin/zc100116/b3`，记录 HEAD。 |
| 1 | 用户（U） | 双击 `tasks/win/20261103-49-ui-style-pick/src/showcase_sim.exe`。 |
| 2 | U | 数字键 1 / 2 / 3 切换样板：A 深色科技、B 浅色简洁、C 深紫仪表。每套都看首页和系统监控页：在"系统监控"卡片上按 Enter 或用鼠标点击进入，按 Esc 返回。← → 移动卡片焦点。 |
| 3 | U | 选定一套风格，提出意见，例如配色、字号、卡片大小和间距、图标、状态栏内容、监控页的布局、文案。可以在这套的基础上混合别套的元素，如"A 的配色 + C 的大号数字"。 |
| 4 | C | 把用户的选择和意见整理进 result.md，尽量保留用户原话。如果 exe 无法启动，记录报错原文并截图。 |
| 5 | C | 提交 result.md（以及截图，如果有），推送 `win/20261103-49-ui-style-pick`。 |
