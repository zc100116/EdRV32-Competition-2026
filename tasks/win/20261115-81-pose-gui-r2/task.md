# 卡 81：姿态页 GUI 优化后复测（卡 68 R2 比特流，CPU 后处理）

## 1. 目标

在卡 68 R2 的比特流上复测"人体姿态"页：
- 确认 GUI 优化降低了绘制时间、排队时间和端到端延迟；
- 补测卡 79 没有取得的静止抖动和举手准确率。

背景：
- 卡 79（b3 `095b17d4`）的中位数：fps 15，npu 39.2 ms，**gui 53.7 ms**，**wait 58.7 ms**，decode 19.3 ms，e2e 190 ms，idle 19%。
- 原因有两个：每帧整屏重画 UI 层；骨架连线由 LVGL 软件抗锯齿绘制。
- 本卡程序（b3 `1c1afbcb`）改为只重画每个人新旧骨架所在的区域，连线改成 CPU 直接画的 3 像素实线，没有抗锯齿。
- 主机模拟器上每帧 GUI 的 CPU 时间：1 人降 93%，3 人降 82%（`docs/reports/2026-11-15-pose-gui.md`）。板上收益以本卡为准。
- decode（CPU 后处理）在卡 68 R2 上不变；它要等卡 75 的硬件后处理才会消失。

**不需要 PDS 综合或布线**，只占用开发板。

## 5. 操作步骤

串口每秒一行 `pose fps=… npu=… wait=… decode=… kpt=… gui=… e2e=… period=… persons=… idle=… npu_gap=… jit_lw=… jit_rw=… jit_ls=… jit_rs=…`。调试工具的串口记录带时间戳。

**每一项开始和结束时，由用户口头报时，Windows Codex 记下当时串口最后一行的时间戳**，统计时按这两个时间切出对应的行。

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261115-81-pose-gui-r2 origin/zc100116/b3`，记录 HEAD。 |
| 1 | 用户（U） | 下载卡 68 R2 的比特流，按 KEY1 复位进入 BIOS，记录 `CLK_SYS_HZ`。 |
| 2 | U + C | 经 BIOS 网口加载 `src/showcase-pose-cpu.elf`，记录 HELLO 中的版本，应为 `1c1afbcb`。进入"人体姿态"页。 |
| 3 | U + C | **单人骨架**：一人站在约 2 m 处正对摄像头，拍一张照片，看骨架和连线是否贴合，连线有没有断开或残影。 |
| 4 | U + C | **静止抖动**：同一人在约 2 m 处站着不动 30 s，记录起止时间。 |
| 5 | U + C | **举手**：在约 2 m 处依次举左手、放下，举右手、放下，双手同时举起、放下，每种 5 次，约 2 s 一次，记录起止时间。逐次记录：指示是否亮起、是否亮错了手、放下后是否熄灭、有没有误亮。建议用手机拍下这段，同时拍到人和屏幕。 |
| 6 | U + C | **距离**：在约 1 m、3 m 处各举右手 3 次，记录亮起次数和骨架是否完整。 |
| 7 | U + C | **两人**：两人并排站在约 2 m 处，拍照，看两人的骨架是否互不串连。 |
| 8 | U + C | **连续运行**：一到两人在画面中自由走动、挥手 3 分钟，记录起止时间，要求不少于 170 行。 |
| 9 | U + C | **切换**：回到启动器，进入"实时识别"页约 10 s，确认检测框正常；再回"人体姿态"页，确认没有残留骨架、没有卡死。 |
| 10 | U | 测试结束后**不要立刻复位**，先停 10 s。如果中途出现不是人为按下的复位或死机，记录发生时间和之前 50 行串口输出。 |
| 11 | C | 按记录的时间分别统计第 4 步（抖动）和第 8 步（耗时）的最小值、中位数和最大值，填写 result.md，推送 `win/20261115-81-pose-gui-r2`。 |

## 6. 产物

放在 `tasks/win/20261115-81-pose-gui-r2/artifacts/`：
- `uart/session.log`：完整串口记录；
- `uart/marks.txt`：每项的起止时间；
- `photos/`：单人骨架、两人骨架；
- `video/`：举手视频，可选，单个文件不超过约 20 MB。

## 7. 通过判据

- 骨架和连线贴合身体，两人时互不串连，人离开后没有残影；
- 2 m 处每种举手动作 5 次中至少 4 次正确亮起，没有误亮；
- 连续 3 分钟没有死机、复位或画面错乱；
- 切换页面后检测与姿态都正常；
- 所有数字取自串口原文，找不到的写"未取得"。
