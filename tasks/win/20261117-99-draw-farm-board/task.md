# 卡 99：空中画板跳点和断线修复、单区域智慧农场（卡 75 比特流）

## 1. 目标

- 复测空中画板：笔迹不再往下拉出 V 形，手指侧一点不断线；
- 试用单区域智慧农场：动物计数、盘点和走失、有人闯入告警。

平板演示 APK 还在开发，完成后另出一张卡。本卡不需要平板。

**主观项每项给 1–5 分（5 分最好），并写一句主要问题。**

## 2. 本版内容（相对卡 98）

| 项 | 内容 |
|---|---|
| 空中画板 | 用卡 98 的录像逐帧回放查出根因并修复：<br>- **V 形**：指尖和第二、三关节的关键点一起往下塌时，上一轮的外推沿已经反向的关节方向，把笔尖推到了掌下。现在改为用最后一次可靠的"指尖相对指根"的位置差，跟着手掌平移；<br>- **侧指断线**：手指侧过来时，手势常被误认成剪刀手或握拳，原来 4 帧就提笔。现在只有张开手掌、握拳，或食指收起，并持续 0.4 s 才提笔；<br>- 丢手保持从 200 ms 放宽到 300 ms；<br>- 去掉多等一帧的样条，笔迹处理延迟从 86 ms 降到 53 ms；<br>- 串口每帧输出一行 `draw f= hand= kp8= kp5= cls= pen= why= out=` |
| 智慧农场 | 不再分栏，整个画面一块区域：<br>- 统计牛、马、羊、鸟四类的数量；<br>- 盘点后某类变少，持续 2 s 就告警走失；<br>- 检测到人持续 0.5 s 就告警闯入，人的框变红；人离开 1 s 后解除；<br>- 看板：当前数量和基准、今日走失和闯入次数、最近事件 |

## 5. 操作步骤

| 步骤 | 执行者 | 内容 |
|---|---|---|
| 0 | Windows Codex（C） | `git fetch origin`，`git switch -c win/20261117-99-draw-farm-board 8619c7797` |
| 1 | 用户（U） | 下载卡 75 比特流，经网口加载 `src/showcase-r5d-hw.elf`，记录 HELLO |
| 2 | U + C | **空中画板**：<br>a. 食指竖起，在脸前横着画 5 条直线，看有没有往下拉的 V 形；<br>b. 画线时手指左右侧一点，看会不会断；<br>c. 写 3 个字；<br>d. 张开手掌，确认能提笔；<br>e. 评分：跟手、平滑、V 形、断线；录视频，记下出问题的大致时刻 |
| 3 | U + C | **智慧农场**：<br>a. 摄像头对着显示器上的农场网页，确认计数为牛 2、马 1、羊 3、鸟 3，按"盘点"；<br>b. 用鼠标把一只羊拖出网页农场，等走失告警，再拖回来，看能否解除；<br>c. 一个人走进摄像头画面，停留几秒，看闯入告警；离开后看能否解除；<br>d. 打开看板，看今日次数和最近事件；<br>e. 评分：计数准确、走失告警、闯入告警、看板；录视频 |
| 4 | C | 整理串口、视频，填写 result.md，推送分支 |

**第 4 步的串口统计**：
1. `draw f=` 行：总行数。把用户记下的出问题时刻前后各 2 s 的原文摘到 `artifacts/uart/draw-issues.log`。
2. `farm counts=` 和 `farm event=` 行原文，按时间列出。
3. 空中画板、智慧农场各段的 vision 行：`fps`、`e2e` 的中位数。
