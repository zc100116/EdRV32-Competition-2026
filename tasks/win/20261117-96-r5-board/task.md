## 2. 本版内容（相对卡 95）

| 项 | 内容 |
|---|---|
| 抓取实验 | 原"物理积木"改名为"抓取实验"，入口在"体感互动 → 抓取实验"。<br>- **物体**：只有方块和球，6 种材质。进入时平台上已经摆好 3 个方块、3 个球。<br>- **抓取模式**：顶栏可以切换 A / B / C / D 四种判定（与设置中的抓取测试相同）。<br>- **抓取**：判定为"抓"就立刻抓起，不再等待；抓着的物体精确跟手，钢块也能拿起来；放手时可以扔出去。<br>- **其他手势**：剪刀手转 90°；点赞召唤一个随机物体，从天上掉下。<br>- **修复**：撞到堆上整体弹飞的问题（角冲量计算溢出）。方块不再反弹，静止时自动摆正。<br>- **加载**：首次进入生成的角度帧从 1632 帧减到 96 帧，估计约 0.7 s |
| 方块工坊 | 物品栏改为**点赞保持 0.8 s** 打开或关闭。光标旁显示进度环，中途换手势就取消。不再用 OK |
| 体感游戏 | 5 个游戏改为只有一条 48 px 顶栏，删除右侧性能面板和底部提示条。<br>结算卡：分数只显示一次，"再来一局"为实心按钮，"返回"为描边按钮 |
| 图像处理 | 设置抽屉中，下拉框展开后有不透明底色，不再与下面的选项重叠，所有下拉框都已修复。<br>间距收紧；顶栏不再显示"NPU 0.0 ms" |
| 简笔画 | 已删除 |
| 智慧农场（新） | "AI 视觉 → 智慧农场"。画面竖分三栏：牛栏（牛、马）、羊圈（羊）、禽舍（鸟）。<br>- 左上角卡片显示各栏数量，格式为"实际 / 应有"；<br>- 顶栏"盘点"：把当前数量记为应有数量；<br>- 少了并持续 2 s → "走失"告警；动物出现在别的栏并持续 1 s → "串栏"告警；<br>- 顶栏"看板"：打开右侧抽屉，内容是数量曲线和告警时间线 |
| 空中画板（新） | "体感互动 → 空中画板"。<br>- 伸出食指（指点手势）就落笔，换手势就抬笔；<br>- 工具条在画面上方居中：8 种颜色、3 种粗细、笔、橡皮、清空，光标悬停 0.6 s 选中；<br>- 只有选中橡皮时，指点经过的地方才擦除 |
