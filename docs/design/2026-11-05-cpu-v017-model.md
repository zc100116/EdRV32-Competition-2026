## 决策

推荐下一轮只做普通tournament的RTL/时序探针：三个负载均有收益且快于置信变体；新增状态12,800bit，代价远低于融合扩口，F2纠正已付费。 融合不加：约2.4…2.6K LUT及688FF，slli→add超7级；串联ALU本轮不做；双LSU暂不加（DRM后超4级、真双R/W待验证）；split仅省75/49/131周期，不进S3。
频率必须保持F新/Fs3>C候选/Cs3；普通tournament要在三负载都获益需保持>0.9796（LVGL限制），不能用IPC收益替代150MHz的PDS验证。
