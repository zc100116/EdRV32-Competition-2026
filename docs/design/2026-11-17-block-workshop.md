# 方块工坊：积木塔改为网格创造模式

## 1. 背景和问题

卡 94（b3 `ce3f4dac2`）上板后，用户 2026-11-17 对积木塔的反馈：

- **不要挑战关卡**：只要自由模式，类似 2D 方块沙盒游戏的创造模式。挑战关卡是协调者写进 R4 规划第 6.6 节、没有经过确认就实现的，撤销。
- **物品栏**：要能任意选择方块。不要现在这种"积木架拿走一块、随机补一块"的方式。
- **形状**：1×1、1×2、三角形等。方块种类要多，要能搭房子。
- **稳定**：已经放在别的方块上的方块还在跳来跳去，不稳定。要设计合理的固定方式，才能搭大房子；悬空的部分要掉下来。
- **场景**：可以选空白场景，也可以选带初始建筑的场景。
- **工具**：手上拿稿子可以挖方块，挖掘要有动画，按阶段逐渐出现裂纹；空手是移动。
- **边缘**：积木架放在画面两侧，靠近边缘时识别不准。
- 其他部分可以发挥想象，完善演示效果。

本记录取代 `2026-11-16-showcase-r4-plan.md` 中的以下内容：
- 第 6 节，积木塔的画面、操作、物理和流程；
- 8.1 节中的 D2（可以转动和倒塌）、D4（剪刀手旋转积木）、D5（玻璃会碎）。

## 2. 约束

- 输入：
  - 手部光标，模式 C：握拳或抓紧为"抓"，张开或四指为"放"，其他手势保持当前状态；
  - 丢手 ≤200 ms 时保持状态；
  - 手势模型共 14 类，见 `ui/gesture.c`。
- 显示：
  - 同步显示的体感页，约 25 fps；
  - L1 是 ARGB8888；RND 能做复制、缩放、翻转、半透明，不能旋转；
  - 静态内容只画一次，只重绘有变化的格子。
- CPU 是 rv32im，用整数运算。游戏逻辑在应用任务中按 60 Hz 运行，使用现有的 `game_loop`。
- 美术和名称都是原创的，不照搬任何现有游戏的方块外观、角色和名称。

## 3. 决策（用户 2026-11-17）

| 编号 | 问题 | 决定 |
|---|---|---|
| W1 | 固定方式 | **网格，连到地面就固定**。方块吸附到网格上，不会跳动。经相邻方块连到地面的都固定；挖掉支撑后，连不到地面的部分整体竖直掉落，落地有扬尘。沙子这类方块单独受重力，会下落 |
| W2 | 物品栏 | **OK 手势**保持约 0.5 s，打开或关闭物品栏，显示在画面正中间：<br>- 第一行是工具：空手（移动）、稿子（挖掘）；<br>- 下面是全部方块；<br>- 手停在格子上握拳就选中，选中后自动关闭。<br>物品栏打开期间，握拳只用于选择，不影响场景中的方块 |
| W3 | 扩展 | **昼夜和灯光**；**小动物漫步** |
| W3a | 小动物 | - 不能机械平移，要用预先做好的走路动画帧；散步和跑开用同一套帧、按不同速度播放；<br>- 空手握住小动物，可以把它举起来；<br>- 拿着稿子握住它，就是敲它一下：它会受惊（晕眩、跑开），不出现伤害或血腥画面 |

**协调者补充**：以下是实现细节，未经用户逐项确认，用户可以调整：

| 项 | 内容 |
|---|---|
| 网格 | 每格 48 px，20 列 × 11 行，可搭建区域 960×528：x 160–1120，y 152–680。离画面左右边缘至少 160 px，避开边缘识别不准的区域。格子比 40 px 大，手抖时也容易对准 |
| 形状 | - 1×1；<br>- 1×2，横放或竖放；<br>- 三角斜坡，4 个朝向。<br>剪刀手把当前选中的形状转 90°：1×2 在横竖之间切换，斜坡换朝向 |
| 方块，约 20 种 | - 地形：草地、泥土、石头、碎石、沙子（会下落）；<br>- 建材：木板、原木、石砖、砖块、金属、冰、玻璃；<br>- 植物：树叶；<br>- 功能：灯（夜里发光）、窗户（夜里透出灯光）、木门（1×2 竖放，小动物可以穿过）；<br>- 1×2：木梁（横）、石柱（竖）；<br>- 斜坡：木斜坡、砖斜坡（屋顶） |
| 放置 | 手里拿着方块时，光标所在格显示半透明预览；握拳放下一块；按住握拳拖动可以连续放置 |
| 移动 | 空手时握住一个方块，提起来跟手走，张手放到预览格。移走后，上面断开的部分会掉落 |
| 挖掘 | 拿着稿子时握住一个方块，按方块硬度在 0.4–2 s 内出现 8 级裂纹，最后碎掉并迸出碎屑。张手则中止，裂纹消失 |
| 场景 | 开始时选择：空地、小屋、城堡。小屋和城堡由方块预先搭好，可以挖、可以改 |
| 昼夜 | 物品栏里有"白天 / 黄昏 / 夜晚"切换，改变暗幕的颜色和浓度；夜里灯和窗户显示光晕 |
| 名称 | 应用名"方块工坊"；首页场景大卡片仍叫"体感积木" |

## 4. 影响

- 删除积木塔的以下部分：挑战流程、积木架、刚体物理和角度帧。具体是：
  - 刚体物理 `ui/phys.c/h`；
  - GEO 生成角度帧的 `ui/sprite_rot.c/h`，以及 GEO 驱动中为它增加的辅助函数；
  - `ui/tower.c/h` 的规则；
  - 相关测试和 DDR 中的图集区域。
- 新增：
  - 网格世界、结构连通判定和掉落；
  - 物品栏、工具、挖掘；
  - 小动物；
  - 昼夜；
  - 场景预设。
- 原创美术：方块纹理、斜坡、8 级裂纹、小动物动画帧、稿子和手形光标、光晕。
