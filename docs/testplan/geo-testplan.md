## 1. 验证对象和范围

`edrv32_geo` 模块级验证，覆盖规格第 2、4、5、6、7 节。`dma2d_rd/wr` 自身的事务拆分已在 `dma2d-testplan` 验证，这里只检查 GEO 的整体结果和协议。与 mem_xbar、真实 DDR 模型和其他主设备并发时的带宽在 SoC 级验证。软件矩阵辅助函数在 `sw/` 的单元测试中验证，不属于本方案。

## 2. 验证环境

- 层级：模块级，`verif/block/geo/`，Verilator `--timing`，自检。
- P5 从设备：testbench 内 AXI256 读写存储模型（随机 `arready/awready/wready`、R 间隔、B 延迟，可设固定读延迟，可对指定事务注入 SLVERR）；复用 `verif/common/edrv32_axi256_checker.sv` 检查协议。
- APB：`verif/common/edrv32_apb_if.sv`。
- 参考模型：Python 脚本 `verif/block/geo/geo_ref.py`，按规格 2.1–2.3 逐位实现（只用标准库），输入源 Surface、输出 Surface 初值和描述符，输出期望的输出 Surface。另提供矩阵生成函数（角度、缩放、平移 → Q16.16），只用于产生激励。参考模型不参照被测 RTL。
- 测试图：随机像素、棋盘格、渐变、带编号的网格（便于定位坐标错误）。

## 4. 参考模型

`geo_ref.py` 对每条描述符：先按规格 2.4 计算是否超出范围（使用 5.2 表中的 BW、BH、PW、PH），超出时期望 ERR_CODE 3 且输出 Surface 不变；否则对矩形内每个 (u, v) 按 2.1、2.2 计算输出像素，矩形外不变。比对时读取存储模型中的整张输出 Surface，失败时打印描述符序号、坐标 (u, v)、期望值和实际值。

## 5. 覆盖目标

规格 2.1–2.6、4、5、6、7 的每一条至少对应一个测试项；必须命中：四个直角旋转和非直角旋转、放大与 s = 2 缩小、镜像和错切、全部越界、矩形外不变、变换范围边界两侧、串行依赖、每种错误代码、ABORT 在途事务。

## 6. 通过判据和回归档位

全部测试自检 PASS；smoke：GE-01–09、11（GE-06 取 4 个角度）；full：全部（GE-12 除外）；perf：GE-12。lint 和风格检查 0 告警。smoke 每个测试目录不超过约 60 秒（CLAUDE.md 9.1）。
