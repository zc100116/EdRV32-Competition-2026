## 1. 验证对象和范围

`edrv32_aud` 模块级验证，覆盖规格第 2、4、5、6 节。ES8156 的寄存器配置和实际声音在上板验证（`gpu-soc-testplan.md`）。

## 2. 验证环境

- **位置**：`verif/block/aud/`。仿真器为 Verilator `--timing`，测试自检。
- **时钟**：clk_mem 125 MHz，clk_aud 12.288 MHz，相位随机。
- **DDR 模型**：AXI256 读存储模型，延迟随机，可注入 SLVERR，并检查协议。
- **I2S 接收模型**：`verif/models/i2s_rx_model.sv`，作为 I2S 从机。它按标准 I2S 格式恢复左右声道样本，并检查 BCLK、LRCK 的频率和相位关系。

## 3. 测试项清单

| 编号 | 规格条款 | 测试内容 | 激励 | 检查 | 档位 |
|---|---|---|---|---|---|
| AT-01 | 2.1、2.5 | I2S 波形和样本：已知样本序列（含 0x8000、0x7FFF、左右不同） | 定向 | 接收到的样本序列与缓冲内容逐个一致；BCLK = clk_aud/4，LRCK = 48 kHz；数据位置 | smoke |
| AT-02 | 2.2、2.3 | 环形缓冲：多次回绕；WR_PTR 分多次推进；读拆分到缓冲末尾、4 KiB 边界、avail 不足 512 B | 定向 | 样本连续无重复无遗漏；每个读事务合法 | smoke |
| AT-03 | 4 | LOW 中断：avail 从高于阈值降到低于阈值时置位一次；一直低于阈值时不重复置位 | 定向 | IRQ_STAT.LOW、`irq_o` | smoke |
| AT-04 | 2.5 | 欠载：缓冲为空时输出 0 并计数，补充样本后恢复 | 定向 | 输出样本、UNDERRUN_CNT | smoke |
| AT-05 | 4、2.5 | ENABLE 关闭、重新打开：RD_PTR 清零，FIFO 清空，关闭期间输出 0 且不计欠载 | 定向 | 样本、计数、无未完成事务 | smoke |
| AT-06 | 6 | AXI 读错误 | 定向 | ERR_CODE 1，DMA 停止，FIFO 剩余样本播完后输出 0 | smoke |
| AT-07 | 2.4 | `urgent_o`：FIFO 水位低于 64 时为 1；ENABLE = 0 时为 0 | 定向 | `urgent_o` | smoke |
| AT-08 | 4 | 寄存器：复位值、ID（TYPE = 1）、对齐位读 0、ENABLE = 1 时写 RING_BASE/SIZE 无效 | 定向 | 读回值 | smoke |
| AT-09 | 全部 | 随机回归：随机 DDR 延迟、随机推进时刻和推进量 | 随机 | 样本序列一致；未欠载时计数为 0 | full |

## 4. 参考模型

testbench 内的环形缓冲镜像：按 WR_PTR 推进的顺序给出期望样本序列；欠载时期望值为 0。

## 5. 覆盖目标

规格第 2、4、6 节的每一条至少对应一个测试项。

## 6. 通过判据和回归档位

全部测试自检 PASS；lint 0 告警。smoke：AT-01–08；full：全部。
