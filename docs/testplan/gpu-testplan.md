## 1. 验证对象和范围

- **单元级**（RTL worker 自己完成）：GPU 内部各单元，按微结构设计记录中的内部接口逐单元验证。
- **模块级**（本方案的主体，由独立的验证 worker 完成，不阅读被测 RTL）：`edrv32_gpu` 整体，覆盖规格第 2、4、5、6、7 节。
- **SoC 级**：软件驱动下的端到端渲染、与 DISP 和 mem_xbar 的连接，见 `gpu-soc-testplan.md`。

## 2. 验证环境

- **位置**：`verif/block/gpu/`。仿真器为 Verilator `--timing`，测试自检。
- **时钟**：clk_gpu 150 MHz；AXI、APB 直接接在 clk_gpu 侧，不经异步桥（异步桥在 SoC 级覆盖）。
- **DDR 模型**：AXI256 从设备存储模型，`arready`/`awready`/`wready` 随机，R、B 延迟随机，可注入 SLVERR；用 `edrv32_axi256_checker.sv` 检查协议（4 KiB 边界、对齐、LEN）。
- **APB**：`edrv32_apb_if.sv`。
- **参考模型**：`tools/gpu/model/`，Python 逐位参考模型（第 4 节）。
- **场景生成**：`tools/gpu/scene/` 生成命令列表、顶点缓冲、四边形表、对象表、纹理和调色板，输出 DDR 镜像（`+DDR_HEX=`）和参考模型的期望结果。
- **结果比对**：仿真结束时，testbench 通过后门导出渲染目标（颜色、深度、模板）和 DDR 镜像，由 Python 与期望结果逐位比对；不一致时打印第一个不一致的位置、期望值和实际值。

## 4. 参考模型

- `tools/gpu/model/`：Python 逐位参考模型，按规格给出的定点格式、舍入和近似方法实现，与 RTL 的内部结构无关。
- **数值格式**：G-N1–G-N3 已在规格 v0.2 定稿（2.4–2.6、2.12）；模型和 RTL 都按 v0.2 实现。
- **期望结果**：渲染目标（颜色、深度、模板）、写出的 Surface、对象表、命中列表、释放列表、计数寄存器、PERF 统计。
- **独立性**：模型由验证 worker 依据规格编写，不参考 RTL。

## 5. 覆盖目标

- 规格第 2、4、5、6 节的每一条至少对应一个测试项。
- 必须命中的组合：
  - 每种取样模式 × 每种纹理格式；
  - 每种混合运算；
  - 每种模板操作；
  - 4 像素组的 4 种起点偏移；
  - 裁剪的每个平面；
  - 对象单元两个列表的溢出；
  - 每种错误。

## 6. 通过判据和回归档位

- 全部测试自检 PASS；lint 和风格检查 0 告警。
- smoke 档：GT-01–08、11–14、16–20、23。
- full 档：全部。
- perf 档：GT-25。
