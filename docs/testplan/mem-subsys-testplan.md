## 1. 验证对象和范围

- 本模块验证：DDR 网关、AXI64 异步桥、mem_xbar（调度、流量控制、读返回缓冲、W 缓冲、违规检测、寄存器）、存储子系统顶层连线；附录 A 板级 DDR 适配器的单元测试。
- 留给上一层：CPU 经 sys_xbar → 网关访问 DDR 的软件级测试（系统子系统 SC-06 已覆盖网关窗口，换成真实存储子系统后在 SoC 级重跑）；各媒体引擎的实际流量（P3 以后各阶段）；上板带宽标定（Windows 任务卡）。

## 2. 验证环境

### 2.1 层级

| 层级 | 目录 | 对象 |
|---|---|---|
| 单元 | `verif/unit/<模块>/` | 网关、异步桥、mem_xbar、板级适配器，由 RTL 作者编写 |
| 模块级（MB 环境） | `verif/block/mem_subsys/` | 存储子系统顶层 + 下列模型，由独立验证 worker 编写 |

### 2.2 MB 环境组件

| 组件 | 说明 |
|---|---|
| AXI64 主设备驱动 | 复用 `verif/common/edrv32_axi64_master.sv`，接网关 |
| AXI256 主设备驱动 ×6 | 新增 `verif/common/edrv32_axi256_master.sv`：可配置事务序列、R/B 反压模式、`urgent` 驱动；P0 只读，其余读写 |
| DDR 时序模型 | 新增 `verif/models/ddr3_axi256_model.sv`，见 2.3 |
| 参考存储 | 字节级稀疏存储，所有写按 B 返回顺序更新，读结果逐拍比对 |
| AXI256 协议检查器 | 新增 `verif/common/edrv32_axi256_checker.sv`：SoC 4.2 全部规则（对齐、4 KiB、LEN、W 不交织、下游无 BREADY/RREADY 时 mem_xbar 必须接收） |
| APB 驱动 | 复用系统子系统的 APB 驱动，访问 MEM_XBAR 寄存器 |
| 调度观察器 | 记录下游每次授权的端口、方向、时刻，供调度规则检查 |

### 2.3 DDR 时序模型

| 项 | 规定 |
|---|---|
| 接口 | SoC 3.2 AXI256 从侧：无 BREADY、无 RREADY |
| bank/行 | 8 个 bank，每 bank 记录一个打开的行；地址映射 [待定，初值：行 = addr[29:15]，bank = addr[14:12]，列 = addr[11:0]] |
| 时序参数（clk_mem 周期，plusarg 可改） | 同行命中首拍延迟 `T_HIT`=8；换行额外 `T_MISS`=4；读写换向 `T_TURN`=3；每 `T_REFI`=975 周期刷新停顿 `T_RFC`=38；数据线每周期至多 1 拍 |
| 在途 | 命令队列深度 8；写数据随 AW 后的 W 到达；B 在一笔写的最后一拍写入后 `T_B`=2 周期返回 |
| 顺序 | 按到达顺序执行（与附录 A 对 IP 的假设一致） |

参数初值由 DDR 带宽分析文档的 idf 时序换算；上板实测后校准（规格待定事项 4）。

## 4. 参考模型

- 数据：字节级参考存储，按下游 B 返回顺序更新；读数据逐拍比对。
- 调度：调度观察器记录授权序列，测试按 SoC 6.4.2 的规则逐次判定（每次授权时根据当拍各端口状态计算"允许的端口集合"，实际授权必须在集合内）。

## 5. 覆盖目标

| 功能点 | 要求 |
|---|---|
| 网关 | 两类合法事务 × 两个窗口 × 读写；SIZE 0–3 × 每个字节位置；所有不支持类别各一次 |
| 调度 | 五条规则每条都实际决定过授权；URG_MAX 达到上限；令牌不足被跳过；饿死触发；换向 |
| 流量控制 | 全局和每端口在途上限都达到过；读返回缓冲 credit 耗尽 |
| 违规 | 三类违规各一次，读写都有 |
| 统计 | 快照、清零、饱和各一次 |

每条规格条款至少对应一个测试项。
