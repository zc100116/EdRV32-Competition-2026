## 1. 验证对象和范围

- 本方案验证系统子系统规格中的全部模块：sys_xbar、ROM、SRAM、两个 APB 桥（含 `edrv32_apb_async_bridge`）、CLINT、PLIC、UART0、GPIO0、I2C0、SYSCTRL、reset_ctrl。
- CACHE_CTRL 已在 cache 验证中覆盖，这里只检查它在系统 APB 槽 5 上可以访问。
- DDR 网关和 mem_xbar 属于存储子系统，这里用 AXI64 内存模型代替 S6。
- SoC 顶层（全部子系统加外部器件模型）的测试在 SoC 级验证方案中定义。

## 2. 验证环境

| 环境 | 层级 | 组成 | 编写者 |
|---|---|---|---|
| U | 单元级 | 单个模块 + 自检 testbench | RTL worker |
| SB | 模块级 | 系统子系统顶层（sys_xbar + 全部从设备 + APB 外设）+ 两个 AXI64 主设备驱动（模拟 I$、D$）+ S6 处的 AXI64 内存模型 + UART 模型 + 两个 SCCB 从设备模型 + GPIO 激励 + 媒体 APB 侧的 APB 从设备模型（clk_mem 域） | 独立验证 worker |
| SC | 模块级 | `edrv32_cpu_subsys` + 系统子系统 + S6 内存模型 + UART/SCCB/GPIO 模型；CPU 运行 `sw/` 构建的程序 | 联调 Task |

### 2.1 SB 环境的组件

| 组件 | 要求 |
|---|---|
| AXI64 主设备驱动 | 两个，可发单拍和 4 拍突发、读写、任意 SIZE/WSTRB；可配置事务间隔；遵守 SoC 规格 4.1（每方向至多 1 笔未完成） |
| 参考存储模型 | 按 SoC 规格 6.1 的地址映射维护 ROM、SRAM、DDR 的期望内容，计算每笔访问的期望数据和响应（OKAY/SLVERR/DECERR） |
| AXI 协议检查器 | 复用 `verif/common/` 中 cache 验证已有的 AXI64 检查器，挂在两个主口和每个从口上 |
| APB 检查器 | 检查 SETUP/ACCESS 时序、`psel` 单热、传输在 `pready` 前保持 |
| APB 从设备模型 | 媒体 APB 侧，可配置 `pready` 延迟、`pslverr`、永不 ready（用于超时） |
| UART 模型 | `verif/models/`：按设定波特率收发字节，可设波特率偏差、注入帧错误 |
| SCCB 从设备模型 | `verif/models/`：OV5640 风格，7 位地址 0x3C（写地址字节 0x78），16 位寄存器地址、8 位数据；可配置在某个字节回 NACK |
| 时钟 | clk_sys 与 clk_mem 两个异步时钟，频率比可配置（含 clk_mem 快于、慢于 clk_sys） |

## 4. 参考模型

- SB 环境：参考存储模型 + 寄存器期望值（按第 4 节寄存器表）；UART、SCCB 模型记录实际总线上的字节并与期望比对。
- SC 环境：程序自检，结果写 SYSCTRL `SIM_EXIT`；UART 输出存入测试日志。

## 5. 覆盖目标

| 功能点 | 要求 |
|---|---|
| sys_xbar | 2 主 × 7 从 × 读/写 每个组合出现（禁止的组合以 DECERR 出现；M0 没有写通道，M0 写不适用）；S0、S1、S6 上发生过两主竞争；S2–S5 上发生过 M0 被拒（DECERR）与 M1 合法访问同时进行 |
| 响应类型 | OKAY、SLVERR、DECERR 在读和写上都出现 |
| APB | 每个已用槽读写、预留槽、超时、`pslverr` |
| PLIC | 已分配的 12 个源（1、2、5、6、8–15）每个都被认领过；预留源 3、4、7 不统计；优先级相等的竞争出现过 |
| UART | 3 种波特率、溢出、帧错误、4 种中断 |
| I2C | 两个端口、读写、NACK、两种速率 |
| 复位 | 上电、媒体软复位、SOC 软复位 |

每条规格条款至少对应一个测试项（第 3 节"规格条款"列）。
