# DISP 验证方案

| 项 | 内容 |
|---|---|
| 版本 | v0.3 |
| 日期 | 2026-10-29 |

## 1. 验证对象和范围

`edrv32_disp` 模块级验证，覆盖规格第 2、4、5、6 节（含 v0.3 两层叠加）。TMDS 串化和差分输出在 FPGA 层，不在本方案（上板任务卡验证）。与 mem_xbar、DDR 模型的联合实时性在 SoC 级验证。

## 2. 验证环境

- 层级：模块级，`verif/block/disp/`，Verilator `--timing`，自检。clk_pix 74.25 MHz、clk_mem 125 MHz，相位可随机；另设快速模式（时序参数不变，只缩短仿真帧数）。
- TMDS 接收模型：新增 `verif/models/tmds_rx_model.sv`：按 DVI 1.0 规范对三路 10 位符号解码（控制符号识别 HS/VS、数据符号解码为 8 位），恢复 HS/VS/DE 和 RGB888，并逐帧收集像素。解码算法按 DVI 规范独立实现，不参照被测编码器。
- TMDS 参考编码：Python 脚本 `verif/block/disp/tmds_ref.py`，按 DVI 1.0 编码算法生成一帧期望符号序列（含运行差异），用于 DS-02 的逐符号比对。
- P0 从设备：AXI256 读存储模型，随机 `arready` 和 R 间隔，可长时间停止响应，可注入 SLVERR；`edrv32_axi256_checker.sv` 检查协议。
- APB：`edrv32_apb_if.sv`。

## 4. 参考模型

- 像素：testbench 根据每帧锁存的参数（由 FRAME 时刻的 CUR_BASE、L1_CUR_BASE 及 testbench 写入的帧锁存寄存器得到）从存储模型取出两层 Surface，L0 按 2.3 展开、按卷轴开窗，L1 按矩形放置，再按规格 2.7 的 d(x) 公式逐位混合为期望帧（Python 参考模型 `verif/block/disp/blend_ref.py` 与 testbench 内 SV 实现共用同一公式，DS-15 两者互相比对）；DS-07、DS-13 中按 2.7 的欠账规则判断读空：两层使用可区分的测试图案，从输出识别 L0 黑块和 L1 透明组，逐层统计欠账并检查恢复后对齐（黑盒，不访问 RTL 内部信号）。
- TMDS：Python 参考编码（DS-02）和独立的接收模型解码（其余项）。

## 5. 覆盖目标

规格 2.1–2.7、4、5、6 的每一条至少对应一个测试项；必须命中：帧中与消隐中写帧锁存寄存器、两层读空跨帧、请求积压、ENABLE 在帧中切换、全部错误代码（1、2、3）、拍内偏移 0–15、α/OPA 端点值、L1 矩形四边贴屏幕边界、按层开关引起的释放。

## 6. 通过判据和回归档位

全部测试自检 PASS；smoke：DS-01、03–07、11、12、14–17；full：全部。lint 和风格检查 0 告警。
