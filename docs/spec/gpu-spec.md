## 1. 概述

GPU 从 DDR 读取 CPU 准备好的命令列表，在片上渲染目标（颜色、深度、模板）中绘制三角形和屏幕空间四边形，最后把渲染目标写出到 DDR 的 Surface，由 DISP 放大 2 倍显示。2D 精灵是屏幕空间四边形的特例（设计记录 R1′）。

```
媒体 APB 槽 6 ─ APB 异步桥 ─ 寄存器块
                                │
DDR ◄─ mem_xbar P3 ◄─ AXI 异步桥 ─┤
                                ├─ 命令处理 ─┬─ 顶点单元（变换、光照、裁剪、透视）─ 三角形建立 ─┐
                                │            ├─ 对象单元（运动、碰撞）──────────────── 四边形 ─┤
                                │            ├─ 纹理装入 DMA → 纹理 RAM、调色板               │
                                │            └─ 写出单元（后处理抗锯齿）◄─────────┐            │
                                │                                                   │            ▼
                                │            片上渲染目标（颜色、深度、模板）◄─ 像素运算 ◄─ 纹理单元 ◄─ 光栅化
```

- 时钟域：clk_gpu（`gpu-soc-spec.md` 5.1），频率 **[待定]**，开发初值 180 MHz，由 PDS 实测定稿（第 9 节 G-T1）。微结构按 200 MHz 的级数预算设计，150 MHz 为保底（资源闭合设计记录第 4 节）。
- 复位：`rst_gpu_n`（clk_gpu 域同步释放，由 reset_ctrl 产生）。
- 总线：mem_xbar P3（AXI256，经 X9 异步桥）；媒体 APB 槽 6（经 X10 异步桥）；中断接 PLIC 源 13（经 X3）。这三处沿用视觉项目中 NPU 的位置和跨时钟域原语。
- 寄存器块的 ID.TYPE = 6。

## 2. 功能描述

### 2.1 坐标系和渲染目标

- **屏幕**：像素 (x, y)，x 向右、y 向下，像素中心在 (x + 0.5, y + 0.5)。
- **渲染目标**：片上 115200 个像素，宽 × 高为 640 × 180 或 1280 × 90，由 `TGT_CFG` 选择，两者占用同一块片上存储。每个像素有颜色（RGB565）、深度（16 位无符号）、模板（8 位无符号）。
- **渲染目标偏移** `TGT_X0`、`TGT_Y0`：屏幕像素 (x, y) 存放在渲染目标的 (x − TGT_X0, y − TGT_Y0)。只有落在渲染目标内的像素才会被写入。`TGT_X0` 必须是 4 的倍数（软件保证）；`TGT_Y0` 任意。
- **裁剪矩形** `SCISSOR`（屏幕坐标，含左上、不含右下）：矩形外的像素丢弃。
- **视口** `VP_X0`、`VP_Y0`、`VP_W`、`VP_H`（屏幕像素）：裁剪空间到屏幕坐标的映射（2.4）。
- **条带渲染**：软件把一屏分成若干条，每条设置不同的偏移和裁剪、同一个视口，各执行一遍绘制命令并写出。640 × 360 分 2 条 640 × 180，1280 × 720 分 8 条 1280 × 90。对象单元只在第一条推进（`STEP` = 1），其余各条 `STEP` = 0（2.9）。

### 2.2 命令列表

- 软件在 DDR 中准备命令列表（64 B 对齐），写 DESC_BASE、DESC_COUNT，再写 DOORBELL（SoC 7.1、7.2，命令式）。
- 每条命令 32 B。第一个字节是操作码，其余字段见 2.3。字段的位位置由 `rtl/include/regs/gpu.json` 定义（协调者维护）；`tools/gen/regs.py` 由它生成 RTL 的 `edrv32_gpu_regs.vh` 和软件的 `regs/gpu_regs.h`。四边形表、顶点、对象、命中列表、释放列表、调色板项的布局也在该文件中。
- 命令按顺序执行，结果等同于逐条串行执行（GPU 内部可以流水，但不得改变可见结果）。
- 执行完全部命令，并且最后一个写响应返回后，置 IRQ_STAT.DONE、DONE_COUNT 加 1（SoC 7.2）。

### 2.3 命令

| 操作码 | 名称 | 字段 | 行为 |
|---|---|---|---|
| 0x01 | `SET_MATRIX` | 4 × 4 矩阵的 DDR 地址 | 读 16 个 s15.16 数（行优先），作为当前 MVP 矩阵 |
| 0x02 | `SET_LIGHT` | 光照方向（物体空间，3 × s1.14，已归一化）、方向光颜色、环境光颜色（各 RGB888） | 设置当前光照（2.5） |
| 0x03 | `SET_TEX` | 纹理描述符：纹理 RAM 中的偏移、宽高的 log2（3–8）、格式、mipmap 级数（1–9）、调色板组号、取样模式（最近邻／双线性／三线性）、LOD 偏置 | 设置当前纹理（2.6） |
| 0x04 | `SET_PIXEL` | 深度比较、深度写入开关、模板设置、混合方程、颜色写入开关 | 设置当前像素运算状态（2.7） |
| 0x05 | `SET_TARGET` | TGT_X0、TGT_Y0、SCISSOR、VP_X0、VP_Y0、VP_W、VP_H | 设置渲染目标偏移、裁剪矩形和视口（2.1） |
| 0x10 | `CLEAR` | 颜色值、深度值、模板值、三个清除开关 | 把渲染目标中与裁剪矩形相交的部分清成给定值 |
| 0x20 | `DRAW_TRI` | 顶点缓冲 DDR 地址、三角形数 | 绘制三角形列表：每 3 个顶点一个三角形，不使用索引（2.4） |
| 0x21 | `DRAW_QUAD` | 四边形表 DDR 地址、四边形数 | 绘制屏幕空间四边形（2.8） |
| 0x22 | `OBJ_STEP` | 对象表 DDR 地址、对象数、本次是否推进运动、是否绘制 | 推进对象运动、检测碰撞，并把存活对象作为四边形绘制（2.9） |
| 0x30 | `TEX_LOAD` | DDR 源地址、纹理 RAM 目标偏移、字节数 | 把纹理数据装入纹理 RAM（2.6） |
| 0x31 | `PAL_LOAD` | DDR 源地址、调色板组号（0–15）、项数 | 装入调色板 |
| 0x40 | `RESOLVE` | 目标 Surface（基址、跨度，RGB565）、写出区域、是否做后处理抗锯齿、抗锯齿阈值 | 把渲染目标写出到 DDR（2.10） |

未定义的操作码：置 ERROR，ERR_CODE = 1，停止执行（第 6 节）。

### 2.4 顶点单元（硬件几何单元，R7）

**顶点格式**（DDR 中每个顶点 16 B）：

| 字段 | 格式 |
|---|---|
| x、y、z | 各 s16，物体空间 |
| nx、ny、nz | 各 s1.7（s8），法线 |
| u、v | 各 u8.8，以纹素为单位；超出纹理尺寸时环绕 |
| 顶点颜色 | RGB565 |
| 填充 | 1 B |

**每个顶点**：
1. 裁剪空间坐标 (X, Y, Z, W) = MVP × (x, y, z, 1)。矩阵元素 s15.16；四个乘积完整累加后一次舍入到 s23.16（40 位），超出范围时饱和（2.12）。
2. 光照：L = max(0, n · l)，n 为 s1.7、l 为 s1.14，L 保留 21 位小数。每个通道 c = round(c₈ × (A × 2²¹ + L × D) / (255 × 2²¹))，饱和到 255；c₈ 为顶点颜色的 E565 展开值，A、D 为环境光和方向光颜色的该通道。

**每个三角形**：
1. **裁剪**：依次对 W ≥ W_NEAR、X ≥ −G·W、X ≤ G·W、Y ≥ −G·W、Y ≤ G·W 五个平面做多边形裁剪，W_NEAR = 1/16，G = 4；到平面的距离 ≥ 0 为内侧。边 (a, b) 与平面的交点，每个分量（X、Y、Z、W、u、v、三个颜色）= round((a·d_b − b·d_a) / (d_b − d_a))，d 为端点到该平面的距离；这个对称形式使共享边的交点与遍历方向无关。裁剪结果 v0…vn 按扇形 (v0, vi, vi+1) 拆成三角形。
2. **透视除法**：q = 1/W，由倒数单元（2.12）求得，Q30。屏幕坐标为 s12.4（17 位，1/16 像素），一次舍入后饱和到 17 位：
   - sx = 16·VP_X0 + round(8·VP_W·(X·q + 1))
   - sy = 16·VP_Y0 + round(8·VP_H·(1 − Y·q))
   - 深度 = clamp(round(65535·Z·q), 0, 65535)
   式中 X·q、Y·q、Z·q 取精确乘积。
3. **背面剔除**：按屏幕空间的环绕方向，由 SET_PIXEL 中的剔除开关决定是否丢弃背面。

### 2.5 光栅化与属性插值

- **覆盖规则**：在 s12.4 坐标下，对像素中心 p = (16x + 8, 16y + 8) 计算边函数 E(a, b) = (b.x − a.x)(p.y − a.y) − (b.y − a.y)(p.x − a.x)，三角形按面积为正排列。三条边的 E 都 > 0 时覆盖；某条边 E = 0 时，只有左上边算覆盖：屏幕上向上的边（b.y < a.y）和向右的水平边（b.y = a.y 且 b.x > a.x）。面积为 0 的三角形丢弃。
- **属性插值**：三角形建立时为 q、u·q、v·q、深度、R、G、B 各求一个平面（起点值和 x、y 方向的增量），像素上只做定点加法；深度和颜色在屏幕空间线性插值。算术按 2.13 第 1–7、15 条。
- **透视校正（R9）**：每个像素求 w = 1/q，u = u·q × w、v 同理，使用 18 位尾数的归一化算术，结果为 Q8 纹素坐标（2.13 第 8–12 条）。
- **扫描**：按 4 个像素一组（x 为 4 的倍数对齐）扫描。LOD 按屏幕上 2 × 2 对齐的像素组计算（2.13 第 13–14 条），组内未被覆盖的像素同样按平面求值参与计算，但不写出。

### 2.6 纹理（R11、R12）

- **纹理 RAM**：片上 192 KiB，分成两半，各 96 KiB。CPU 可以在 GPU 使用一半时，用 `TEX_LOAD` 装入另一半；软件负责不覆盖正在使用的数据。
- **格式**：

| 编码 | 格式 | 每纹素 |
|---|---|---|
| 0 | I4，4 位调色板索引 | 4 位 |
| 1 | I8，8 位调色板索引 | 8 位 |
| 2 | RGB565 直接色，不透明 | 16 位 |

- **调色板**：16 组 × 256 项，每项 RGB565 + 4 位透明度 A4。A4 = 0 表示透明，像素丢弃（不写颜色、深度、模板）；A4 展开到 8 位为 A4 × 17。I4 使用组内的前 16 项。
- **尺寸**：宽、高都是 2 的幂，8–256。纹理坐标按尺寸环绕。
- **Mipmap**：第 k 级宽 W_k = max(1, W >> k)、高 H_k = max(1, H >> k)。
- **存储布局**：纹理在纹理 RAM 中分块交织存放，使任意位置的 2 × 2 取样足迹落在 4 个不同的存储体上。由工具离线转换，`TEX_LOAD` 按字节线性拷贝。
  - 一个 16 位字是一个纹素块：I4 为 2 × 2 纹素，I8 为 2 × 1，RGB565 为 1 × 1，记块宽高 (bw, bh)。
  - 第 k 级的块网格 Bx = ⌈W_k / bw⌉、By = ⌈H_k / bh⌉，占用 L_k = 8 · ⌈Bx/2⌉ · ⌈By/2⌉ 字节（块网格补齐到 2 × 2 的倍数，补齐的字填 0、不被取样）。
  - 第 k 级起点 P_k = OFFSET + Σ_{j<k} L_j（OFFSET 32 B 对齐）。
  - 纹素 (u, v)（已按 W_k、H_k 环绕）所在块 bx = ⌊u / bw⌋、by = ⌊v / bh⌋，字地址（以 16 位为单位）h = P_k / 2 + 4 · (⌊by/2⌋ · ⌈Bx/2⌉ + ⌊bx/2⌋) + (bx mod 2) + 2 · (by mod 2)。
  - 字内位置：I4 的半字节序号 = (u mod 2) + 2 · (v mod 2)；I8 的字节序号 = u mod 2；RGB565 为整字。
  - 纹理占用 = Σ L_k（全部级）；SET_TEX 的越界检查（第 6 节）按此计算。
- **取样**：u、v 为 Q8 纹素坐标，第 k 级坐标 u_k = ⌊u / 2^k⌋（Q8）、v_k 同理；纹素坐标按 W_k、H_k 环绕。
  - 最近邻：纹素 (⌊u_k / 256⌋, ⌊v_k / 256⌋)。
  - 双线性：u′ = u_k − 128、v′ = v_k − 128（减半个纹素，使纹素中心与取样点对齐），左上纹素 (⌊u′ / 256⌋, ⌊v′ / 256⌋)，fx = u′ mod 256、fy = v′ mod 256。四个纹素的权重为 (256 − fx)(256 − fy)、fx(256 − fy)、(256 − fx)fy、fx·fy，结果 = round(Σ wᵢ tᵢ / 2¹⁶)，R、G、B、A 分别计算。
  - 三线性：在第 l、l + 1 级各做一次双线性，结果 = round((t_l · (256 − f) + t_{l+1} · f) / 256)，f 为 LOD 的小数部分；l 已是最后一级时只做第 l 级。
  - 调色板纹理先查表展开成 RGBA8（E565，A4 × 17），再对非预乘的 RGBA 过滤。
  - LOD：跨度取 2 × 2 像素组内相邻像素 u、v 之差的最大绝对值（纹素/像素，Q16，2.13 第 13–14 条）。LOD = log2(跨度)，Q8：前导 1 的位置给出整数部分，其后 8 位作为索引查表 round(256 · log2(1 + i/256))；跨度为 0 时 LOD = 0。LOD 加偏置（s3.4）后夹到 [0, 级数 − 1]，l = ⌊LOD⌋。最近邻和双线性取第 l 级。同一 2 × 2 像素组内的像素共用 LOD。
- **透明**：取样后的 alpha 为 0 时像素丢弃（2.7 第 2 步）。
- **着色**：像素颜色 = 纹理颜色 × 插值顶点颜色，逐通道 d(t × c)；d 的定义与 RND 2.2 相同。

### 2.7 像素运算（R13）

按以下顺序处理每个被覆盖的像素：

1. 裁剪矩形和渲染目标范围之外：丢弃。
2. 纹理透明（取样后的 alpha = 0）：丢弃。
3. **模板测试**：比较 (ref & mask) 与 (stencil & mask)，函数可选 ALWAYS、NEVER、EQUAL、NOTEQUAL、LESS、LEQUAL、GREATER、GEQUAL。失败时执行 sfail 操作并丢弃。
4. **深度测试**：函数可选 LEQUAL（新深度 ≤ 已有深度通过）或 ALWAYS。失败时执行 zfail 操作并丢弃；通过时执行 zpass 操作，深度写入开关打开时写入新深度。
5. 模板操作：KEEP、ZERO、REPLACE、INCR（饱和）、DECR（饱和）、INVERT；写入受写掩码控制。
6. **混合**：结果 = op(Fs × S, Fd × D)，逐通道 8 位计算，结果饱和到 0–255，再按 P565 截断写回（P565 的定义与 RND 2.2 相同）。
   - 因子 Fs、Fd 可选 0、1、Sa、1 − Sa、S、1 − S、D、1 − D、常数 α、1 − 常数 α。其中 Sa 是像素的透明度：三角形为取样后的 alpha，四边形和对象为 d(纹理 alpha × 全局透明度)；Sa = 0 时不另行丢弃。S、D 是源色和目标色，D 为 E565 展开值。乘法统一用 d()。
   - op 可选 ADD、SUB（S 项 − D 项）、REVSUB（D 项 − S 项）、MIN、MAX。
   - 常用设置：不透明为 (1, 0, ADD)；Alpha 为 (Sa, 1 − Sa, ADD)；叠加发光为 (Sa, 1, ADD)。
7. 颜色写入开关关闭时不写颜色，用于只写模板的阴影体。

### 2.8 屏幕空间四边形（快速通道）

四边形表中每项 16 B：

| 字段 | 格式 |
|---|---|
| x、y | s12，左上角屏幕坐标 |
| 宽、高 | u9，像素 |
| 纹理原点 u0、v0 | u8 |
| 水平、垂直翻转 | 各 1 位 |
| 调色板组号 | 4 位 |
| 全局透明度 | 8 位 |
| 深度 | u16（深度测试用；不测深度时设成任意值） |

- 四边形使用当前的 SET_TEX、SET_PIXEL 状态，只做最近邻取样，纹素与像素一一对应，不缩放。
- 纹理坐标 = (u0 + i, v0 + j)，i、j 为四边形内的列号和行号，翻转时取反向。
- 不经过顶点单元，不做透视。

### 2.9 对象单元（R5）

**对象表**：DDR 中每个对象 32 B。

| 字段 | 格式 | 说明 |
|---|---|---|
| 存活 | 1 位 | 0 表示空槽 |
| 位置 px、py | 各 s16.8 | 屏幕坐标 |
| 速度 vx、vy | 各 s8.8 | 像素/帧 |
| 加速度 ax、ay | 各 s4.12 | 像素/帧² |
| 寿命 | u16 | 帧数，0 表示不限寿命 |
| 碰撞半宽、半高 | 各 u8 | 以位置为中心的碰撞框 |
| 碰撞目标掩码 | 8 位 | 与哪几个目标框检测碰撞 |
| 四边形参数 | — | 宽、高、u0、v0、翻转、调色板组号、全局透明度，与 2.8 相同；绘制位置 = 位置取整 − 半个宽高 |

**`OBJ_STEP`，推进开关 `STEP` = 1**：对每个存活对象，按表的顺序：
1. 推进：v = v + round(a / 16)（加速度从 Q12 舍入到 Q8），按 16 位二补码回绕；p = p + v，按 24 位二补码回绕。寿命不为 0 时减 1，减到 0 后对象失效。
2. 存活区域：⌊p⌋ 不在**存活区域**（寄存器 `OBJ_LIVE_RECT`，含左上、不含右下）内时失效。
3. 碰撞：只对经过第 1、2 步仍存活的对象。碰撞框为 [⌊px⌋ − 半宽, ⌊px⌋ + 半宽) × [⌊py⌋ − 半高, ⌊py⌋ + 半高)，目标框（寄存器 `OBJ_TGT[0..7]`）含左上、不含右下；两个方向都满足 a0 < b1 且 b0 < a1 时命中，边缘接触不算。对掩码中的每个目标按编号递增检查，命中时向**命中列表**追加一项（对象编号、目标编号）。
4. 本次失效的对象，把编号追加到**释放列表**，供 CPU 回收槽位。
5. 写回整条 32 B：只改存活、px、py、vx、vy、寿命，其余字段和保留位保持读入时的值。
6. 绘制开关打开时，仍存活的对象作为四边形绘制（2.8），左上角 = (⌊px⌋ − ⌊宽/2⌋, ⌊py⌋ − ⌊高/2⌋)。

**`STEP` = 0**：只执行第 6 步，即绘制开关打开时绘制存活对象；不推进，不判定存活区域和碰撞，不写列表，不写回表。HIT_COUNT、FREE_COUNT 为 0，ALIVE_COUNT 为存活对象数。

命中列表和释放列表都写在 DDR 中，基址和容量由寄存器给出。列表满时停止追加，并置 STATUS 中的溢出位（第 4 节），计数仍然统计实际数目。

### 2.10 写出与后处理抗锯齿

- `RESOLVE`：把渲染目标中给定区域的颜色，按 RGB565 写到 DDR Surface（Surface 规则见 SoC 7.3，GPU 是生产者）。
- 写出区域 X0、X1 必须是 4 的倍数（软件保证），Y0、Y1 任意；区域行首、行尾不必按 DDR 32 B 对齐。
- 后处理抗锯齿打开时，对每个像素 C 和它上下左右的邻居 N、S、W、E：
  - 亮度 Y = (R8 + 2·G8 + B8) >> 2，R8、G8、B8 是 E565 展开值。
  - 若 max(Y) − min(Y) < 阈值（5 个像素中）：输出 C。
  - 否则：若 |Y_N − Y_S| ≥ |Y_W − Y_E|，判定为水平边，输出 (2C + N + S) >> 2；否则为竖直边，输出 (2C + W + E) >> 2。逐通道计算后按 P565 写回。
  - 邻居取渲染目标中的原值（不取已处理的结果）；区域边界外的邻居取边界像素本身。条带渲染时，条的边界即区域边界。
- 只有执行到 RESOLVE 时才写 DDR；绘制命令不访问 DDR 中的颜色缓冲。

### 2.12 算术约定

- **舍入**：round(a / b) 为最近舍入，正好一半时远离零；右移 n 位的舍入等同 round(a / 2ⁿ)。各节写明的舍入点之外，中间乘加精确扩展、不截断。
- **饱和**：按各节写明的目标位宽饱和；对象的速度和位置按位宽回绕（2.9）。
- **倒数单元**（2.4、2.5 共用）：把正数输入归一化为 m ∈ [1, 2)（Q30）和指数；索引 i = ⌊(m − 1) · 2¹⁰⌋；种子 r₀ = round(2⁶⁰ / m_i)，m_i = 1 + (i + 0.5) / 2¹⁰（Q30）；一次牛顿迭代 t = round(m · r₀ / 2³⁰)，r = round(r₀ · (2³¹ − t) / 2³⁰)；再按指数移位（舍入）恢复量级，输出 Q30。
- **d()、E565、P565**：与 RND 2.2 相同；P565 截断。
- 逐位参考：`tools/gpu/model/`（2.4–2.13 的实现；2.13 在 `planes.py`）。

### 2.13 三角形建立和逐像素算术

记号：R(·) 按 2.12 舍入；未写舍入的中间乘加完整保留，不截断、不饱和、不回绕。依据数值报告 `2026-11-24-model-gpu-numeric-v03.md`（方案 B32/P18）和 `2026-11-25-model-gpu-plane-width.md`（方案 G2：平面精度 G、2 × 2 LOD）。

**平面建立（每个三角形一次）**

1. 屏幕坐标 s12.4、边函数、左上规则、剔除按 2.4、2.5。面积 A 取正（顶点已按面积为正排列）。规范起点 xr = ⌊min sx / 16⌋、yr = ⌊min sy / 16⌋，与条带和裁剪矩形无关。
2. k = ⌊log2 A⌋，m = A / 2^k 按 2.12 归一化到 [1, 2)（Q30），用 2.12 的倒数单元求 r ≈ 2³⁰ / m，每个三角形只求一次；求系数时再乘 2^(−k)，不先把 1/A 舍入到 Q30。
3. 属性按 [深度, q, u·q, v·q, R, G, B] 排列，顶点原始值的小数位 f = [0, 30, 38, 38, 16, 16, 16]。缩放指数 h：q、u·q、v·q 各取 h = bit_length(三个顶点中最大的 |原始值|) − 32（全为 0 时 bit_length = 0）；深度 h = −16；R、G、B h = −8。系数丢弃位数 d = [8, 4, 4, 4, 12, 12, 12]（第 5–7 条）。
4. 顶点缩放值 a_i = R(原始值_i / 2^h)（最多 33 位幅值）；该属性的平面单位为 2^(h − f)，深度即 Q16，颜色即 Q24。
5. 边 (b, c)、(c, a)、(a, b) 依次对应顶点 a、b、c：Dx_i = 16 · (起点.y − 终点.y)，Dy_i = 16 · (终点.x − 起点.x)。完整增量 Gx = R(r · Σ Dx_i · a_i / 2^(30 + k))，Gy 同理用 Dy_i；分子为有符号 56 位，乘 r 后 87 位，Gx、Gy 为有符号 56 位。存储增量 gx = R(Gx / 2^d)、gy = R(Gy / 2^d)。
6. 完整起点值 S = a_a + R(((16·xr + 8 − a.x) · Gx + (16·yr + 8 − a.y) · Gy) / 16)，用未丢位的 Gx、Gy 求，a.x、a.y 为顶点 a 的 s12.4 坐标，a_a 为它的缩放属性；存储起点值 s = R(S / 2^d)。存储的 s、gx、gy 物理单位为 2^(h − f + d)。

**逐像素插值**

7. 像素 (x, y) 的平面值 T = s + (x − xr) · gx + (y − yr) · gy，按属性顺序为有符号 W = [62, 66, 66, 66, 58, 58, 58] 位，单位 2^(h − f + d)。硬件可以逐行、逐组步进（行起点加 gy，lane 之间加 gx，组之间加 4·gx），步进中不舍入、不截断，因此与直接求值逐位相同。

**归一化数和透视校正**

8. N(v, e) 把 v · 2^e 最近舍入为（符号，18 位幅值 M ∈ [2¹⁷, 2¹⁸)，有符号 10 位指数 E）；舍入进位溢出时 M 右移 1 位、E 加 1；0 记为 (+, 0, 0)。两个归一化数相乘：幅值相乘（36 位），符号异或，结果再 N。
9. 两个归一化数相减：任一为 0 时按恒等式；否则 e = max(Ea, Eb) − 3，两数分别 R(M · 2^(E − e)) 对齐（含 3 个保护位）后做有符号 23 位减法，结果再 N。
10. 像素的 q 值 Q = N(T_q, h − f + d)，记符号、幅值 M、指数 E，F = 17。种子索引 i = ⌊(M − 2^F) / 2^(F − 10)⌋，种子 r₀ = R(2^F / (1 + (i + 0.5) / 1024))（1024 项 ROM）。
11. t = R(M · r₀ / 2^F)，r₁ = R(r₀ · (2^(F+1) − t) / 2^F)，w = N(r₁, −2F − E)，w 的符号取 Q 的符号。Q 为 0 时 w = 0。被覆盖的像素 Q 总是正数；负数和 0 只出现在第 13 条中未被覆盖的像素上。
12. U = N(N(T_uq, h − f + d) × w)，V 同理；输出纹理坐标 u = R(U × 256)，有符号 32 位 Q8，不饱和，再按 2.6 环绕。LOD 使用 U、V 的归一化值，不用 Q8 输出。

**LOD（2 × 2 像素组）**

13. 像素组为屏幕坐标 (2i, 2j)、(2i + 1, 2j)、(2i, 2j + 1)、(2i + 1, 2j + 1) 四个像素，其中至少一个被覆盖时整组参与计算。组内每个像素（包括未被覆盖的像素，以及在裁剪矩形和渲染目标之外的像素）都按第 7 条求平面值，再按第 10–12 条求 U、V。
14. 组内四对相邻像素：横向 (2i, 2j)–(2i + 1, 2j)、(2i, 2j + 1)–(2i + 1, 2j + 1)，纵向 (2i, 2j)–(2i, 2j + 1)、(2i + 1, 2j)–(2i + 1, 2j + 1)。每对的 U 差和 V 差按第 9 条相减，绝对值最近舍入为无符号 Q16，八个值中的最大值为跨度。组内像素共用这个跨度，LOD 按 2.6。

**输出**

15. 深度存储单位为 2^−8（Q8），R、G、B 为 2^−12（Q12）；各自最近舍入为整数后，深度夹到 [0, 65535]，R、G、B 夹到 [0, 255]。

## 5. 行为与时序

- **命令边界**：一条命令的全部像素写入渲染目标之后，后续命令的读写才能看到这些像素（2.2 的串行等效）。
- **RESOLVE**：开始写出前，前面所有绘制命令的像素必须已经写入渲染目标。
- **TEX_LOAD 与绘制**：TEX_LOAD 之后的绘制命令看到的是装入后的内容。
- **OBJ_STEP**：命中列表、释放列表、计数寄存器在该命令最后一个写响应返回后才有效。
- **ABORT**：按 SoC 7.1，停止取新命令，等已发出的 AXI 事务完成后回到 IDLE；渲染目标内容不保证。

## 6. 错误处理

| ERR_CODE | 错误 | 检测 | 处理 |
|---|---|---|---|
| 1 | 未定义的操作码 | 命令解码 | 置 ERROR，停止执行 |
| 2 | AXI 错误响应 | RRESP、BRESP 非 OKAY | 置 ERROR，停止执行（已发出的事务照常完成） |
| 3 | 纹理描述符越界 | SET_TEX：纹理（含全部 mipmap 级）超出纹理 RAM | 置 ERROR，停止执行 |
| 4 | TEX_LOAD 越界 | 目标偏移 + 字节数超出纹理 RAM | 置 ERROR，停止执行 |

命中列表和释放列表溢出不是错误，见 2.9。其他检查不做（CLAUDE.md 第 12 节）。
