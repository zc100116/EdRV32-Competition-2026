## 1. 概述

GPU 从 DDR 读取 CPU 准备好的命令列表，在片上渲染目标（颜色、深度、模板）中绘制三角形和屏幕空间四边形，最后把渲染目标写出到 DDR 的 Surface，由 DISP 放大 2 倍显示。2D 精灵是屏幕空间四边形的特例（设计记录 R1′）。

```
媒体 APB 槽 6 ─ APB 异步桥 ─ 寄存器块
                                │
DDR ◄─ mem_xbar P3 ◄─ AXI 异步桥 ─┤
                                ├─ 命令处理 ─┬─ 顶点单元（变换、光照、裁剪、透视）─ 三角形建立 ─┐
                                │            ├─ 对象单元（运动、碰撞）──────────────── 四边形 ─┤
                                │            ├─ 纹理装入 DMA → 纹理 RAM、调色板               │
                                │            └─ 写出单元（后处理抗锯齿）◄─────────┐            │
                                │                                                   │            ▼
                                │            片上渲染目标（颜色、深度、模板）◄─ 像素运算 ◄─ 纹理单元 ◄─ 光栅化
```

- 时钟域：clk_gpu（取代 SoC 规格中的 clk_npu），频率 **[待定]**，开发初值 150 MHz，由 PDS 实测定稿（第 9 节 G-T1）。
- 复位：`rst_gpu_n`（clk_gpu 域同步释放，由 reset_ctrl 产生）。
- 总线：mem_xbar P3（AXI256，经 X9 异步桥）；媒体 APB 槽 6（经 X10 异步桥）；中断接 PLIC 源 13（经 X3）。这三处沿用原 NPU 的位置和跨时钟域原语，SoC 规格的修改见第 9 节。
- 寄存器块的 ID.TYPE = 6。

## 2. 功能描述

### 2.1 坐标系和渲染目标

- **屏幕**：像素 (x, y)，x 向右、y 向下，像素中心在 (x + 0.5, y + 0.5)。
- **渲染目标**：片上一块 640 × 360 的区域，每个像素有颜色（RGB565）、深度（16 位无符号）、模板（8 位无符号）。
- **渲染目标偏移** `TGT_X0`、`TGT_Y0`：屏幕像素 (x, y) 存放在渲染目标的 (x − TGT_X0, y − TGT_Y0)。只有落在渲染目标内的像素才会被写入。
- **裁剪矩形** `SCISSOR`（屏幕坐标，含左上、不含右下）：矩形外的像素丢弃。
- **条带渲染**：软件把一屏分成若干条，每条设置不同的偏移和裁剪，各执行一遍绘制命令并写出，就能得到大于 640 × 360 的画面，例如 1280 × 720 分成 4 条 1280 × 180。渲染目标的宽 × 高可以是 640 × 360 或 1280 × 180，由 `TGT_CFG` 选择，两者占用同一块片上存储。

### 2.2 命令列表

- 软件在 DDR 中准备命令列表（64 B 对齐），写 DESC_BASE、DESC_COUNT，再写 DOORBELL（SoC 7.1、7.2，命令式）。
- 每条命令 32 B。第一个字节是操作码，其余字段见 2.3。字段的位位置由 `rtl/include/gpu_cmd.json` 定义（协调者维护）；RTL 的 localparam 和软件头文件都由它生成。
- 命令按顺序执行，结果等同于逐条串行执行（GPU 内部可以流水，但不得改变可见结果）。
- 执行完全部命令，并且最后一个写响应返回后，置 IRQ_STAT.DONE、DONE_COUNT 加 1（SoC 7.2）。

### 2.3 命令

| 操作码 | 名称 | 字段 | 行为 |
|---|---|---|---|
| 0x01 | `SET_MATRIX` | 4 × 4 矩阵的 DDR 地址 | 读 16 个 s15.16 数（行优先），作为当前 MVP 矩阵 |
| 0x02 | `SET_LIGHT` | 光照方向（物体空间，3 × s1.14，已归一化）、方向光颜色、环境光颜色（各 RGB888） | 设置当前光照（2.5） |
| 0x03 | `SET_TEX` | 纹理描述符：纹理 RAM 中的偏移、宽高的 log2（3–8）、格式、mipmap 级数（1–9）、调色板组号、取样模式（最近邻／双线性／三线性）、LOD 偏置 | 设置当前纹理（2.6） |
| 0x04 | `SET_PIXEL` | 深度比较、深度写入开关、模板设置、混合方程、颜色写入开关 | 设置当前像素运算状态（2.7） |
| 0x05 | `SET_TARGET` | TGT_X0、TGT_Y0、SCISSOR | 设置渲染目标偏移和裁剪矩形（2.1） |
| 0x10 | `CLEAR` | 颜色值、深度值、模板值、三个清除开关 | 把渲染目标中与裁剪矩形相交的部分清成给定值 |
| 0x20 | `DRAW_TRI` | 顶点缓冲 DDR 地址、三角形数 | 绘制三角形列表：每 3 个顶点一个三角形，不使用索引（2.4） |
| 0x21 | `DRAW_QUAD` | 四边形表 DDR 地址、四边形数 | 绘制屏幕空间四边形（2.8） |
| 0x22 | `OBJ_STEP` | 对象表 DDR 地址、对象数、本次是否推进运动、是否绘制 | 推进对象运动、检测碰撞，并把存活对象作为四边形绘制（2.9） |
| 0x30 | `TEX_LOAD` | DDR 源地址、纹理 RAM 目标偏移、字节数 | 把纹理数据装入纹理 RAM（2.6） |
| 0x31 | `PAL_LOAD` | DDR 源地址、调色板组号（0–15）、项数 | 装入调色板 |
| 0x40 | `RESOLVE` | 目标 Surface（基址、跨度，RGB565）、写出区域、是否做后处理抗锯齿、抗锯齿阈值 | 把渲染目标写出到 DDR（2.10） |

未定义的操作码：置 ERROR，ERR_CODE = 1，停止执行（第 6 节）。

### 2.4 顶点单元（硬件几何单元，R7）

**顶点格式**（DDR 中每个顶点 16 B）：

| 字段 | 格式 |
|---|---|
| x、y、z | 各 s16，物体空间 |
| nx、ny、nz | 各 s1.7（s8），法线 |
| u、v | 各 u8.8，以纹素为单位；超出纹理尺寸时环绕 |
| 顶点颜色 | RGB565 |
| 填充 | 1 B |

**每个顶点**：
1. 裁剪空间坐标 (X, Y, Z, W) = MVP × (x, y, z, 1)，定点格式见第 9 节 G-N1。
2. 光照：L = max(0, n · l)；顶点颜色 c = 顶点颜色 × (环境光 + L × 方向光颜色)，逐通道饱和到 255。

**每个三角形**：
1. **裁剪**：对近平面 W ≥ W_NEAR 和保护带 |X| ≤ G·W、|Y| ≤ G·W 共 5 个平面做多边形裁剪，属性线性插值。裁剪结果按扇形拆成三角形。W_NEAR 和 G 的取值为 **[待定]**（G-N2）。
2. **透视除法**：q = 1/W；屏幕坐标 = 视口变换 (X·q, Y·q)，格式 s12.4（1/16 像素）；深度 = Z·q 映射到 u16。
3. **背面剔除**：按屏幕空间的环绕方向，由 SET_PIXEL 中的剔除开关决定是否丢弃背面。

### 2.5 光栅化与属性插值

- **覆盖规则**：像素中心在三角形内时覆盖；中心正好落在边上时，按左上规则处理。
- **透视校正（R9）**：在屏幕空间对 u·q、v·q、q 线性插值；每个像素求 w = 1/q，再得 u、v。深度和顶点颜色在屏幕空间线性插值。
- **扫描**：按 4 个像素一组（x 为 4 的倍数对齐）逐行扫描。

### 2.6 纹理（R11、R12）

- **纹理 RAM**：片上 256 KB **[待定]**（G-R1），分成两半。CPU 可以在 GPU 使用一半时，用 `TEX_LOAD` 装入另一半；软件负责不覆盖正在使用的数据。
- **格式**：

| 编码 | 格式 | 每纹素 |
|---|---|---|
| 0 | I4，4 位调色板索引 | 4 位 |
| 1 | I8，8 位调色板索引 | 8 位 |
| 2 | RGB565 直接色，不透明 | 16 位 |

- **调色板**：16 组 × 256 项，每项 RGB565 + 4 位透明度 A4。A4 = 0 表示透明，像素丢弃（不写颜色、深度、模板）；A4 展开到 8 位为 A4 × 17。I4 使用组内的前 16 项。
- **尺寸**：宽、高都是 2 的幂，8–256。纹理坐标按尺寸环绕。
- **Mipmap**：第 k 级的尺寸是第 0 级的 1/2^k，最小为 1。各级在纹理 RAM 中按级数顺序连续存放。
- **取样**：
  - 最近邻：取包含 (u, v) 的纹素。
  - 双线性：取周围 4 个纹素，按 u、v 的小数部分加权，权重 8 位。
  - 三线性：在相邻两级上各做一次双线性，再按 LOD 的小数部分混合。
  - LOD = log2(每像素纹素跨度的最大值) + 偏置，跨度由 u、v 对 x、y 的偏导数和 w 求得；log2 的近似方法和精度为 **[待定]**（G-N3）。最近邻和双线性模式下，按 LOD 取整选一级。
- **着色**：像素颜色 = 纹理颜色 × 插值顶点颜色，逐通道 d(t × c)；d 的定义与 RND 2.2 相同。

### 2.7 像素运算（R13）

按以下顺序处理每个被覆盖的像素：

1. 裁剪矩形和渲染目标范围之外：丢弃。
2. 纹理透明（A4 = 0）：丢弃。
3. **模板测试**：比较 (ref & mask) 与 (stencil & mask)，函数可选 ALWAYS、NEVER、EQUAL、NOTEQUAL、LESS、LEQUAL、GREATER、GEQUAL。失败时执行 sfail 操作并丢弃。
4. **深度测试**：函数可选 LEQUAL（新深度 ≤ 已有深度通过）或 ALWAYS。失败时执行 zfail 操作并丢弃；通过时执行 zpass 操作，深度写入开关打开时写入新深度。
5. 模板操作：KEEP、ZERO、REPLACE、INCR（饱和）、DECR（饱和）、INVERT；写入受写掩码控制。
6. **混合**：结果 = op(Fs × S, Fd × D)，逐通道 8 位计算，结果饱和到 0–255，再按 P565 截断写回（P565 的定义与 RND 2.2 相同）。
   - 因子 Fs、Fd 可选 0、1、Sa、1 − Sa、S、1 − S、D、1 − D、常数 α、1 − 常数 α。其中 Sa 是像素的透明度（纹理 A4 × 17 乘以四边形或对象的全局透明度），S、D 是源色和目标色。乘法统一用 d()。
   - op 可选 ADD、SUB（S 项 − D 项）、REVSUB（D 项 − S 项）、MIN、MAX。
   - 常用设置：不透明为 (1, 0, ADD)；Alpha 为 (Sa, 1 − Sa, ADD)；叠加发光为 (Sa, 1, ADD)。
7. 颜色写入开关关闭时不写颜色，用于只写模板的阴影体。

### 2.8 屏幕空间四边形（快速通道）

四边形表中每项 16 B：

| 字段 | 格式 |
|---|---|
| x、y | s12，左上角屏幕坐标 |
| 宽、高 | u9，像素 |
| 纹理原点 u0、v0 | u8 |
| 水平、垂直翻转 | 各 1 位 |
| 调色板组号 | 4 位 |
| 全局透明度 | 8 位 |
| 深度 | u16（深度测试用；不测深度时设成任意值） |

- 四边形使用当前的 SET_TEX、SET_PIXEL 状态，只做最近邻取样，纹素与像素一一对应，不缩放。
- 纹理坐标 = (u0 + i, v0 + j)，i、j 为四边形内的列号和行号，翻转时取反向。
- 不经过顶点单元，不做透视。

### 2.9 对象单元（R5）

**对象表**：DDR 中每个对象 32 B。

| 字段 | 格式 | 说明 |
|---|---|---|
| 存活 | 1 位 | 0 表示空槽 |
| 位置 px、py | 各 s16.8 | 屏幕坐标 |
| 速度 vx、vy | 各 s8.8 | 像素/帧 |
| 加速度 ax、ay | 各 s4.12 | 像素/帧² |
| 寿命 | u16 | 帧数，0 表示不限寿命 |
| 碰撞半宽、半高 | 各 u8 | 以位置为中心的碰撞框 |
| 碰撞目标掩码 | 8 位 | 与哪几个目标框检测碰撞 |
| 四边形参数 | — | 宽、高、u0、v0、翻转、调色板组号、全局透明度，与 2.8 相同；绘制位置 = 位置取整 − 半个宽高 |

**`OBJ_STEP`**：对每个存活对象，按表的顺序：
1. 推进开关打开时：v += a；p += v；寿命不为 0 时减 1，减到 0 后对象失效（存活位清 0）。
2. 位置离开**存活区域**（寄存器 `OBJ_LIVE_RECT`）时失效。
3. 对掩码中每个目标框（寄存器 `OBJ_TGT[0..7]`，屏幕坐标矩形）检查碰撞框是否重叠；重叠时向**命中列表**追加一项（对象编号、目标编号）。
4. 本次失效的对象，把编号追加到**释放列表**，供 CPU 回收槽位。
5. 推进开关打开时，把更新后的对象写回表中。
6. 绘制开关打开时，存活对象作为四边形绘制（2.8）。

命中列表和释放列表都写在 DDR 中，基址和容量由寄存器给出。列表满时停止追加，并置 STATUS 中的溢出位（第 4 节），计数仍然统计实际数目。

### 2.10 写出与后处理抗锯齿

- `RESOLVE`：把渲染目标中给定区域的颜色，按 RGB565 写到 DDR Surface（Surface 规则见 SoC 7.3，GPU 是生产者）。
- 后处理抗锯齿打开时，对每个像素 C 和它上下左右的邻居 N、S、W、E：
  - 亮度 Y = (R8 + 2·G8 + B8) >> 2，R8、G8、B8 是 E565 展开值。
  - 若 max(Y) − min(Y) < 阈值（5 个像素中）：输出 C。
  - 否则：若 |Y_N − Y_S| ≥ |Y_W − Y_E|，判定为水平边，输出 (2C + N + S) >> 2；否则为竖直边，输出 (2C + W + E) >> 2。逐通道计算后按 P565 写回。
  - 区域边界外的邻居取边界像素本身。
- 只有执行到 RESOLVE 时才写 DDR；绘制命令不访问 DDR 中的颜色缓冲。

## 3. 接口

GPU 顶层只有标准接口。

| 信号组 | 方向 | 时钟域 | 说明 |
|---|---|---|---|
| `clk_gpu_i`、`rst_gpu_n_i` | in | — | 时钟和同步释放的复位 |
| `m_axi_*` | — | clk_gpu | AXI256 主口（SoC 4.2），经 X9 异步桥接 mem_xbar P3；只发 INCR 突发 |
| `s_apb_*` | — | clk_gpu | APB 从口（SoC 4.3），经 X10 异步桥接媒体 APB 槽 6 |
| `irq_o` | out | clk_gpu | 电平中断，IRQ_STAT 与 IRQ_EN 按位与后取或；经 X3 同步后接 PLIC 源 13 |

## 4. 寄存器

公共寄存器 0x000–0x07C 按 SoC 7.1。私有寄存器：

| 偏移 | 名称 | 访问 | 复位值 | 说明 |
|---|---|---|---|---|
| 0x100 | TGT_CFG | RW | 0 | bit0：0 = 640 × 360，1 = 1280 × 180 |
| 0x110 | OBJ_LIVE_RECT0 | RW | 0 | [15:0] x0（s16），[31:16] y0 |
| 0x114 | OBJ_LIVE_RECT1 | RW | 0 | [15:0] x1，[31:16] y1（不含） |
| 0x118 | OBJ_HIT_BASE | RW | 0 | 命中列表 DDR 地址，32 B 对齐 |
| 0x11C | OBJ_HIT_MAX | RW | 0 | 命中列表容量（项） |
| 0x120 | OBJ_HIT_COUNT | RO | 0 | 上一次 OBJ_STEP 的命中总数（含溢出未写入的） |
| 0x124 | OBJ_FREE_BASE | RW | 0 | 释放列表 DDR 地址，32 B 对齐 |
| 0x128 | OBJ_FREE_MAX | RW | 0 | 释放列表容量 |
| 0x12C | OBJ_FREE_COUNT | RO | 0 | 上一次 OBJ_STEP 的释放总数 |
| 0x130 | OBJ_ALIVE_COUNT | RO | 0 | 上一次 OBJ_STEP 后的存活对象数 |
| 0x134 | OBJ_STAT | RO | 0 | bit0 命中列表溢出，bit1 释放列表溢出（下一次 OBJ_STEP 开始时清零） |
| 0x140–0x17C | OBJ_TGT[0..7] | RW | 0 | 每个目标框两个字：{y0, x0}、{y1, x1}，s16 |

**PERF**（公共 PERF[0..15]）：0 总忙周期；1 顶点数；2 绘制的三角形数（裁剪、剔除后）；3 四边形数（含对象）；4 写入的像素数；5 纹理存储体冲突停顿周期；6 DDR 读等待周期；7 写出周期；8 对象单元周期；其余读为 0。

## 5. 行为与时序

- **命令边界**：一条命令的全部像素写入渲染目标之后，后续命令的读写才能看到这些像素（2.2 的串行等效）。
- **RESOLVE**：开始写出前，前面所有绘制命令的像素必须已经写入渲染目标。
- **TEX_LOAD 与绘制**：TEX_LOAD 之后的绘制命令看到的是装入后的内容。
- **OBJ_STEP**：命中列表、释放列表、计数寄存器在该命令最后一个写响应返回后才有效。
- **ABORT**：按 SoC 7.1，停止取新命令，等已发出的 AXI 事务完成后回到 IDLE；渲染目标内容不保证。

## 6. 错误处理

| ERR_CODE | 错误 | 检测 | 处理 |
|---|---|---|---|
| 1 | 未定义的操作码 | 命令解码 | 置 ERROR，停止执行 |
| 2 | AXI 错误响应 | RRESP、BRESP 非 OKAY | 置 ERROR，停止执行（已发出的事务照常完成） |
| 3 | 纹理描述符越界 | SET_TEX：纹理（含全部 mipmap 级）超出纹理 RAM | 置 ERROR，停止执行 |
| 4 | TEX_LOAD 越界 | 目标偏移 + 字节数超出纹理 RAM | 置 ERROR，停止执行 |

命中列表和释放列表溢出不是错误，见 2.9。其他检查不做（CLAUDE.md 第 12 节）。

## 7. 性能与资源指标

测量条件：clk_gpu 150 MHz，DDR 为 SoC 仿真模型的默认延迟。数值为开发目标，最终按 PDS 和上板数据定稿（G-P1）。

| 项 | 指标 |
|---|---|
| 四边形：16 × 16，I4，最近邻，Alpha 混合，无深度测试 | 稳态每个不超过 80 个周期（对应 60 fps 下约 3 万个，设计记录 2D 估算第 3 节） |

## 8. 验证要点

参考模型：Python 逐位参考模型（`tools/gpu/model/`），输入同一份命令列表和 DDR 镜像，输出渲染目标、写出的 Surface、对象表、命中列表、释放列表，与 RTL 逐位比对。

必须覆盖：
1. 每条命令的每个字段；未定义操作码和 6 中的每种错误。
2. 覆盖规则：共享边、共享顶点的三角形不漏画、不重画；退化三角形；完全在屏外、跨越近平面、跨越保护带的三角形。
3. 透视校正、顶点光照、三种取样模式、mipmap 每一级、LOD 偏置。
4. 像素运算：模板 8 种函数、6 种操作、读写掩码；深度两种函数、写入开关；混合全部因子和运算；颜色写入开关；透明丢弃。
5. 4 像素组起点不对齐、跨裁剪矩形、跨渲染目标边界；重叠绘制时同一个字的连续读改写。
6. 条带渲染：1280 × 720 分 4 条的结果与一次性参考结果一致。
7. 对象单元：推进、寿命到期、离开存活区域、8 个目标框的碰撞、两个列表的溢出和计数。
8. RESOLVE：抗锯齿开关、区域边界。
9. 性能：第 7 节各项。
10. ABORT 后没有未完成的 AXI 事务。
