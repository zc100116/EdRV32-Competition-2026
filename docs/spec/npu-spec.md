## 1. 概述

NPU 是命令式引擎（SoC 规格 7.2）：软件在 DDR 中准备描述符表、模型镜像（权重和量化参数）和工作区，写门铃后 NPU 依次执行全部描述符，完成后置 `IRQ_STAT.DONE`。第一版面向 YOLOv8n、640×384 输入的固定网络，每个描述符执行一个算子。

| 项 | 规定 |
|---|---|
| SoC 位置 | DDR 主口为 mem_xbar 端口 P3（BE，尽力而为）；寄存器在媒体 APB 槽 6；中断为 PLIC 源 13 |
| 时钟域 | 计算、DMA 和寄存器块都在 `clk_npu`。频率 150 MHz（N-W2 独立工程 PDS 实测 slow WNS +0.214 ns；整 SoC PDS 时复查） |
| 跨时钟域 | 只在边界：AXI256 主口经 `axi_async_bridge` 到 clk_mem；媒体 APB 经 `apb_async_bridge` 从 clk_mem 进入；中断为 clk_npu 域电平，由 PLIC 入口同步 |
| 算力 | 512 个 INT8 MAC/周期（32 输出通道 × 8 输入通道 × 2 像素），256 个 APM |
| 精度 | INT8 权重和激活，INT32 累加，每输出通道量化 |

## 2. 功能描述

### 2.1 算子

| 算子 | 规定 |
|---|---|
| CONV | 1×1 或 3×3；步长 1 或 2；3×3 时四周补零 1 像素，1×1 不补零。输出后依次做 2.3 的量化、可选的激活查表、可选的融合残差加 |
| POOL | 5×5 最大池化，步长 1，四周补 INT8 最小值（−128）2 像素，输出尺寸等于输入尺寸（SPPF） |
| UPSAMPLE | 2× 最近邻放大：每个源像素在水平和垂直方向各复制一次 |
| 通道拼接 | 不是算子：拼接的各部分在 WORK 区中按相同的平面跨距连续分配，消费方把它们当成一个特征图读取（零拷贝） |
| 逐元素加 | 只以 CONV 的融合残差加形式出现（描述符 `RES_EN`），没有独立的加法描述符 |

### 2.2 特征图布局

| 格式 | 布局 |
|---|---|
| INT8_C16（中间特征图、检测头输出） | 按 16 通道分成平面：`[C16 平面][行][像素对]`。一个 256 位 beat 存 2 个相邻像素 × 16 通道，低 128 位是左像素，每个像素内通道 0 在最低字节。行跨距 = 宽度 / 2 × 32 B；平面跨距由描述符给出，必须是 32 B 的整数倍 |
| INT8_C4（首层输入） | `[行][像素]`，每像素 4 字节 `{0, B, G, R}`（R 在最低字节），一个 beat 8 个像素；行跨距 = 宽度 × 4 B |

所有特征图的宽度必须是偶数；CONV 的输入宽度必须是 4 的倍数；`IN_C4 = 1` 时输入宽度必须是 8 的倍数（INT8_C4 行跨距 = IN_W × 4 B，须满足 SoC 规格 7.3 的 32 B stride 规则），由离线工具保证，NPU 不检查。同一条描述符的输入区和残差源区不得与它的输出区重叠，由离线工具保证；重叠时结果未定义，NPU 不检查。通道数不是 16 的整数倍时，末平面中无效通道的值为 0（由上一层的量化参数保证：权重、bias 为 0，零点为 0）。

### 2.3 量化与激活

对每个输出通道 `c`，累加和 `acc`（INT32）按下式转成 INT8：

```
t = (acc + bias[c]) × mult[c]                    // bias INT32，mult 有符号 16 位
u = (t + (shift[c] > 0 ? 1 << (shift[c] − 1) : 0)) >> shift[c]   // 算术右移，shift 0–47
q = clamp(u + zp, −128, 127)                      // zp 为该层输出零点（INT8）
y = LUT_EN ? lut[q 视为 8 位无符号下标] : q          // 256 项 INT8 激活表（SiLU 等）
```

中间运算不截断：`acc + bias` 为 33 位有符号数，乘 `mult` 后为 49 位有符号数，舍入和算术右移在 49 位上进行，加零点后再饱和；`mult` 可以为负。

融合残差加（`RES_EN = 1`）在 `y` 之后：`out = clamp(y + r − zp, −128, 127)`，其中 `r` 是残差源同位置的值；两个操作数和输出使用同一尺度和零点（由离线工具保证）。

### 2.4 执行模型

1. 软件写 `MODEL_BASE`、`WORK_BASE`、`INPUT_BASE`、`OUTPUT_BASE`、`DESC_BASE`、`DESC_COUNT`，再写 `DOORBELL`。
2. NPU 按顺序读取并执行 `DESC_COUNT` 条描述符。前一条描述符的全部写响应返回之后，后一条描述符才读取它的输出（层间依赖以写响应为栅栏，SoC 规格 4.2）。在不违反这一依赖的前提下，NPU 可以提前读取后续描述符、权重和量化参数。
3. 全部描述符执行完、最后一个写响应返回后，`DONE_COUNT` 加 1，置 `IRQ_STAT.DONE`。
4. 每帧软件只需更新 `INPUT_BASE`（VIN 输入环形缓冲中最新的一帧）和 `OUTPUT_BASE`（检测头输出双缓冲），描述符表和模型镜像不变。

### 2.5 离线工具

描述符表、权重镜像和量化参数由 `tools/npu/` 的离线编译工具从 YOLOv8n 配置和量化结果生成。描述符中的派生量（块数、跨距、行槽基址等）由工具预先算好；NPU 不检查这些派生量与形状字段是否自洽（只做第 6 节列出的检查）。权重镜像按第 4.3 节的格式排列。

## 4. 寄存器

公共寄存器 0x000–0x07C 见 SoC 规格 7.1：`ID` = 0x0006_0001（模块类型码 6，等于媒体 APB 槽号）；`CTRL.START` 和 `IRQ_STAT.FRAME` 不使用；命令式引擎用 `DESC_BASE`、`DESC_COUNT`、`DOORBELL`、`DONE_COUNT`。

公共寄存器的行为：
- 复位值按 SoC 规格 7.1（`ID` 见上，`STATUS` 复位为 0x2（IDLE），其余为 0）。
- `CTRL.ENABLE` 不门控 `DOORBELL`。`STATUS.BUSY` = 1 时写 `DOORBELL` 被忽略。
- `CTRL.SOFT_RST` 只在 IDLE 时生效，把寄存器块的全部寄存器（含 ENABLE、IRQ_EN、DESC_BASE、DESC_COUNT、各基址寄存器、DONE_COUNT、PERF）和控制状态恢复到复位值；片上存储内容不清除。`CTRL.ABORT`、`CTRL.SOFT_RST` 等触发位读出为 0。
- 未定义的偏移读出 0，写入被忽略。`apb_pstrb_i` 被忽略，每次写都按完整 32 位处理。

私有寄存器：

| 偏移 | 名称 | 访问 | 复位值 | 说明 |
|---|---|---|---|---|
| 0x100 | MODEL_BASE | RW | 0 | 模型镜像（权重、量化参数、激活表）基址，4 KiB 对齐 |
| 0x104 | WORK_BASE | RW | 0 | 中间特征图工作区基址，4 KiB 对齐 |
| 0x108 | INPUT_BASE | RW | 0 | 首层输入（INT8_C4）基址，4 KiB 对齐 |
| 0x10C | OUTPUT_BASE | RW | 0 | 检测头输出区基址，4 KiB 对齐 |
| 0x110 | CUR_DESC | RO | 0 | 正在执行的描述符序号；出错时保持为出错的那一条；正常完成后保持为 `DESC_COUNT`−1，直到下一次 `DOORBELL` |

`PERF[0..15]`（0x040–0x07C）**[待定]** 开发初值：0 总周期、1 MAC 有效拍、2 读 beat 数、3 写 beat 数、4 输入行等待拍、5 权重/参数装载等待拍、6 写响应等待拍、7 非卷积算子拍；每次 `DOORBELL` 清零。

基址寄存器在 `STATUS.BUSY = 1` 时被写入，行为未定义；软件必须在 DONE 之后才改写。

### 4.1 描述符

定长 64 B（2 个 256 位 beat），按 64 B 对齐，`DESC_BASE + n × 64` 为第 n 条。字段按 32 位字编号，字内低位在前：

| 字 | 位 | 字段 | 说明 |
|---|---|---|---|
| 0 | [3:0] | `OP` | 0 CONV，1 POOL，2 UPSAMPLE，其他值非法 |
| 0 | [4] | `K3` | CONV：1 为 3×3，0 为 1×1 |
| 0 | [5] | `S2` | CONV：1 为步长 2 |
| 0 | [6] | `LUT_EN` | CONV：使用激活表 |
| 0 | [7] | `RES_EN` | CONV：融合残差加 |
| 0 | [8] | `IN_C4` | CONV：输入为 INT8_C4（首层） |
| 0 | [9] | `HALF_TAIL` | CONV：最后一个 C32 输出块只有 16 个有效通道，该块只写一个 C16 平面；`IN_C4 = 0` 时该块按半块模式执行（5.1），`IN_C4 = 1` 时按普通块执行。`HALF_TAIL` 与 `IN_C4` 可以同时为 1（首层 Cout = 16） |
| 0 | [13:12] | `IN_SEL` | 输入基址选择：0 MODEL，1 WORK，2 INPUT，3 OUTPUT |
| 0 | [15:14] | `OUT_SEL` | 输出基址选择，编码同上 |
| 0 | [17:16] | `RES_SEL` | 残差源基址选择，编码同上 |
| 1 | [31:0] | `IN_OFFSET` | 输入相对基址的偏移，32 B 对齐 |
| 2 | [31:0] | `IN_PLANE_STRIDE` | 输入平面跨距（字节）；INT8_C4 时为 0 |
| 3 | [31:0] | `OUT_OFFSET` | 输出偏移 |
| 4 | [31:0] | `OUT_PLANE_STRIDE` | 输出平面跨距 |
| 5 | [31:0] | `RES_OFFSET` | 残差源偏移；残差源平面跨距等于输出平面跨距 |
| 6 | [31:0] | `WEIGHT_OFFSET` | 权重相对 MODEL_BASE 的偏移 |
| 7 | [31:0] | `QUANT_OFFSET` | 量化参数和激活表相对 MODEL_BASE 的偏移 |
| 8 | [11:0] / [27:16] | `IN_W` / `IN_H` | 输入宽、高（像素） |
| 9 | [11:0] / [27:16] | `OUT_W` / `OUT_H` | 输出宽、高（像素） |
| 10 | [5:0] | `CIN_BLOCKS` | 输入 C16 平面数（IN_C4 时为 1） |
| 10 | [11:8] | `COUT_BLOCKS` | CONV：C32 输出块数 |
| 10 | [23:16] | `OUT_ZP` | 输出零点（INT8） |
| 11 | [10:0] | `ROW_SLOT_BEATS` | 每个行槽在行缓存**每个 bank** 中占用的项数 = `CIN_BLOCKS × IN_W / 4`（IN_C4 时 CIN_BLOCKS = 1） |
| 11 | [26:16] | `K_COUNT` | CONV：普通块每个像素对的归约拍数 = `IN_C4 ? J : 2 × CIN_BLOCKS × J`，J = K3 ? 9 : 1；半块模式的块为 K_COUNT / 2 |
| 12 | [19:0] | `WEIGHT_BLOCK_BYTES` | CONV：普通 C32 输出块的权重字节数 = 256 × K_COUNT（半块模式的尾块实际只占一半，见 4.3） |
| 13–15 | — | 预留 | 写 0，NPU 忽略 |

**[待定]** 位域布局为开发初值，RTL 开发中如需调整，经协调者确认后在本节修改。

### 4.2 模型镜像中的量化参数

每个 C32 输出块一份 512 B 记录，位于 `MODEL_BASE + QUANT_OFFSET + 块号 × 512`：

| 偏移 | 内容 |
|---|---|
| 0–255 | 32 个通道各 8 B：`[31:0]` bias（INT32），`[47:32]` mult（有符号 16 位），`[53:48]` shift（0–47），其余为 0 |
| 256–511 | 256 项激活表（每项 INT8）；`LUT_EN = 0` 时内容无意义 |

### 4.3 模型镜像中的权重

每个 CONV 描述符的权重从 `MODEL_BASE + WEIGHT_OFFSET` 开始连续存放，按 256 B 一行（一个归约拍的 32 输出 × 8 输入 INT8 权重，字节 `8 × oc + k8` 对应物理输出通道 oc、输入 k8）。输出块 b 从 `b × WEIGHT_BLOCK_BYTES` 开始；只有最后一块可能紧缩，所以整层长度 = `(COUT_BLOCKS − 1) × WEIGHT_BLOCK_BYTES + 最后块实际字节`。无效通道的权重为 0。

| 块类型 | 行号 r 的含义 | 行内字节 `j` | 对应权重 W[cout, cin, ky, kx] |
|---|---|---|---|
| 普通块 | `r = ((ky × kernel + kx) × CIN_BLOCKS + c16) × 2 + h` | `j = 8 × oc + k8`，oc 0..31 | `W[32b + oc, 16 × c16 + 8h + k8, ky, kx]` |
| 半块模式尾块（HALF_TAIL = 1、IN_C4 = 0） | `r = (ky × kernel + kx) × CIN_BLOCKS + c16` | `j = 8 × (16h + c) + k8`，c 0..15 | `W[32b + c, 16 × c16 + 8h + k8, ky, kx]` |
| 首层（IN_C4 = 1） | `r = ky × 3 + kx` | `j = 8 × oc + k8` | k8 < 4 时 `W[32b + oc, k8, ky, kx]`（第 4 输入为固定 0 通道），k8 ≥ 4 为 0 |

每个字节为 INT8 补码，字节在 DDR 中按地址递增。容量检查（第 6 节）按 `COUT_BLOCKS × WEIGHT_BLOCK_BYTES` 计算，不因尾块紧缩放宽。设计记录 `2026-10-27-npu-datapath.md` 4.7 有逐字节的例子。量化参数记录的第 7 字节（旧工程的零点）必须为 0，零点只来自描述符 `OUT_ZP`。

## 5. 行为与时序

### 5.1 CONV 的调度

以下调度是第一版的性能结构（设计记录 Q4），RTL 应按此实现；实现中如有更好的等效做法，经协调者确认后可以替换。

| 项 | 规定 |
|---|---|
| 循环顺序 | 外层按输出行，内层按 C32 输出块：一行输入在行缓存中被该层全部输出块共用，每层输入只从 DDR 读一遍（W4b） |
| 权重和参数常驻 | 一层的全部权重、全部输出块的量化参数和激活表在本层开始时按输出块顺序装入片上并常驻到本层结束；输出块 0 装完即可开始第一输出行的计算，后续块直接写入最终位置，计算某块之前它的权重、参数和激活表必须已装完（W3） |
| 输入行预取 | 计算当前输出行时预取后续输出行需要的输入行（W1）；只有每层开头的首批输入行需要等待 |
| 写响应 | 行尾不等待写响应，只在描述符结束时等待最后一个写响应（W2） |
| 首层 | `IN_C4 = 1` 时直接读 INT8_C4，3×3×4 通道（含 1 个零通道）作为归约维度，不再补到 C16（W5）；每个 DDR beat（8 像素）在行缓存中展开为 4 项，每项 2 像素 |
| 融合残差加 | `RES_EN = 1` 时，写回前读入残差源同位置的数据并相加（W6） |
| 半块模式 | `HALF_TAIL = 1` 且 `IN_C4 = 0` 时，最后一个输出块的 32 路输出通道分成两半，各处理同一 C16 中的一个 C8，两半部分和相加，归约拍数减半（D2） |
| 供数方式 | 阵列直接从行缓存按滑动窗口取数，不做显式 im2col；每拍处理一个 (ky, kx, C16 组, C8 半块)，同时服务两个输出像素；连续像素对之间没有填充空拍（D3b） |

### 5.2 片上存储

| 存储 | 容量 | 用途 |
|---|---|---|
| 行缓存 | 64 KiB，2 bank × 1024 × 256 位，像素对按奇偶分 bank | 3×3 五个行槽、1×1 两个行槽；约束 `5 × ROW_SLOT_BEATS ≤ 1024`（3×3）、`2 × ROW_SLOT_BEATS ≤ 1024`（1×1），ROW_SLOT_BEATS 为每 bank 项数 |
| 常驻权重 | 288 KiB 逻辑容量（最大层 L7 为 294,912 B），8 bank × 1152 × 256 位，每拍读 2048 位 | W4b/W3 |
| 量化参数 | 8 块 × 32 通道 × 64 位，按通道分 8 bank | W4b/W3 |
| 激活表 | 8 块 × 256 × 8 位，4 份副本（量化 4 路并行查表） | W4b/W3 |
| 残差读缓冲 | 1 KiB（两个 16 项半区） | W6 |
| 结果缓冲 | 32 个像素对 × 512 位（容纳全部在途结果和一个交给写 DMA 的 16 像素对块） | 5.4 第 2 条 |
| 非卷积暂存 | POOL 输入平面 120 × 256 位、POOL/UPSAMPLE 共用行暂存 20 × 256 位 | 5.3 |

大容量存储应使用 DRM；只用 32 项的量化参数、残差读缓冲、结果缓冲使用分布式 RAM（v0.6）。PDS 实测（N-W2，v0.6 之前）：CONV 数据通路 148 DRM，非卷积暂存 8 DRM，AXI 异步桥写 FIFO 1 DRM，合计 157 DRM；v0.6 估算 129 DRM（量化 −8、残差 −4、结果 −8、激活表 −8）**[待定]**，以 PDS 实测回填。

### 5.3 POOL 和 UPSAMPLE

- POOL：每个 C16 平面独立处理，输入平面最大 20×12；采样循环流水化，每拍处理一个采样（5×5 窗口的一个位置，16 通道并行比较），连续采样之间没有空拍。
- UPSAMPLE：每条源行读一次、写两条输出行；输入宽度最大 40。
- POOL 和 UPSAMPLE 与 CONV 串行执行（同一时刻只执行一条描述符）。

### 5.4 时序设计（推荐）

本节是推荐做法，实现者有依据时可以调整，调整写入设计记录。

1. 主数据通路流水级 **[待定]**（开发初值，细节见设计记录 2026-10-27-npu-datapath 4.3）：

| 级 | 内容 |
|---|---|
| A1 | 窗口地址生成：循环计数逐拍累加，地址路径上不做乘法 |
| A2–A3 | 行缓存读、常驻权重读（DRM 输出寄存器） |
| A4–A5 | 取像素、取 C8/C16 半块；激活复制到各 APM 列 |
| M1–M2 | APM 乘法（APM 内部 X/Y 和 MULT 寄存器） |
| C1–C8 | 8 路归约：每个物理输出通道的 8 个输入项在 APM 内用 SIMD 级联累加（`GTP_APM_E2` `USE_SIMD=1`、`USE_POSTADD=1`，第 k 级 Z 取前一级 `CPO`，每级 1 拍），第 k 项的激活和权重晚 k 拍进入；归约不经过 LUT（设计记录 2026-10-30-npu-apm-cascade） |
| R4 | 半块两半相加 1 拍（普通块同样经过此级以对齐延迟） |
| ACC | 累加 |
| Q0–Q12 | 量化：4 路分时复用（8 APM），每个像素对的 64 个值（单平面块 32 个）分 16 组（8 组）依次通过；acc + bias、乘 mult（每路 2 个 APM）、舍入、移位、加零点饱和、激活表（DRM 读 2 拍）。级数按实现更新 **[待定]** |
| WB1–WB2 | 残差加、打包写入结果缓冲 |

最后一个归约项从 A1 到写入结果缓冲：双平面块 29 拍、单平面块 27 拍（v0.4 的 LUT 归约结构）；改为 APM 级联后按实现更新 **[待定]**，开发初值为各 +5 拍。下一个输出块、下一输出行的发射只受结果缓冲空位约束，层内不因切换输出块或输出行而排空流水；流水尾部只在描述符结束时暴露一次。

2. 去掉全局背压：只有当结果缓冲的空位足够容纳全部在途结果时，发射级才发射；MAC 和量化流水不因输出背压停顿。
3. 每级组合逻辑应不超过约 8 级 LUT；高扇出控制信号（发射、命令切换、地址）应由寄存器驱动并按负载复制；描述符字段应在命令开始时装入影子寄存器，并在使用方附近各寄存一份本地副本。
4. 数据通路（行缓存、窗口生成、MAC 阵列、累加、量化、写回打包）完成后，应先单独做一次 PDS 综合和布局布线，再接入调度器。
5. 数据通路子顶层 `edrv32_npu_datapath` 与调度/DMA 之间的内部接口，以设计记录 2026-10-27-npu-datapath 4.2 为开发接口；修改须经协调者确认，并随 RTL 定稿写入本节。

### 5.5 ABORT

`CTRL.ABORT` 后 NPU 不再读取新的描述符，停止发出新的 AXI 事务，等待已发出的事务全部完成后回到 IDLE（SoC 规格 7.1）；被中止的描述符输出内容未定义，`DONE_COUNT` 不增加。

## 6. 错误处理

| 错误 | 检测 | 上报 | 恢复 |
|---|---|---|---|
| AXI 读或写响应 SLVERR/DECERR | R/B 通道 | `IRQ_STAT.ERROR`，`ERR_CODE` = 1（读）/ 2（写），`CUR_DESC` 保持 | 停止执行后续描述符，等在途事务完成后回到 IDLE；软件清 ERROR 后可重新启动 |
| 非法 `OP` | 描述符译码 | `ERR_CODE` = 3 | 同上 |
| 形状超出 5.2 的容量约束 | 描述符译码（只查三项：`ROW_SLOT_BEATS` × 行槽数 ≤ 1024、`COUT_BLOCKS` ≤ 8、`COUT_BLOCKS × WEIGHT_BLOCK_BYTES` ≤ 常驻权重容量） | `ERR_CODE` = 4 | 同上 |

除上表外不做其他检查（例如不检查派生字段与形状是否自洽、地址是否越界）。
