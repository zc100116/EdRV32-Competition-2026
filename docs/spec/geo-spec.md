## 1. 概述

GEO 按软件给出的逆映射矩阵，把源 Surface 变换到输出 Surface 中的一个矩形里：对矩形内每个输出像素，算出它在源图中的位置，取周围 4 个像素做双线性插值。可以实现任意角度旋转、缩放、平移、镜像和一般仿射。

- 模式：命令式（SoC 7.2）。软件在 DDR 中准备描述符表，写 `DESC_BASE`、`DESC_COUNT`，再写 `DOORBELL`；GEO 依次执行，每条描述符完成一次变换（通常一帧一条），全部完成、最后一个写响应返回后置 `IRQ_STAT.DONE`。
- 典型用法（设计记录 Q2）：VIN 完成一帧后，CPU 填写本帧的源、输出 Surface 地址并写门铃；矩阵只在变换参数改变时由软件重新计算。
- DDR 端口为 mem_xbar P5（读写，SRT）；寄存器在媒体 APB 槽 3；中断为 PLIC 源 10。
- 时钟域：全部在 clk_mem；复位 `rst_mem_n`（系统子系统规格 2.10）。

## 2. 功能描述

### 2.1 坐标和矩阵

- 输出矩形左上角为 (0, 0)。矩形内输出像素 (u, v)（0 ≤ u < RECT_W，0 ≤ v < RECT_H）对应的源坐标为：

  ```
  x = A·u + B·v + TX
  y = C·u + D·v + TY
  ```

  A、B、C、D、TX、TY 为 32 位有符号 Q16.16 定点数，乘加按整数精确计算，结果取 32 位 Q16.16（软件保证不溢出）。
- 源像素 (i, j) 的中心位于坐标 (i, j)。`x0 = x >>> 16`（向负无穷取整），`fx = x[15:8]`；`y0`、`fy` 同理。
- 软件辅助函数（`sw/lib`）从角度、缩放、平移计算矩阵，不属于硬件规格。

### 2.2 双线性插值

1. 取 4 个采样点 P00 = (x0, y0)、P01 = (x0 + 1, y0)、P10 = (x0, y0 + 1)、P11 = (x0 + 1, y0 + 1)。
2. 采样点在源图以外（列 < 0 或 ≥ SRC_W，行 < 0 或 ≥ SRC_H）时，用背景色 BG 代替。
3. 每个采样点按 PIX 规格 2.1 的方法展开为 RGB888；对 R、G、B 分别计算：

   ```
   out = (P00·(256 − fx)·(256 − fy) + P01·fx·(256 − fy)
          + P10·(256 − fx)·fy + P11·fx·fy + 32768) >> 16
   ```

4. 结果按 PIX 规格 2.1 截断回 RGB565，写入输出 Surface 中 (RECT_X + u, RECT_Y + v) 处。

4 个采样点全在源图以外时，结果等于 BG。

### 2.3 输出矩形

- GEO 只写输出 Surface 中的矩形 [RECT_X, RECT_X + RECT_W) × [RECT_Y, RECT_Y + RECT_H)，矩形外的像素保持不变。
- `RECT_X` 必须是 16 的倍数（描述符中低 4 位忽略），`RECT_W` 必须是偶数（最低位忽略）。矩形必须位于输出 Surface 内，由软件保证，GEO 不检查。
- `RECT_W` 或 `RECT_H` 为 0 时，该描述符不写任何像素，照常完成。
- 矩形内的写入顺序不作规定；一条描述符完成（最后一个写响应返回）时，矩形内全部像素已写入。

### 2.4 变换范围

GEO 按块处理输出矩形：每个输出块（宽 BW × 高 BH 像素）在源图中的覆盖区域，整片读入片上缓冲（宽 PW × 高 PH 像素）后再插值（BW、BH、PW、PH 见 5.2）。为保证覆盖区域装得下，描述符必须满足：

```
|A|·(BW − 1) + |B|·(BH − 1) ≤ (PW − 2) · 2^16
|C|·(BW − 1) + |D|·(BH − 1) ≤ (PH − 2) · 2^16
```

不满足时报配置错误（第 6 节）。5.2 的取值必须保证：均匀缩放 s ≤ 2（源尺寸 ÷ 输出尺寸）、任意旋转角度、任意平移的矩阵都满足上式；放大（s < 1）不受限制。

### 2.5 源和输出 Surface

- 格式只支持 RGB565（SoC 7.3）。`SRC_BASE`、`DST_BASE` 4 KiB 对齐，`SRC_STRIDE`、`DST_STRIDE` 为 32 B 的整数倍（描述符中低位忽略）。
- `SRC_W`、`SRC_H` 为 1–4095；为 0 时所有采样点都在源图以外，输出全为 BG。
- 同一条描述符的源 Surface 与输出矩形不得重叠，由软件保证，GEO 不检查。前后两条描述符之间按顺序执行：后一条开始读取前，前一条的写响应已全部返回。

### 2.6 描述符

描述符表在 DDR 中，起始地址 `DESC_BASE`（32 B 对齐），每条 64 B（16 个 32 位字，小端），连续存放。

| 字 | 位 | 字段 | 说明 |
|---|---|---|---|
| 0 | [31:12] | `SRC_BASE` | 源 Surface 基址（[11:0] 忽略） |
| 1 | [15:5] | `SRC_STRIDE` | 源行跨距（字节；[4:0] 忽略） |
| 2 | [11:0] / [27:16] | `SRC_W` / `SRC_H` | 源宽、高（像素） |
| 3 | [31:12] | `DST_BASE` | 输出 Surface 基址 |
| 4 | [15:5] | `DST_STRIDE` | 输出行跨距 |
| 5 | [11:4] / [27:16] | `RECT_X` / `RECT_Y` | 输出矩形左上角（像素；RECT_X 的 [3:0] 忽略） |
| 6 | [11:1] / [27:16] | `RECT_W` / `RECT_H` | 输出矩形宽、高（像素；RECT_W 的 [0] 忽略） |
| 7 | [15:0] | `BG` | 背景色（RGB565） |
| 8–13 | [31:0] | `A`、`B`、`TX`、`C`、`D`、`TY` | 逆映射矩阵（有符号 Q16.16） |
| 14–15 | — | — | 不使用，忽略 |

未列出的位忽略。

## 4. 寄存器

媒体 APB 槽 3。公共寄存器按 SoC 7.1；寄存器块忽略 `pstrb`，按整字写（SoC 4.3）。未列出的偏移读为 0、写忽略。

### 4.1 公共寄存器

| 偏移 | 名称 | 规定 |
|---|---|---|
| 0x000 | ID | 0x0003_0001 |
| 0x004 | CTRL | bit0 ENABLE：可读写，不门控 DOORBELL；bit1 START 无作用；bit2 ABORT（5.3）；bit3 SOFT_RST：只在 IDLE 时生效，把全部寄存器和控制状态恢复到复位值 |
| 0x008 | STATUS | BUSY = 正在执行描述符表或有未完成的 AXI 事务；IDLE = 非 BUSY；ERROR = IRQ_STAT.ERROR |
| 0x00C | IRQ_EN | 复位 0 |
| 0x010 | IRQ_STAT | bit0 DONE；bit1 ERROR |
| 0x014 | ERR_CODE | 第 6 节 |
| 0x020 | DESC_BASE | [31:5]，[4:0] 读为 0 |
| 0x024 | DESC_COUNT | [15:0] 描述符条数，其余位读为 0 |
| 0x028 | DOORBELL | 写任意值启动；STATUS.BUSY = 1 时写入被忽略；DESC_COUNT = 0 时立即置 DONE |
| 0x02C | DONE_COUNT | 已完成的描述符条数（自增，回绕） |
| 0x040–0x07C | PERF | 4.3 |

### 4.2 私有寄存器

| 偏移 | 名称 | 访问 | 复位值 | 说明 |
|---|---|---|---|---|
| 0x100 | CUR_DESC | RO | 0 | 正在执行（或因错误停止时）的描述符序号，从 0 起；正常完成后为 DESC_COUNT |

### 4.3 性能计数器

32 位，回绕；每次 DOORBELL 清零。

| 编号 | 内容 |
|---|---|
| PERF0 | 从 DOORBELL 到 DONE 或停止的总周期；ABORT 或错误后计到 STATUS.BUSY 清零（在途事务排空）为止 |
| PERF1 | 写出的输出像素数 |
| PERF2 | 读 beat 数（描述符和源像素） |
| PERF3 | 写 beat 数 |
| PERF4 | 插值单元因片上缓冲未就绪而等待的周期 |
| PERF5 | 插值单元因写出侧不接收而等待的周期 |
| PERF6–15 | 读为 0 |

## 5. 行为与时序

### 5.1 执行

1. DOORBELL 后 GEO 从 `DESC_BASE` 起依次读取并执行 `DESC_COUNT` 条描述符。
2. 每条描述符：按 2.4 检查变换范围；按块读取源覆盖区域、插值、写出；该条的最后一个写响应返回后 DONE_COUNT 加 1、CUR_DESC 加 1。
3. 全部完成后置 IRQ_STAT.DONE，回到 IDLE。

### 5.2 块和片上缓冲 **[待定]**

| 参数 | 开发初值 | 约束 |
|---|---|---|
| 输出块 BW × BH | 32 × 16 | — |
| 源缓冲 PW × PH | 80 × 80 | 满足 2.4 对 s ≤ 2 任意角度的要求：`2·√((BW − 1)² + (BH − 1)²) + 2 ≤ min(PW, PH)` |
| 源缓冲组数 | 2（读下一块与计算当前块重叠） | — |
| 吞吐 | 每拍 1 个输出像素 | 第 7 节 |

### 5.3 ABORT

`CTRL.ABORT` 写 1：不再读取新描述符和源数据，已发出的 AXI 事务全部完成后回到 IDLE（SoC 7.1）；正在执行的描述符不计入 DONE_COUNT，不置 DONE，输出矩形中已写入的部分保留。

## 6. 错误处理

| ERR_CODE | 错误 | 检测 | 上报 | 恢复 |
|---|---|---|---|---|
| 1 | 读响应非 OKAY（描述符或源像素） | R 通道 | IRQ_STAT.ERROR，CUR_DESC 保持 | 停止执行后续描述符，等在途事务完成后回到 IDLE；软件清 ERROR 后可重新启动 |
| 2 | 写响应非 OKAY | B 通道 | 同上 | 同上 |
| 3 | 变换超出范围（2.4） | 描述符读入后、读取源数据前 | 同上 | 该条不执行，停止执行后续描述符 |

除上表外不做其他检查（不检查地址越界、矩形是否在输出 Surface 内、源与输出是否重叠）。`ERR_CODE` 记录最近一次错误，写 IRQ_STAT.ERROR 清零时一并清除（SoC 7.1）。

## 8. 验证要点

1. 插值结果与 Python 参考模型逐位一致（2.1–2.2）：恒等变换、整数平移、0°/90°/180°/270° 和任意角度旋转、放大、s = 2 缩小、非均匀缩放、镜像、错切。
2. 源图边缘和图外：部分采样点越界、全部越界（2.2 第 2 条）；SRC_W/SRC_H 为 1 和 0。
3. 输出矩形：矩形外的像素不变；RECT_X 为 16 的倍数的各位置；RECT_W/RECT_H 为 0；矩形宽度不是 BW 的倍数。
4. 变换范围检查：s ≤ 2 的任意角度都被接受；明显超出的矩阵报 ERR_CODE 3 且不写任何像素。
5. 多条描述符顺序执行，后一条读取前一条的输出（2.5 第 3 条）。
6. 第 6 节每种错误和 ABORT（含在途事务）；SOFT_RST；DESC_COUNT = 0。
7. 性能：第 7 节两档的帧时间。
