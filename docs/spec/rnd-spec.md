## 1. 概述

RND 从 DDR 读取 CPU 准备好的命令列表，依次在 DDR 中的图像缓冲上绘制：填充、边框、字形、位图、搬运、阴影、模糊、瓦片地图、三角形、圆头线段、圆头弧、矩形遮罩和仿射双线性位图。它是 LVGL 绘制单元的硬件后端（设计记录 rnd-disp 4.3），也用来画游戏的瓦片背景和精灵（同 5.2）。

```
APB 槽 4 ─ 寄存器块 ─ 命令执行 ─┬─ 读客户端（命令、源、目标、调色板、瓦片、地图、临时区）─┐
                                 ├─ 2 像素/拍 alpha 通路                                 ├─ dma2d_rd/wr ─ P4
                                 └─ 256 位快速通路（纯色填充、搬运）                     ─┘
```

时钟域：全部在 clk_mem（SoC 5.1）。复位：`rst_mem_n`（系统子系统规格 2.10）。mem_xbar P4（软实时，读写，无紧急信号，SoC 6.4.1），媒体 APB 槽 4，PLIC 源 11。

## 2. 功能描述

### 2.1 像素格式和缓冲

| 编码 | 格式 | 每像素 | 存储 | 可用于 |
|---|---|---|---|---|
| 0 | RGB565 | 16 位 | 小端 16 位，`[15:11]` R、`[10:5]` G、`[4:0]` B | 目标、源、瓦片 |
| 1 | ARGB8888（非预乘，SoC 7.3） | 32 位 | 小端 32 位，`[31:24]` α、`[23:16]` R、`[15:8]` G、`[7:0]` B | 目标、源、瓦片 |
| 2 | A8 | 8 位 | 1 字节 | 字形 |
| 3 | A4 | 4 位 | 字节内第一个像素在高位 | 字形 |
| 4 | A2 | 2 位 | 同上 | 字形 |
| 5 | A1 | 1 位 | 同上 | 字形 |
| 6 | I8 | 8 位 | 调色板索引，字节内高位在前（同上） | 源、瓦片 |
| 7 | I4 | 4 位 | 同上 | 源、瓦片 |
| 8 | I2 | 2 位 | 同上 | 源 |
| 9 | I1 | 1 位 | 同上 | 源 |

- 目标缓冲：基址按像素大小对齐（RGB565 2 B、ARGB8888 4 B），跨距为像素大小的整数倍。
- 源缓冲（BLIT、AFFINE_BLIT、GLYPH、COPY 的源）：基址和跨距以字节为单位，不要求对齐；亚字节格式每行从一个字节的最高位开始。
- 调色板：2^bpp 项 ARGB8888，基址 4 B 对齐。
- 瓦片数据、瓦片地图、命令列表、临时区的对齐见各命令。
- 参数块：DDR 中的小端 32 位字，基址必须 64 B 对齐；TRIANGLE/LINE/ARC 固定 128 B，AFFINE_BLIT 和启用 ROUND_CLIP 的 BLIT 固定 64 B（2.6）。
- 坐标：目标像素 (x, y) 位于 `基址 + y × 跨距 + x × 像素字节数`。
- RND 只访问 DDR（SoC 6.1）；交给 DISP 扫描的缓冲还必须满足 SoC 7.3 的 Surface 对齐要求。

### 2.2 像素运算（逐位规定，参考模型与之一致）

| 记号 | 定义 |
|---|---|
| d(x) | (t + (t >> 8)) >> 8，t = x + 128；对 0 ≤ x ≤ 65025 等于 x / 255 四舍五入（与 DISP 2.7 相同） |
| mix(a, F, B) | d(a × F + (255 − a) × B)，逐通道 |
| E565(v) | RGB565 展开为 8 位：R、B `{v[4:0], v[4:2]}`，G `{v[5:0], v[5:4]}`（与 DISP 2.3 相同） |
| P565(R, G, B) | `{R[7:3], G[7:2], B[7:3]}`（截断） |
| Q[a] | ⌊(255 × 65536 + ⌊a / 2⌋) / a⌋，a = 1…255（24 位常数表） |
| An(m) | 亚字节 alpha 展开到 8 位：A4 × 17，A2 × 85，A1 × 255，A8 不变 |

**写入（over）**：每条绘制命令对绘制区域内每个目标像素给出源颜色 S_c（8 位 R、G、B）和源 alpha sa（0–255），按目标格式写回：

- 目标 RGB565，原值 D：D_c = E565(D)；写回 P565(mix(sa, S_c, D_c))。
- 目标 ARGB8888，原值 {Da, D_c}：
  - oa = sa + d((255 − sa) × Da)；
  - oa = 0 时写回 0；否则 r = (sa × Q[oa] + 32768) >> 16，写回 {oa, mix(r, S_c, D_c)}。
  - sa = 255 时结果为 {255, S_c}；Da = 255 时结果为 {255, mix(sa, S_c, D_c)}。
- sa = 0 的像素保持原值（可以不写）。

**混合模式**（用于 BLIT 和 AFFINE_BLIT，`MODE` 字段）：先把源颜色换成 T_c，再按上面的 over 写入：

| MODE | 名称 | T_c |
|---|---|---|
| 0 | 正常 | S_c |
| 1 | 相加 | min(S_c + D_c, 255) |
| 2 | 相减 | max(D_c − S_c, 0) |
| 3 | 相乘 | d(S_c × D_c) |

D_c 为目标原值的 8 位颜色（RGB565 先 E565）。

### 2.3 圆角矩形覆盖率

FILL、BORDER、BOX_SHADOW、MASK_RECT，以及 BLIT/AFFINE_BLIT 的目标圆角裁切使用。记本节结果为 C；G1 几何使用下述独立 coverage。矩形宽 W、高 H，半径 r，局部坐标 (i, j)，0 ≤ i < W，0 ≤ j < H：

1. r' = min(r, ⌊min(W, H) / 2⌋)。
2. jd = min(j, H − 1 − j)。若 r' > 0 且 jd < r'：dy = 16 × (r' − jd) − 8，e = 16 × r' − isqrt(256 × r'² − dy²)（isqrt 向下取整）；否则 e = 0。e 是本行边缘向内缩进的距离（Q4）。
3. room = min(16 × i + 16 − e, 16 × W − e − 16 × i)。
4. cov = 0（room ≤ 0），255（room ≥ 16），16 × room（其余）。矩形外 cov = 0。

只在水平方向做抗锯齿（与旧工程 `edrv32_render_round_row.v` 的做法相同）。

#### 一般几何覆盖率（TRIANGLE、LINE、ARC）

- AA=1：每像素采样 `(x+(2i+1)/8, y+(2j+1)/8)`，i、j=0…3；先合并各主体和圆头的 inside，再统计 N，`cov=floor((255N+8)/16)`。
- AA=0：只采样像素中心 `(x+1/2,y+1/2)`，cov 为 0 或 255。
- 线性量 E 的参数为 signed32 Q15.16 的 E0、Ex、Ey；E0 对应 RECT 左上角整数坐标，`E=E0+(xs-X0)Ex+(ys-Y0)Ey`。子像素分数必须精确保留至比较，不逐项截断；可将比较两边乘 8 用整数实现。
- 圆心和半径由软件量化到 1/8 像素网格。每圆的四字依次为 q0[31:0]、q0[47:32]（第二字高 16 位忽略）、signed32 Δx、signed32 Δy。q0 为 `(X0+1/8,Y0+1/8)` 的 `q=X²+Y²−R²`，X、Y、R 以 1/8 像素为单位；Δx、Δy 为从该点各前进一个完整像素的 q 差。
- 对离初始子点 a、b 个 1/8 像素的样本，`q=q0+a(Δx−64)/8+b(Δy−64)/8+a²+b²`；差分由软件保证来自上述圆，除法为精确整数除法。像素内 AA 用 a=8(x−X0)+2i、b=8(y−Y0)+2j；无 AA 用 a=8(x−X0)+3、b=8(y−Y0)+3。圆内为 q≤0。
- 增量实现：子步 +2 的 q 差为 `(Δ8−48)/4`，下一子步差增加 8；完整像素步 +8 的差为 Δ8，下一完整步差增加 128。行起点必须独立保存；不得用每像素 sqrt、除法或三角函数。
- 软件必须保证全部圆 q 与线性整数像素累加值在 signed48 范围内，圆的完整步差在 signed32 范围内；子像素计算保留额外分数位。硬件不做溢出检测。

### 2.4 盒式模糊

BOX_SHADOW、BLUR 使用。半径 R（0–31），M_R = ⌊(65536 + R) / (2R + 1)⌋：

- 一遍水平模糊：out(i) = (Σ_{k = −R…R} in(i + k) × M_R + 32768) >> 16。
- 一遍竖直模糊同理。
- 先水平、后竖直，逐通道进行；越界取值规则见各命令。
- 结果不超过 255，与精确平均值的误差不超过 0.6。

### 2.5 命令列表

- 命令列表在 DDR 中，起始地址 `DESC_BASE`（64 B 对齐），每条 64 B（16 个 32 位小端字），连续存放。
- 公共字段（W0–W7）：

| 字 | 位 | 字段 | 说明 |
|---|---|---|---|
| 0 | [7:0] | `OP` | 命令码（2.6） |
| 0 | [8] | `DST_FMT` | 目标格式：0 RGB565，1 ARGB8888 |
| 0 | [15:12] | `SRC_FMT` | 源格式（2.1 编码），各命令允许的取值见 2.6 |
| 0 | [31:16] | `FLAGS` | 各命令定义 |
| 1 | [31:0] | `DST_BASE` | 目标缓冲基址（2.1） |
| 2 | [15:0] | `DST_STRIDE` | 目标跨距（字节） |
| 3 | [11:0] / [27:16] | `CLIP_X0` / `CLIP_Y0` | 裁剪矩形左上角（目标像素，含） |
| 4 | [11:0] / [27:16] | `CLIP_X1` / `CLIP_Y1` | 裁剪矩形右下角（含） |
| 5 | [15:0] / [31:16] | `X0` / `Y0` | 图元矩形左上角（有符号 16 位，含） |
| 6 | [15:0] / [31:16] | `X1` / `Y1` | 图元矩形右下角（有符号 16 位，含） |
| 7 | [23:0] / [31:24] | `COLOR` / `OPA` | 颜色 RGB888（[23:16] R）；整体透明度 |

- 图元矩形 RECT = [X0, X1] × [Y0, Y1]，宽 W = X1 − X0 + 1，高 H = Y1 − Y0 + 1。
- **绘制区域** A = RECT ∩ CLIP（BOX_SHADOW 另行规定）；A 为空（含 X1 < X0 或 Y1 < Y0）时命令不访问目标，直接完成。
- 软件必须保证：CLIP 落在目标缓冲内；源、调色板、瓦片和地图的读取范围落在各自的缓冲内；除 COPY 外，源与目标不重叠。RND 不检查这些条件（第 6 节）。
- 参数块属于当前命令，不增加 DONE_COUNT，也不推进 CUR_DESC。通过格式检查后读取参数；参数字编号 P0 从块首开始，未用字忽略。
- 新几何 RECT 包含 AA 边界；软件将零面积三角形、零扫角弧编码为空 RECT。空绘制区域不读取参数块、源或目标，继承直接完成语义。
- 未列出的位忽略。

### 2.6 命令

#### 0x01 FILL：纯色或线性渐变填充，可带圆角

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `GRAD` | 1 = 渐变 |
| FLAGS[1] | `GRAD_V` | 0 = 水平（沿 x），1 = 竖直（沿 y） |
| 8 | [11:0] `RADIUS` | 圆角半径 |
| 9 | `GRAD_START` | 渐变起点 ARGB8888（非预乘） |
| 10–13 | `STEP_A`、`STEP_R`、`STEP_G`、`STEP_B` | 每像素增量：整字为有符号 32 位数，单位 2⁻¹⁶（即 Q15.16） |

- `SRC_FMT` 忽略。
- 渐变：k = x − X0（水平）或 y − Y0（竖直）。通道值 g = clamp((START × 65536 + k × STEP + 32768) >> 16, 0, 255)，START 为该通道的起点。
- S_c = COLOR（`GRAD` = 0）或 g_R、g_G、g_B（`GRAD` = 1）。
- a0 = 255（`GRAD` = 0）或 g_A（`GRAD` = 1）。
- sa = d(d(OPA × a0) × cov)。cov 按 2.3 对 RECT 和 `RADIUS` 计算；`RADIUS` = 0 时 cov = 255。
- 多段渐变由软件拆成多条 FILL：RECT 和 `RADIUS` 相同，CLIP 各取一段。

#### 0x02 BORDER：圆角边框

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | [11:0] `RADIUS` | 外缘半径 |
| 9 | [11:0] `WIDTH` | 边框宽度 BW |
| 9 | [19:16] `SIDES` | bit0 上，bit1 下，bit2 左，bit3 右 |

- `SRC_FMT` 忽略。
- 外缘：RECT，半径 `RADIUS`，有效半径 r'（2.3 第 1 条）。
- 内缘矩形：
  - `SIDES` 中选中的边，从 RECT 向内缩进 BW；
  - 未选中的边，向外扩出 r' + 1；
  - 内缘半径 max(r' − BW, 0)。
- cov_o、cov_i 分别按 2.3 对外缘和内缘计算。
- S_c = COLOR，sa = d(OPA × d(cov_o × (255 − cov_i)))。

#### 0x03 GLYPH：字形或掩码着色

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | `SRC_BASE` | 掩码基址（字节） |
| 9 | [15:0] `SRC_STRIDE` | 掩码跨距（字节） |
| 10 | [15:0] / [31:16] | `SRC_X` / `SRC_Y`：与 (X0, Y0) 对应的掩码像素 |

- `SRC_FMT` ∈ {A8, A4, A2, A1}。
- 目标像素 (x, y) 取掩码 m = (`SRC_X` + x − X0, `SRC_Y` + y − Y0) 处的值。
- S_c = COLOR，sa = d(OPA × An(m))。

#### 0x04 BLIT：位图绘制

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] / [1] | `HFLIP` / `VFLIP` | 水平 / 竖直翻转 |
| FLAGS[2] | `COLORKEY` | 1 = 源 RGB565 等于 `KEY` 的像素视为透明 |
| FLAGS[3] | `RECOLOR` | 1 = 重新着色 |
| FLAGS[6:4] | `MODE` | 混合模式（2.2），4–7 非法 |
| FLAGS[7] | `ROUND_CLIP` | 1 = 目标空间圆角裁切 |
| 8 | `SRC_BASE` | 源基址（字节） |
| 9 | [15:0] `SRC_STRIDE` | 源跨距（字节） |
| 10 | [15:0] / [31:16] | `SRC_X` / `SRC_Y` |
| 11 / 12 | `SCALE_X` / `SCALE_Y` | 每个目标像素的源步长，无符号 Q16.16；0x0001_0000 为 1:1 |
| 13 | `PALETTE` / `PARAM_BASE` | ROUND_CLIP=0 时为调色板基址；为 1 时为 64 B 参数块指针 |
| 14 | [15:0] / [27:16] | `KEY`（RGB565）/ `CLIP_RADIUS`（ROUND_CLIP=1 时） |
| 15 | [23:0] / [31:24] | `RC_COLOR` / `RC_OPA`：重新着色的颜色和比例 |

- `SRC_FMT` ∈ {RGB565, ARGB8888, I8, I4, I2, I1}。
- 采样（最近邻）：
  - kx = x − X0（`HFLIP` = 0）或 X1 − x（`HFLIP` = 1）；
  - u = `SRC_X` + ((kx × `SCALE_X`) >> 16)；
  - v 同理，用 y、Y0/Y1、`VFLIP`、`SRC_Y`、`SCALE_Y`；
  - 取源像素 (u, v)。
- 源像素换算为 {As, S_c}：
  - RGB565：As = 255，S_c = E565；`COLORKEY` = 1 且像素值等于 `KEY` 时 As = 0。
  - ARGB8888：直接取用。
  - 索引格式：取调色板中对应的一项。
- `RECOLOR` = 1：S_c = mix(`RC_OPA`, `RC_COLOR`_c, S_c)。
- ROUND_CLIP=1 的参数块：P0=PALETTE；P1 的 [15:0]/[31:16] 为 IMAGE_X0/Y0，P2 同样为 IMAGE_X1/Y1，坐标均 signed16，含右下角。image_area 独立于 RECT、CLIP 和源采样，按 2.3 对它及 CLIP_RADIUS 求 C_image；半径 0 不裁切（C_image=255）。ROUND_CLIP=0 时 C_image=255。
- 按 `MODE` 得 T_c；sa = d(d(OPA × As) × C_image)。
- LVGL 的 IMAGE 和 LAYER 任务按采样需求映射到 BLIT 或 AFFINE_BLIT。

#### 0x05 COPY：同格式矩形搬运

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | `SRC_BASE` | 源基址 |
| 9 | [15:0] `SRC_STRIDE` | 源跨距 |
| 10 | [15:0] / [31:16] | `SRC_X` / `SRC_Y` |

- `SRC_FMT` 必须等于 `DST_FMT`。
- 目标像素 (x, y) = 源像素 (`SRC_X` + x − X0, `SRC_Y` + y − Y0)，逐位复制，包括 alpha；COLOR、OPA 忽略。
- 源和目标可以在同一缓冲内重叠（`SRC_STRIDE` = `DST_STRIDE`）：结果与"先读完整个源区域、再写目标"相同。跨距不同的源和目标由软件保证不重叠，RND 不检查。

#### 0x06 BOX_SHADOW：圆角阴影

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `CUTOUT` | 1 = 挖去原背景（LVGL bg_cover=0） |
| 8 | [11:0] `RADIUS` | 阴影形状的圆角半径 |
| 9 | [4:0] `BLUR` | 模糊半径 R（0–31） |
| 10 | `TEMP_BASE` | 临时区基址（32 B 对齐） |
| 11 | [15:0] / [31:16] | `BG_X0` / `BG_Y0`，signed16 |
| 12 | [15:0] / [31:16] | `BG_X1` / `BG_Y1`，signed16，含右下角 |
| 13 | [11:0] `BG_RADIUS` | 原背景圆角半径 |

- `SRC_FMT` 忽略。
- RECT 是阴影形状（已含扩展和偏移，由软件计算）。
- 扩展网格：RECT 四边各向外扩 R，尺寸 (W + 2R) × (H + 2R)。
- 掩码 m：
  1. 网格上按 2.3 求 RECT 的 cov（RECT 外为 0）；
  2. 按 2.4 做水平、竖直两遍模糊，网格外取 0。
- 绘制区域为扩展网格 ∩ CLIP；S_c = COLOR。CUTOUT=0 时 sa=d(OPA×m)；CUTOUT=1 时对未偏移、未扩展的 BG 矩形按 2.3 求 C_bg，`sa=d(OPA×d(m×(255−C_bg)))`。背景外 C_bg=0，临时区大小不变。
- 临时区：
  - 大小 2 × S × (H + 2R) 字节，S = 32 × ⌈(W + 2R) / 32⌉；
  - 命令完成后内容不作规定；
  - 不得与目标重叠。

#### 0x07 BLUR：区域模糊

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | [4:0] `BLUR` | 模糊半径 R（0–31） |
| 9 | `TEMP_BASE` | 临时区基址（32 B 对齐） |

- `SRC_FMT`、COLOR、OPA 忽略。
- 对绘制区域 A 的目标像素原地做 2.4 的两遍模糊，越界时取 A 内最近的像素。
- 逐通道处理：
  - ARGB8888 处理 α、R、G、B 四个通道；
  - RGB565 先 E565，结果按 P565 写回。
- 两遍之间的中间结果：水平遍的输出逐通道保留 8 位，竖直遍在此基础上计算；RGB565 目标只在最后写回时按 P565 截断一次。
- 临时区：每像素 4 B（RGB565 目标存 {0, R, G, B}，ARGB8888 目标存 {α, R, G, B}），大小为 32 × ⌈4 × A 的宽度 / 32⌉ × A 的高度字节；不得与目标重叠。

#### 0x08 TILEMAP：瓦片地图

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `TILE16` | 0 = 8 × 8 瓦片，1 = 16 × 16 瓦片 |
| FLAGS[2] | `COLORKEY` | 同 BLIT |
| 8 | `TILE_BASE` | 瓦片数据基址（32 B 对齐） |
| 9 | `MAP_BASE` | 地图基址（32 B 对齐） |
| 10 | [15:0] `MAP_STRIDE` | 地图跨距（字节，偶数） |
| 11 | [15:0] / [31:16] | `MAP_X` / `MAP_Y`：与 (X0, Y0) 对应的地图像素坐标 |
| 13 | `PALETTE` | 调色板基址（索引格式） |
| 14 | [15:0] `KEY` | 颜色键 |

- `SRC_FMT` ∈ {RGB565, ARGB8888, I8, I4}（瓦片格式）。
- 瓦片边长 T = 8 或 16。
- 瓦片存储：瓦片 t 的数据位于 `TILE_BASE` + t × B，B = T² × bpp / 8 字节（都是 32 的倍数）；行连续存放，像素顺序按 2.1。
- 地图项：16 位小端，[11:0] 瓦片号，[12] 水平翻转，[13] 竖直翻转，[15:14] 忽略。
- 目标像素 (x, y)：
  1. mx = `MAP_X` + x − X0，my = `MAP_Y` + y − Y0；
  2. 地图项 E 位于 `MAP_BASE` + ⌊my / T⌋ × `MAP_STRIDE` + 2 × ⌊mx / T⌋；
  3. 瓦片内坐标 tx = mx mod T、ty = my mod T，翻转位为 1 时分别取 T − 1 − tx、T − 1 − ty；
  4. 取瓦片 E[11:0] 的像素 (tx, ty)，按 BLIT 的规则换算为 {As, S_c}（含 `COLORKEY`、调色板）。
- sa = d(OPA × As)，正常模式。

#### 0x09 TRIANGLE：三角形

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `AA` | 2.3 一般几何采样 |
| FLAGS[6] / [7] | `GRAD` / `GRAD_V` | 同 FILL |
| 8 | `PARAM_BASE` | 128 B 参数块 |
| P0–P8 | `E0/Ex/Ey` × 3 | 三个内侧边方程，signed32 Q15.16 |
| P9 | `GRAD_START` | 同 FILL W9 |
| P10–P13 | `STEP_A/R/G/B` | 同 FILL W10–W13 |

- SRC_FMT 忽略。样本的三个 E 均≥0 时 inside。共享边使用 top-left：水平向右或向上边含边，反边不含；软件统一顶点方向，将非含边的 E0 减 1 个 Q16 最低位编码，硬件仍只比较≥0。
- cov 按 2.3 一般几何。S、g 和 a0 按 FILL（渐变 k 仍从 RECT 原点起算），`sa=d(d(OPA×a0)×cov)`；多段渐变沿用相同 RECT、不同 CLIP。

#### 0x0A LINE：单段线及圆头

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `AA` | 2.3 一般几何采样 |
| FLAGS[1] / [2] | `CAP_START` / `CAP_END` | 起点 / 终点圆头 |
| 8 | `PARAM_BASE` | 128 B 参数块 |
| P0–P5 | `T0/Tx/Ty`、`N0/Nx/Ny` | 沿线 t、法线 n，signed32 Q15.16 |
| P6 / P7 | `LENGTH` / `HALF_WIDTH` | unsigned32 Q16.16 的 L、h |
| P8–P11 / P12–P15 | 起点 / 终点圆 | 2.3 的四字圆参数，半径 h |

- SRC_FMT 忽略。inside 为主体 `0≤t≤L && |n|≤h` 与使能圆头 q≤0 的并集；零长度线由软件编码为端点圆，并使主体条件恒假（T0<0、Tx=Ty=0）。只支持单段线，虚线和 points 折线不在范围内。
- S_c=COLOR，`sa=d(OPA×cov)`；圆头与主体重叠只混合一次。

#### 0x0B ARC：圆弧及圆头

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `AA` | 2.3 一般几何采样 |
| FLAGS[1] / [2] | `CAP_START` / `CAP_END` | 起点 / 终点圆头 |
| FLAGS[3] | `LARGE_ARC` | 0 = 扫角≤180°，1 = 扫角>180° |
| FLAGS[4] / [5] | `FULL_CIRCLE` / `INNER_EMPTY` | 整圆 / 内半径为 0 |
| 8 | `PARAM_BASE` | 128 B 参数块 |
| P0–P15 | 外圆、内圆、起点圆头、终点圆头 | 每圆四字，格式见 2.3 |
| P16–P21 | `B0/Bx/By` × 2 | 两个内侧角半平面，signed32 Q15.16 |

- SRC_FMT 忽略。圆环 inside 为外圆 q≤0 且（INNER_EMPTY=1 或内圆 q>0）。小弧与两个 B≥0 的 AND 相交，大弧与其 OR 相交；FULL_CIRCLE=1 忽略角边界和圆头。其余情形再与使能圆头的 q≤0 取并集。
- 软件取 w=min(width,r)，内半径 r−w；圆头半径 w/2，圆心位于中径 r−w/2 的两角端点；然后量化圆参数。内半径 0 必须设 INNER_EMPTY。
- S_c=COLOR，`sa=d(OPA×cov)`；并集后采样计数，不重复混合。

#### 0x0C MASK_RECT：原地矩形 alpha 遮罩

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `KEEP_OUTSIDE` | mask 矩形外保持 alpha，否则清零 |
| 8 | [11:0] `RADIUS` | mask 圆角半径 |
| 9 | [15:0] / [31:16] | `MASK_X0/Y0`，signed16 |
| 10 | [15:0] / [31:16] | `MASK_X1/Y1`，signed16，含右下角 |

- 软件必须保证 DST_FMT=ARGB8888；SRC_FMT、COLOR、OPA 忽略。处理范围仍为 RECT∩CLIP；mask 形状独立于 RECT。
- mask 矩形内按 2.3 求 C，`Da'=d(Da×C)`；矩形外 KEEP_OUTSIDE=1 时 Da'=Da，否则 Da'=0。
- RGB 保持原非预乘值；Da'=0 写全零。直接写回目标，不执行 2.2 over。

#### 0x0D AFFINE_BLIT：逆仿射位图，最近邻或双线性

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `BILINEAR` | 0 最近邻；1 双线性（必须实现） |
| FLAGS[2] / [3] / [6:4] / [7] | `COLORKEY` / `RECOLOR` / `MODE` / `ROUND_CLIP` | 同 BLIT；翻转合入逆矩阵，FLAGS[1] 忽略 |
| 8 / 9[15:0] | `SRC_BASE` / `SRC_STRIDE` | 同 BLIT |
| 10[15:0] / [31:16] | `SRC_W` / `SRC_H` | 源有效像素数 |
| 11 | `PARAM_BASE` | 64 B 参数块 |
| 12[11:0] / 13 / 14[15:0] / 15 | `CLIP_RADIUS` / `PALETTE` / `KEY` / `RC_COLOR+RC_OPA` | 同 BLIT 对应字段 |
| P0–P5 | `U0,V0,DU_DX,DV_DX,DU_DY,DV_DY` | signed32 Q15.16 |
| P6 / P7 | `IMAGE_X0/Y0` / `IMAGE_X1/Y1` | 各字低/高半字为 x/y，signed16，含右下角 |

- SRC_FMT∈{RGB565,ARGB8888,I8,I4,I2,I1}；MODE 4–7 非法。逆矩阵在软件计算。
- 对目标像素中心，`u=U0+(x−X0)DU_DX+(y−Y0)DU_DY`，`v=V0+(x−X0)DV_DX+(y−Y0)DV_DY`，源采用边界坐标，像素中心为 (k+0.5,l+0.5)。signed48 累加保留 Q16，不逐步截回 32 位；软件保证所有中间值不溢出。
- 最近邻取 `(floor(u),floor(v))`。不在 `[0,SRC_W)×[0,SRC_H)` 时透明且不读源 DDR；有效像素按 BLIT 解码（含颜色键/调色板），得到 {As,S_c}。
- 双线性：`s=u−0.5,t=v−0.5,i=floor(s),j=floor(t)`；f、g 为非负小数部分高 8 位，四 tap 顺序为 (i,j)、(i+1,j)、(i,j+1)、(i+1,j+1)，权重为 `(256−f)(256−g),f(256−g),(256−f)g,fg`，和为 65536。
- 各 tap 独立判断源范围；越界取 `{a,p}={0,0}` 且不读越界像素。先颜色键、解码/调色板，RGB565 先 E565，再预乘 `p_c=d(a×S_c)`。`a'=floor((Σw a+32768)/65536)`，p'_c 同式；a'=0 保持目标，否则 `S'_c=min(255,(p'_c Q[a']+32768)>>16)`，令 As=a'、S_c=S'_c。
- 然后 RECOLOR、MODE、over，顺序与 BLIT 相同；`sa=d(d(OPA×As)×C_image)`。ROUND_CLIP=1 时 image_area 取 P6/P7 并按 2.3 求 C_image；半径为 0 或 ROUND_CLIP=0 时 C_image=255。源 alpha 的插值与目标空间圆角相互独立。
- 双线性为 2×2 重建滤波，不包含 mipmap、面积滤波或各向异性滤波；只在最终写回时 P565 一次。AA=0 变换可用最近邻；AA 变换使用双线性并必须通过第 8 节的 LVGL 判据。

## 5. 行为与时序

### 5.1 执行

1. DOORBELL 后，RND 从 `DESC_BASE` 起依次读取并执行 `DESC_COUNT` 条命令。
2. 每条命令按 2.6 检查 `OP` 和格式（第 6 节错误 3），再取所需参数块和执行；参数读、源窗口填充都属于当前命令。
3. 一条命令的最后一个写响应返回后，DONE_COUNT 加 1、CUR_DESC 加 1。下一条命令对 DDR 的读取在此之后才开始，所以后一条命令总能看到前一条写入的结果。
4. 全部完成后置 IRQ_STAT.DONE，回到 IDLE。

### 5.2 数据通路

- alpha 通路：每拍处理 2 个目标像素，吞吐 250 Mpx/s。FILL（非快速情形）、BORDER、GLYPH、BLIT、TILEMAP、BOX_SHADOW 着色都使用这条通路。目标需要先读出原值（读改写）。
- 256 位快速通路：
  - FILL 满足 `GRAD` = 0、`RADIUS` = 0、OPA = 255 时，不读目标，直接写 COLOR（RGB565 写 P565(COLOR)，ARGB8888 写 {255, COLOR}）；
  - COPY 也走这条通路。
  - 每拍一个 256 位 beat，行首、行尾用字节使能。
- G1 独立 coverage 发生器使用两 lane，每 lane 并行四子列、四拍完成四子行；无停顿 AA 峰值为 2 像素/4 拍，即 62.5 Mpx/s。并集/计数结果寄存后进入原混合；背压必须冻结当前像素组与几何行起点。
- G2 的 alpha 和反遮罩乘法分级寄存；MASK_RECT 走目标 alpha 直接写回。新增逻辑不得组合串入原混合关键路径。
- AFFINE 目标以 RECT 原点为锚点按 32×16 块遍历，块按先 x 后 y，块内按先 x 后 y，CLIP 只屏蔽块中的范围外像素；任意块起点均按 2.6 的绝对公式定位，不沿跨块顺序错误累加。
- 源窗口固定 32 个 8×8 块（解码 ARGB8888，共 8 KiB），每命令开始清 valid；不能消费尚未完成填充的数据。源块原始数据按有效行从上到下读取，32 B beat 对齐，仅提取有效源像素，边界外作为透明 tap；边缘 beat 可含未使用字节。
- 最近邻可用原两 lane；双线性固定单 lane，命中及流水稳态峰值 1 像素/拍，即 125 Mpx/s。源窗口与填充暂存合计≤4 DRM；DDR 缺失和仲裁另计，不保证端到端峰值。替换与端口组织由开发者在资源约束下决定。
- 新 RAM 必须使用 rtl/tech 包装，附 fpga/ip 创建说明；其余行缓冲、调色板和瓦片缓存继续复用。

### 5.3 ABORT

`CTRL.ABORT` 写 1：
- 不再读取新命令和数据，已发出的 AXI 事务全部完成后回到 IDLE（SoC 7.1）；
- 正在执行的命令不计入 DONE_COUNT，不置 DONE；
- 目标中已写入的部分保留。
- 参数块读取及源块填充中的 ABORT 同样停止新请求，排空已发事务；未完成源块不得置 valid，后续启动必须清空源窗口 valid。

### 5.4 软件约定

- 一致性（SoC 7.4）：
  - DOORBELL 前，命令列表、参数块和 CPU 写过的源数据/调色板所在的 cache 行必须写回；
  - DONE 后、CPU 读写 RND 写过的区域前，必须作废对应的 cache 行。
  - LVGL 软件绘制单元和 RND 交替写同一缓冲时，按设计记录 rnd-disp 4.3 维护。
- DISP 正在扫描的 Surface 不得作为 RND 的目标（SoC 7.3 R3）。
- 字体、图片、瓦片、调色板和参数块必须放在 DDR（2.1），参数块与命令在完成前保持不变。
- 软件负责几何归一化、top-left 偏置、圆参数量化、包围盒、逆矩阵和起点；硬件不检查参数对齐、坐标范围或溢出。AFFINE 的有效源区域必须完整位于缓冲内，软件必须提供包围源块边缘对齐读取的 DDR 可读范围。
- LVGL 驱动必须认领 G1 单段/圆头几何及水平/竖直三角形渐变，G2 遮罩/bg_cover=0/clip_radius，G3+G4 旋转、斜切、缩放；仍保留原不支持条件（如虚线、points 折线、图像弧填充、复杂渐变、bitmap mask）。

## 6. 错误处理

| ERR_CODE | 错误 | 检测 | 上报 | 恢复 |
|---|---|---|---|---|
| 1 | 读响应非 OKAY | R 通道 | IRQ_STAT.ERROR，CUR_DESC 保持 | 停止执行后续命令，等在途事务完成后回到 IDLE；软件清 ERROR 后可重新启动 |
| 2 | 写响应非 OKAY | B 通道 | 同上 | 同上 |
| 3 | 非法命令：`OP` 不在 2.6 中；`SRC_FMT` 不在该命令允许的范围内；COPY 的 `SRC_FMT` ≠ `DST_FMT`；BLIT 或 AFFINE_BLIT 的 `MODE` 为 4–7 | 命令读入后、访问数据前 | 同上 | 该条不执行，停止执行后续命令 |

参数块读、源窗口填充读的非 OKAY 同属错误 1。MASK_RECT 的 ARGB 目标是软件契约，不新增目标格式错误码。

除上表外不做其他检查（不检查地址越界、裁剪矩形是否在目标内、源与目标是否重叠，见 2.5）。`ERR_CODE` 记录最近一次错误，写 IRQ_STAT.ERROR 清零时一并清除（SoC 7.1）。

## 7. 性能与资源指标

| 项 | 指标 |

AFFINE 源 DDR 读量必须记录为 `Σ失配块 Σ有效行 32 ceil((行首偏移+有效字节)/32)`，调色板启动另计最多 1024 B；不得以窗口容量宣称读放大≤4。对32 B对齐 ARGB源，NN 每目标像素最坏256 B、双线性1024 B（相对4 B像素64/256倍）；任意字节对齐时分别512/2048 B（128/512倍）。索引/RGB565 必须按原始格式实际 beat 单列，不按解码后字节数代替。

## 8. 验证要点

1. 每条命令的像素结果与 Python 参考模型逐位一致：两种目标格式；全部源格式；OPA、α 取 0、255 和中间值；目标 α 取 0、255 和中间值（2.2 over 的分支）。
2. 几何：RECT 部分或全部在 CLIP 外、负坐标、空区域；源和目标的任意字节偏移（行首、行尾跨 beat）；亚字节格式的位偏移。
3. FILL：渐变的两个方向、负步长和饱和；圆角半径 0、1、大于 min(W, H) / 2；多段渐变拼接无缝。
4. BORDER：各种 `SIDES` 组合、宽度大于半径。
5. BLIT：缩放（放大、缩小、`SCALE` 很大）、翻转、颜色键、重新着色、四种混合模式、四种索引格式。
6. COPY：同一缓冲内四个方向的重叠。
7. BOX_SHADOW、BLUR：R = 0、1、31；BLUR 越界取最近像素。
8. TILEMAP：两种瓦片尺寸、翻转、跨瓦片和跨地图行的起点、颜色键、索引格式。
9. 命令顺序：后一条命令读取前一条刚写的区域。
10. 错误：三种错误码；错误后停止、CUR_DESC 正确、无未完成事务；ABORT。
11. AXI：随机背压下协议正确，事务满足 SoC 4.2（首尾对齐、最长 16 拍、不跨 4 KiB）。
12. LVGL 画面：用 LVGL 软件渲染的结果作参考，命令序列在 RND 上的结果逐像素比对，两者的抗锯齿和舍入算法不同，允许的差异由验证方案规定。

13. G1：三角形顺逆/共享边/退化/渐变；水平斜线/零长/两圆头；跨0°/180°/大弧/整圆/重叠圆头；AA 两值、裁剪、背压均与整数模型逐位一致。
14. G2：MASK 的半径0/1/超半边、KEEP_OUTSIDE两值、透明ARGB和负坐标；阴影偏移/扩展与背景挖空独立；BLIT 的 image_area 裁切独立于 RECT/采样。
15. AFFINE：0°/90°/任意角、正负斜切、双轴放缩/翻转、NN/双线性、负坐标和源边界、半像素、透明彩边、四 tap 跨四块、索引/两颜色格式、高频缩小、32×16 目标边界、32 块冲突、命令间重写可见性；参数读/块填充 ABORT 和读错。
16. 硬件相对整数参考模型逐字节0差异。对锁定 LVGL 的同对象/同时刻软件重画，RN-17 原阈值不变：RGB565 每通道计算差，非边缘≤1 LSB，任一通道>1 LSB 的像素≤全图1%。新几何边缘带为两参考几何边界各向内外扩1像素的并集，带内不设单点上限；带外≤1 LSB。ARGB MASK 另逐 alpha 比较，边缘带外≤1/255，带内无单点上限。G4 未通过同一阈值不得宣称 AA 认领验收通过。
17. RN-17 新增旋转、弧和 widgets 帧；主机 profile 中 G1–G4 覆盖任务不得再以这些原因回软件；board_render smoke 必须通过。Yosys 记录资源参考及最长逻辑级数，最终 125 MHz 以 PDS slow setup WNS≥0、TNS=0 定稿。
