## 1. 概述

RND 从 DDR 读取 CPU 准备好的命令列表，依次在 DDR 中的图像缓冲上绘制：填充、边框、字形、位图、搬运、阴影、模糊、瓦片地图。它是 LVGL 绘制单元的硬件后端（设计记录 rnd-disp 4.3），也用来画游戏的瓦片背景和精灵（同 5.2）。

```
APB 槽 4 ─ 寄存器块 ─ 命令执行 ─┬─ 读客户端（命令、源、目标、调色板、瓦片、地图、临时区）─┐
                                 ├─ 2 像素/拍 alpha 通路                                 ├─ dma2d_rd/wr ─ P4
                                 └─ 256 位快速通路（纯色填充、搬运）                     ─┘
```

时钟域：全部在 clk_mem（SoC 5.1）。复位：`rst_mem_n`（系统子系统规格 2.10）。mem_xbar P4（软实时，读写，无紧急信号，SoC 6.4.1），媒体 APB 槽 4，PLIC 源 11。

## 2. 功能描述

### 2.1 像素格式和缓冲

| 编码 | 格式 | 每像素 | 存储 | 可用于 |
|---|---|---|---|---|
| 0 | RGB565 | 16 位 | 小端 16 位，`[15:11]` R、`[10:5]` G、`[4:0]` B | 目标、源、瓦片 |
| 1 | ARGB8888（非预乘，SoC 7.3） | 32 位 | 小端 32 位，`[31:24]` α、`[23:16]` R、`[15:8]` G、`[7:0]` B | 目标、源、瓦片 |
| 2 | A8 | 8 位 | 1 字节 | 字形 |
| 3 | A4 | 4 位 | 字节内第一个像素在高位 | 字形 |
| 4 | A2 | 2 位 | 同上 | 字形 |
| 5 | A1 | 1 位 | 同上 | 字形 |
| 6 | I8 | 8 位 | 调色板索引，字节内高位在前（同上） | 源、瓦片 |
| 7 | I4 | 4 位 | 同上 | 源、瓦片 |
| 8 | I2 | 2 位 | 同上 | 源 |
| 9 | I1 | 1 位 | 同上 | 源 |

- 目标缓冲：基址按像素大小对齐（RGB565 2 B、ARGB8888 4 B），跨距为像素大小的整数倍。
- 源缓冲（BLIT、GLYPH、COPY 的源）：基址和跨距以字节为单位，不要求对齐；亚字节格式每行从一个字节的最高位开始。
- 调色板：2^bpp 项 ARGB8888，基址 4 B 对齐。
- 瓦片数据、瓦片地图、命令列表、临时区的对齐见各命令。
- 坐标：目标像素 (x, y) 位于 `基址 + y × 跨距 + x × 像素字节数`。
- RND 只访问 DDR（SoC 6.1）；交给 DISP 扫描的缓冲还必须满足 SoC 7.3 的 Surface 对齐要求。

### 2.2 像素运算（逐位规定，参考模型与之一致）

| 记号 | 定义 |
|---|---|
| d(x) | (t + (t >> 8)) >> 8，t = x + 128；对 0 ≤ x ≤ 65025 等于 x / 255 四舍五入（与 DISP 2.7 相同） |
| mix(a, F, B) | d(a × F + (255 − a) × B)，逐通道 |
| E565(v) | RGB565 展开为 8 位：R、B `{v[4:0], v[4:2]}`，G `{v[5:0], v[5:4]}`（与 DISP 2.3 相同） |
| P565(R, G, B) | `{R[7:3], G[7:2], B[7:3]}`（截断） |
| Q[a] | ⌊(255 × 65536 + ⌊a / 2⌋) / a⌋，a = 1…255（24 位常数表） |
| An(m) | 亚字节 alpha 展开到 8 位：A4 × 17，A2 × 85，A1 × 255，A8 不变 |

**写入（over）**：每条绘制命令对绘制区域内每个目标像素给出源颜色 S_c（8 位 R、G、B）和源 alpha sa（0–255），按目标格式写回：

- 目标 RGB565，原值 D：D_c = E565(D)；写回 P565(mix(sa, S_c, D_c))。
- 目标 ARGB8888，原值 {Da, D_c}：
  - oa = sa + d((255 − sa) × Da)；
  - oa = 0 时写回 0；否则 r = (sa × Q[oa] + 32768) >> 16，写回 {oa, mix(r, S_c, D_c)}。
  - sa = 255 时结果为 {255, S_c}；Da = 255 时结果为 {255, mix(sa, S_c, D_c)}。
- sa = 0 的像素保持原值（可以不写）。

**混合模式**（只用于 BLIT，`MODE` 字段）：先把源颜色换成 T_c，再按上面的 over 写入：

| MODE | 名称 | T_c |
|---|---|---|
| 0 | 正常 | S_c |
| 1 | 相加 | min(S_c + D_c, 255) |
| 2 | 相减 | max(D_c − S_c, 0) |
| 3 | 相乘 | d(S_c × D_c) |

D_c 为目标原值的 8 位颜色（RGB565 先 E565）。

### 2.3 圆角矩形覆盖率

FILL、BORDER、BOX_SHADOW 使用。矩形宽 W、高 H，半径 r，局部坐标 (i, j)，0 ≤ i < W，0 ≤ j < H：

1. r' = min(r, ⌊min(W, H) / 2⌋)。
2. jd = min(j, H − 1 − j)。若 r' > 0 且 jd < r'：dy = 16 × (r' − jd) − 8，e = 16 × r' − isqrt(256 × r'² − dy²)（isqrt 向下取整）；否则 e = 0。e 是本行边缘向内缩进的距离（Q4）。
3. room = min(16 × i + 16 − e, 16 × W − e − 16 × i)。
4. cov = 0（room ≤ 0），255（room ≥ 16），16 × room（其余）。矩形外 cov = 0。

只在水平方向做抗锯齿（与旧工程 `edrv32_render_round_row.v` 的做法相同）。

### 2.4 盒式模糊

BOX_SHADOW、BLUR 使用。半径 R（0–31），M_R = ⌊(65536 + R) / (2R + 1)⌋：

- 一遍水平模糊：out(i) = (Σ_{k = −R…R} in(i + k) × M_R + 32768) >> 16。
- 一遍竖直模糊同理。
- 先水平、后竖直，逐通道进行；越界取值规则见各命令。
- 结果不超过 255，与精确平均值的误差不超过 0.6。

### 2.5 命令列表

- 命令列表在 DDR 中，起始地址 `DESC_BASE`（64 B 对齐），每条 64 B（16 个 32 位小端字），连续存放。
- 公共字段（W0–W7）：

| 字 | 位 | 字段 | 说明 |
|---|---|---|---|
| 0 | [7:0] | `OP` | 命令码（2.6） |
| 0 | [8] | `DST_FMT` | 目标格式：0 RGB565，1 ARGB8888 |
| 0 | [15:12] | `SRC_FMT` | 源格式（2.1 编码），各命令允许的取值见 2.6 |
| 0 | [31:16] | `FLAGS` | 各命令定义 |
| 1 | [31:0] | `DST_BASE` | 目标缓冲基址（2.1） |
| 2 | [15:0] | `DST_STRIDE` | 目标跨距（字节） |
| 3 | [11:0] / [27:16] | `CLIP_X0` / `CLIP_Y0` | 裁剪矩形左上角（目标像素，含） |
| 4 | [11:0] / [27:16] | `CLIP_X1` / `CLIP_Y1` | 裁剪矩形右下角（含） |
| 5 | [15:0] / [31:16] | `X0` / `Y0` | 图元矩形左上角（有符号 16 位，含） |
| 6 | [15:0] / [31:16] | `X1` / `Y1` | 图元矩形右下角（有符号 16 位，含） |
| 7 | [23:0] / [31:24] | `COLOR` / `OPA` | 颜色 RGB888（[23:16] R）；整体透明度 |

- 图元矩形 RECT = [X0, X1] × [Y0, Y1]，宽 W = X1 − X0 + 1，高 H = Y1 − Y0 + 1。
- **绘制区域** A = RECT ∩ CLIP（BOX_SHADOW 另行规定）；A 为空（含 X1 < X0 或 Y1 < Y0）时命令不访问目标，直接完成。
- 软件必须保证：CLIP 落在目标缓冲内；源、调色板、瓦片和地图的读取范围落在各自的缓冲内；除 COPY 外，源与目标不重叠。RND 不检查这些条件（第 6 节）。
- 未列出的位忽略。

### 2.6 命令

#### 0x01 FILL：纯色或线性渐变填充，可带圆角

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `GRAD` | 1 = 渐变 |
| FLAGS[1] | `GRAD_V` | 0 = 水平（沿 x），1 = 竖直（沿 y） |
| 8 | [11:0] `RADIUS` | 圆角半径 |
| 9 | `GRAD_START` | 渐变起点 ARGB8888（非预乘） |
| 10–13 | `STEP_A`、`STEP_R`、`STEP_G`、`STEP_B` | 每像素增量，有符号 Q8.16 |

- `SRC_FMT` 忽略。
- 渐变：k = x − X0（水平）或 y − Y0（竖直）。通道值 g = clamp((START × 65536 + k × STEP + 32768) >> 16, 0, 255)，START 为该通道的起点。
- S_c = COLOR（`GRAD` = 0）或 g_R、g_G、g_B（`GRAD` = 1）。
- a0 = 255（`GRAD` = 0）或 g_A（`GRAD` = 1）。
- sa = d(d(OPA × a0) × cov)。cov 按 2.3 对 RECT 和 `RADIUS` 计算；`RADIUS` = 0 时 cov = 255。
- 多段渐变由软件拆成多条 FILL：RECT 和 `RADIUS` 相同，CLIP 各取一段。

#### 0x02 BORDER：圆角边框

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | [11:0] `RADIUS` | 外缘半径 |
| 9 | [11:0] `WIDTH` | 边框宽度 BW |
| 9 | [19:16] `SIDES` | bit0 上，bit1 下，bit2 左，bit3 右 |

- `SRC_FMT` 忽略。
- 外缘：RECT，半径 `RADIUS`，有效半径 r'（2.3 第 1 条）。
- 内缘矩形：
  - `SIDES` 中选中的边，从 RECT 向内缩进 BW；
  - 未选中的边，向外扩出 r' + 1；
  - 内缘半径 max(r' − BW, 0)。
- cov_o、cov_i 分别按 2.3 对外缘和内缘计算。
- S_c = COLOR，sa = d(OPA × d(cov_o × (255 − cov_i)))。

#### 0x03 GLYPH：字形或掩码着色

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | `SRC_BASE` | 掩码基址（字节） |
| 9 | [15:0] `SRC_STRIDE` | 掩码跨距（字节） |
| 10 | [15:0] / [31:16] | `SRC_X` / `SRC_Y`：与 (X0, Y0) 对应的掩码像素 |

- `SRC_FMT` ∈ {A8, A4, A2, A1}。
- 目标像素 (x, y) 取掩码 m = (`SRC_X` + x − X0, `SRC_Y` + y − Y0) 处的值。
- S_c = COLOR，sa = d(OPA × An(m))。

#### 0x04 BLIT：位图绘制

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] / [1] | `HFLIP` / `VFLIP` | 水平 / 竖直翻转 |
| FLAGS[2] | `COLORKEY` | 1 = 源 RGB565 等于 `KEY` 的像素视为透明 |
| FLAGS[3] | `RECOLOR` | 1 = 重新着色 |
| FLAGS[6:4] | `MODE` | 混合模式（2.2），4–7 非法 |
| 8 | `SRC_BASE` | 源基址（字节） |
| 9 | [15:0] `SRC_STRIDE` | 源跨距（字节） |
| 10 | [15:0] / [31:16] | `SRC_X` / `SRC_Y` |
| 11 / 12 | `SCALE_X` / `SCALE_Y` | 每个目标像素的源步长，无符号 Q16.16；0x0001_0000 为 1:1 |
| 13 | `PALETTE` | 调色板基址（索引格式） |
| 14 | [15:0] `KEY` | 颜色键（RGB565） |
| 15 | [23:0] / [31:24] | `RC_COLOR` / `RC_OPA`：重新着色的颜色和比例 |

- `SRC_FMT` ∈ {RGB565, ARGB8888, I8, I4, I2, I1}。
- 采样（最近邻）：
  - kx = x − X0（`HFLIP` = 0）或 X1 − x（`HFLIP` = 1）；
  - u = `SRC_X` + ((kx × `SCALE_X`) >> 16)；
  - v 同理，用 y、Y0/Y1、`VFLIP`、`SRC_Y`、`SCALE_Y`；
  - 取源像素 (u, v)。
- 源像素换算为 {As, S_c}：
  - RGB565：As = 255，S_c = E565；`COLORKEY` = 1 且像素值等于 `KEY` 时 As = 0。
  - ARGB8888：直接取用。
  - 索引格式：取调色板中对应的一项。
- `RECOLOR` = 1：S_c = mix(`RC_OPA`, `RC_COLOR`_c, S_c)。
- 按 `MODE` 得 T_c；sa = d(OPA × As)。
- LVGL 的 IMAGE 和 LAYER 任务都映射到 BLIT（设计记录 rnd-disp 4.2）。

#### 0x05 COPY：同格式矩形搬运

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | `SRC_BASE` | 源基址 |
| 9 | [15:0] `SRC_STRIDE` | 源跨距 |
| 10 | [15:0] / [31:16] | `SRC_X` / `SRC_Y` |

- `SRC_FMT` 必须等于 `DST_FMT`。
- 目标像素 (x, y) = 源像素 (`SRC_X` + x − X0, `SRC_Y` + y − Y0)，逐位复制，包括 alpha；COLOR、OPA 忽略。
- 源和目标可以在同一缓冲内重叠：结果与"先读完整个源区域、再写目标"相同。

#### 0x06 BOX_SHADOW：圆角阴影

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | [11:0] `RADIUS` | 阴影形状的圆角半径 |
| 9 | [4:0] `BLUR` | 模糊半径 R（0–31） |
| 10 | `TEMP_BASE` | 临时区基址（32 B 对齐） |

- `SRC_FMT` 忽略。
- RECT 是阴影形状（已含扩展和偏移，由软件计算）。
- 扩展网格：RECT 四边各向外扩 R，尺寸 (W + 2R) × (H + 2R)。
- 掩码 m：
  1. 网格上按 2.3 求 RECT 的 cov（RECT 外为 0）；
  2. 按 2.4 做水平、竖直两遍模糊，网格外取 0。
- 绘制区域为扩展网格 ∩ CLIP；S_c = COLOR，sa = d(OPA × m)。
- 临时区：
  - 大小 2 × S × (H + 2R) 字节，S = 32 × ⌈(W + 2R) / 32⌉；
  - 命令完成后内容不作规定；
  - 不得与目标重叠。

#### 0x07 BLUR：区域模糊

| 字 | 字段 | 说明 |
|---|---|---|
| 8 | [4:0] `BLUR` | 模糊半径 R（0–31） |
| 9 | `TEMP_BASE` | 临时区基址（32 B 对齐） |

- `SRC_FMT`、COLOR、OPA 忽略。
- 对绘制区域 A 的目标像素原地做 2.4 的两遍模糊，越界时取 A 内最近的像素。
- 逐通道处理：
  - ARGB8888 处理 α、R、G、B 四个通道；
  - RGB565 先 E565，结果按 P565 写回。
- 两遍之间的中间结果：水平遍的输出逐通道保留 8 位，竖直遍在此基础上计算；RGB565 目标只在最后写回时按 P565 截断一次。
- 临时区：每像素 4 B（RGB565 目标存 {0, R, G, B}，ARGB8888 目标存 {α, R, G, B}），大小为 32 × ⌈4 × A 的宽度 / 32⌉ × A 的高度字节；不得与目标重叠。

#### 0x08 TILEMAP：瓦片地图

| 字 | 字段 | 说明 |
|---|---|---|
| FLAGS[0] | `TILE16` | 0 = 8 × 8 瓦片，1 = 16 × 16 瓦片 |
| FLAGS[2] | `COLORKEY` | 同 BLIT |
| 8 | `TILE_BASE` | 瓦片数据基址（32 B 对齐） |
| 9 | `MAP_BASE` | 地图基址（32 B 对齐） |
| 10 | [15:0] `MAP_STRIDE` | 地图跨距（字节，偶数） |
| 11 | [15:0] / [31:16] | `MAP_X` / `MAP_Y`：与 (X0, Y0) 对应的地图像素坐标 |
| 13 | `PALETTE` | 调色板基址（索引格式） |
| 14 | [15:0] `KEY` | 颜色键 |

- `SRC_FMT` ∈ {RGB565, ARGB8888, I8, I4}（瓦片格式）。
- 瓦片边长 T = 8 或 16。
- 瓦片存储：瓦片 t 的数据位于 `TILE_BASE` + t × B，B = T² × bpp / 8 字节（都是 32 的倍数）；行连续存放，像素顺序按 2.1。
- 地图项：16 位小端，[11:0] 瓦片号，[12] 水平翻转，[13] 竖直翻转，[15:14] 忽略。
- 目标像素 (x, y)：
  1. mx = `MAP_X` + x − X0，my = `MAP_Y` + y − Y0；
  2. 地图项 E 位于 `MAP_BASE` + ⌊my / T⌋ × `MAP_STRIDE` + 2 × ⌊mx / T⌋；
  3. 瓦片内坐标 tx = mx mod T、ty = my mod T，翻转位为 1 时分别取 T − 1 − tx、T − 1 − ty；
  4. 取瓦片 E[11:0] 的像素 (tx, ty)，按 BLIT 的规则换算为 {As, S_c}（含 `COLORKEY`、调色板）。
- sa = d(OPA × As)，正常模式。

- `dma2d` 实例数和各自的 `OUTSTANDING` 由开发者在第 7 节的吞吐和资源约束下决定，写进设计记录。

## 4. 寄存器

媒体 APB 槽 4。公共寄存器按 SoC 7.1；寄存器块忽略 `pstrb`，按整字写（SoC 4.3）。未列出的偏移读为 0、写忽略。

### 4.1 公共寄存器

| 偏移 | 名称 | 规定 |
|---|---|---|
| 0x000 | ID | 0x0004_0001 |
| 0x004 | CTRL | bit0 ENABLE：可读写，不门控 DOORBELL；bit1 START 无作用；bit2 ABORT（5.3）；bit3 SOFT_RST：只在 IDLE 时生效，把全部寄存器和控制状态恢复到复位值 |
| 0x008 | STATUS | BUSY = 正在执行命令列表或有未完成的 AXI 事务；IDLE = 非 BUSY；ERROR = IRQ_STAT.ERROR |
| 0x00C | IRQ_EN | 复位 0 |
| 0x010 | IRQ_STAT | bit0 DONE；bit1 ERROR |
| 0x014 | ERR_CODE | 第 6 节 |
| 0x020 | DESC_BASE | [31:6]，[5:0] 读为 0 |
| 0x024 | DESC_COUNT | [15:0] 命令条数，其余位读为 0 |
| 0x028 | DOORBELL | 写任意值启动；STATUS.BUSY = 1 时写入被忽略；DESC_COUNT = 0 时立即置 DONE |
| 0x02C | DONE_COUNT | 已完成的命令条数（自增，回绕） |
| 0x040–0x07C | PERF | 4.3 |

### 4.2 私有寄存器

| 偏移 | 名称 | 访问 | 复位值 | 说明 |
|---|---|---|---|---|
| 0x100 | CUR_DESC | RO | 0 | 正在执行（或因错误停止时）的命令序号，从 0 起；正常完成后为 DESC_COUNT |

### 4.3 性能计数器

32 位，回绕；每次 DOORBELL 清零。

| 编号 | 内容 |
|---|---|
| PERF0 | 从 DOORBELL 到 DONE 或停止的总周期；ABORT 或错误后计到 STATUS.BUSY 清零为止 |
| PERF1 | 绘制区域内处理的目标像素数 |
| PERF2 | 读 beat 数（命令、源、目标、调色板、瓦片、地图、临时区） |
| PERF3 | 写 beat 数 |
| PERF4 | alpha 通路因读数据未就绪而等待的周期 |
| PERF5 | alpha 通路因写出侧不接收而等待的周期 |
| PERF6–15 | 读为 0 |

## 5. 行为与时序

### 5.1 执行

1. DOORBELL 后，RND 从 `DESC_BASE` 起依次读取并执行 `DESC_COUNT` 条命令。
2. 每条命令按 2.6 检查 `OP` 和格式（第 6 节错误 3），再执行。
3. 一条命令的最后一个写响应返回后，DONE_COUNT 加 1、CUR_DESC 加 1。下一条命令对 DDR 的读取在此之后才开始，所以后一条命令总能看到前一条写入的结果。
4. 全部完成后置 IRQ_STAT.DONE，回到 IDLE。

### 5.2 数据通路

- alpha 通路：每拍处理 2 个目标像素，吞吐 250 Mpx/s。FILL（非快速情形）、BORDER、GLYPH、BLIT、TILEMAP、BOX_SHADOW 着色都使用这条通路。目标需要先读出原值（读改写）。
- 256 位快速通路：
  - FILL 满足 `GRAD` = 0、`RADIUS` = 0、OPA = 255 时，不读目标，直接写 COLOR（RGB565 写 P565(COLOR)，ARGB8888 写 {255, COLOR}）；
  - COPY 也走这条通路。
  - 每拍一个 256 位 beat，行首、行尾用字节使能。
- 片上缓冲（行缓冲、调色板、瓦片缓存）的组织由开发者在第 7 节约束下决定，写进设计记录。

### 5.3 ABORT

`CTRL.ABORT` 写 1：
- 不再读取新命令和数据，已发出的 AXI 事务全部完成后回到 IDLE（SoC 7.1）；
- 正在执行的命令不计入 DONE_COUNT，不置 DONE；
- 目标中已写入的部分保留。

### 5.4 软件约定

- 一致性（SoC 7.4）：
  - DOORBELL 前，命令列表和 CPU 写过的源数据所在的 cache 行必须写回；
  - DONE 后、CPU 读写 RND 写过的区域前，必须作废对应的 cache 行。
  - LVGL 软件绘制单元和 RND 交替写同一缓冲时，按设计记录 rnd-disp 4.3 维护。
- DISP 正在扫描的 Surface 不得作为 RND 的目标（SoC 7.3 R3）。
- 字体、图片、瓦片和调色板必须放在 DDR（2.1）。

## 6. 错误处理

| ERR_CODE | 错误 | 检测 | 上报 | 恢复 |
|---|---|---|---|---|
| 1 | 读响应非 OKAY | R 通道 | IRQ_STAT.ERROR，CUR_DESC 保持 | 停止执行后续命令，等在途事务完成后回到 IDLE；软件清 ERROR 后可重新启动 |
| 2 | 写响应非 OKAY | B 通道 | 同上 | 同上 |
| 3 | 非法命令：`OP` 不在 2.6 中；`SRC_FMT` 不在该命令允许的范围内；COPY 的 `SRC_FMT` ≠ `DST_FMT`；BLIT 的 `MODE` 为 4–7 | 命令读入后、访问数据前 | 同上 | 该条不执行，停止执行后续命令 |

除上表外不做其他检查（不检查地址越界、裁剪矩形是否在目标内、源与目标是否重叠，见 2.5）。`ERR_CODE` 记录最近一次错误，写 IRQ_STAT.ERROR 清零时一并清除（SoC 7.1）。

## 8. 验证要点

1. 每条命令的像素结果与 Python 参考模型逐位一致：两种目标格式；全部源格式；OPA、α 取 0、255 和中间值；目标 α 取 0、255 和中间值（2.2 over 的分支）。
2. 几何：RECT 部分或全部在 CLIP 外、负坐标、空区域；源和目标的任意字节偏移（行首、行尾跨 beat）；亚字节格式的位偏移。
3. FILL：渐变的两个方向、负步长和饱和；圆角半径 0、1、大于 min(W, H) / 2；多段渐变拼接无缝。
4. BORDER：各种 `SIDES` 组合、宽度大于半径。
5. BLIT：缩放（放大、缩小、`SCALE` 很大）、翻转、颜色键、重新着色、四种混合模式、四种索引格式。
6. COPY：同一缓冲内四个方向的重叠。
7. BOX_SHADOW、BLUR：R = 0、1、31；BLUR 越界取最近像素。
8. TILEMAP：两种瓦片尺寸、翻转、跨瓦片和跨地图行的起点、颜色键、索引格式。
9. 命令顺序：后一条命令读取前一条刚写的区域。
10. 错误：三种错误码；错误后停止、CUR_DESC 正确、无未完成事务；ABORT。
11. AXI：随机背压下协议正确，事务满足 SoC 4.2（首尾对齐、最长 16 拍、不跨 4 KiB）。
12. LVGL 画面：用 LVGL 软件渲染的结果作参考，命令序列在 RND 上的结果逐像素比对，两者的抗锯齿和舍入算法不同，允许的差异由验证方案规定。
