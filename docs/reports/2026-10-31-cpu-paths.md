# CPU 三条长路径（C6，2026-10-31）

基线 b3 `034885e6`；改后 RTL `432b0151`。协调者确认顶层为 `edrv32_cpu_subsys`、RVC_EN=0。
Yosys 0.70+219、ABC LUT6、无时钟约束；FPGA_MODE，8 个 RAM IP 与乘法 IP 黑盒，方法同 rnd-opt1；Verilator 5.020 / Icarus。
PG2L200H-6 的 PDS 映射、WNS 和布线结果未取得；下面是通用 LUT6 参考级数，包含寄存器使能路径。

|版本|LUT6|FF|全局最长级数|
|---|---:|---:|---:|
|改前|41139|13681|30|
|改后|41508|13765|31|

|路径过滤（省略 u_target 前缀）|改前|改后|
|---|---:|---:|
|CSR 地址 `u_core.m_instr_r[31:20]` / 寄存选择 `m_csr_select_r` → `u_csr`|16|11|
|`u_dcache.lookup_valid[01]_bank_r` → `e_record/value/pc_target/jalr_expected*_r`|19|10|
|`u_core.e_operand_a_r` → `u_icache.lookup_bank/slot_r`|26|无组合路径|
|`u_core.e_operand_a_r` → 整个 `u_frontend`（含预测器）|29|31|

- CSR：D 生成 40 位独热读选择与 implemented/readonly 位，E/M 同步传递；M 仅选择现有 CSR 状态，保留提交、异常优先级与计数器写覆盖。
- D$：EX 的记录、异常负载、PC 目标及 JALR 预测比较操作数，采用与操作数相同的空闲负载使能；早期 hold 条件与晚到握手分开，valid/issue/停顿行为不变。保留原前递优先级和数据 mux。
- JALR：I$ 在自身 ready 时预采样组索引，缺失期间保持；F2 在没有响应所有者或当前响应结束时预采样元数据，重定向取消仍由 valid 控制，没有新增流水级。
- LUT6 +369（+0.90%）、FF +84；目标路径缩短，但全局最长链 +1，改后是分支比较/重定向到预测器 RAS 使能，不能据此宣称整核频率提升。
- 原 `m_instr_r[31:20]` 到 CSR 仍有 13 级系统指令/事件控制路径；CSR 地址数据 mux 已改由 `m_csr_select_r` 驱动。

性能：R-01..05、RVC_EN=0/1、读延迟 2、GCC 15.2.0 -O2；R-05 取 Total ticks，其余取 B2_WINDOW。
