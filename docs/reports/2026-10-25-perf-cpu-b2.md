## R-05 CoreMark

所有配置都是复位后运行一次、10 次迭代、`MEM_STATIC`、单 context、2000 字节数据区（每算法报告的 size 为 666）、volatile seeds `0/0/0x66`。计时取程序 `Total ticks`，归一化公式为：

```text
CoreMark/MHz = iterations × 1,000,000 / cycles = 10,000,000 / Total ticks
```

HPM 使用 `start_time` 入口退休到 `stop_time` 入口退休的窗口（`window=0`），包含正常计时调用边界，不包含 CRC 校验和控制台输出。各配置这个窗口的周期数均恰好等于对应 `Total ticks`。16 类事件由 B2 对 CPU 事件总线并行计数，避免为第二批事件重跑工作负载；物理 HPM3–10 配置为事件 1–8，CSR 快照原文也保留在日志中。`window=total` 的整机计数另在日志中，未与计时窗口混用。
