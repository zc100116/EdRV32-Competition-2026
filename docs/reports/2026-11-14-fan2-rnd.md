# T-FAN2-RND 同拍控制复制
基线 `8c72c731`；改后为本报告所在提交；交付前 rebase 到最新 `zc100116/b3`。
工具：Verilator 5.020，Yosys 0.70+219；SIM_MODE、RAM/变量乘法黑盒、ABC LUT6。
目标 PG2L200H-6，时钟不变；以下是逻辑参考，不是 PDS 器件映射或布线结果。
新增26份4位FSM（命令10、捕获8、结果选择8），统一装载 state_next_w；加原4份mux共30份副本，另有主状态。
新增4份32位command控制、4个half、8对alpha末级valid/bank、8个BLIT bank；RTL新增260位寄存器。
参考映射FF 12949→13207（+258），LUT6 26370→26659（+289）；RAM和变量乘法器数量不变。
每拍复位/使能/更新条件不变，无新增流水级；DRAW原3处跨generate引用改为显式region_step连线。

| 目标 | Yosys原扇出 | 改后原网；每份副本扇出 |
|---|---:|---|
| cancel_region[6] / u_write.abort_i | 46 | 80；组合stop副本被合并，未证实改善 |
| u_write.stop_w | 8 | 8个别名各19（同一物理网，不能视为8份） |
| state_r（RTL 4位，从LSB起） | 5,9,5,7 | 6,9,6,8；18份capture各2,2,1,1，8份result各1,1,1,1 |
| blend_tag[31] | 8 | 9；alpha bank副本0–6各2、副本7为9（与原输出别名） |
| blend_valid | 2 | 3；alpha valid副本0–6各1、副本7为3（与原输出别名） |
| BLIT render_bank | 520 | 7；8份各64 |
| start | 53 | 52（未改RTL，映射差异） |
| command_control[2][8] | 84 | 52；4份FILL格式各32 |

结果RAM数据选择每份64位；PDS独热第5位对应状态未取得，经协调者同意按RTL最大负载S_FETCH_WAIT拆分。
start由当拍APB译码产生，无可复制的本地源寄存器；经协调者同意保留，不增加一拍。
DMA经协调者授权只复制组合stop/abort锁存使能、按WSTRB等负载组分配；Yosys合并副本，PDS保留效果待测。
复现：`. ~/.local/opt/edrv32/env.sh` 后，`python3 tools/synth/fanout_rnd.py build/fan2-rnd/before --revision 8c72c731`；改后同命令改目录after、不传revision。
原始网表/日志/逐位负载：`build/fan2-rnd/{before,after}/rnd/{hardnet.json,loads.tsv,target-loads.txt,*.ys,*.log}`。
风格：`python3 tools/check/verilog_style.py rtl/media/rnd rtl/common/edrv32_dma2d_wr.v`，11文件0告警；diff检查通过。
Lint：`python3 verif/unit/npu_post_tail/lint.py`复现SoC/FPGA；RND/ETH/GEO/VIN各用 `verilator --lint-only --timing -Wall -j 1 -DSIM_MODE --top-module edrv32_<模块> -F rtl/filelists/<模块>.f`，全部0告警；最终独立日志 `build/fan2-rnd/*.lint.log`。
单元：`python3 tools/regress.py full --path verif/unit/rnd_engine -j 1`；`python3 tools/regress.py full --path verif/unit/dma2d_wr -j 1`：rnd_engine 3 PASS、dma2d_wr 4 PASS，0 FAIL（各执行一次）。
只运行上述两个单元各一次，无模块/SoC仿真；alpha单元仅按协调者授权补两行新输出接空，不运行。
