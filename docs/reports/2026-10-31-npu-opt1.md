# NPU 第 1 档优化与重量化复用测量（2026-10-31）

基线 `034885e6`；改后 `f4ec9a78`；追加规格 `1c38d04f` 已 cherry-pick 为 `5db8f704`。Yosys 0.70+219 / Verilator 5.020；NPU 150 MHz、mem 125 MHz，PG2L200H-6 的逻辑参考，RAM/APM 包装按寄存黑盒切断，ABC LUT6；未取得 PDS WNS/器件映射资源。
全 NPU 参考 LUT6/FF/最长级数：44108/35623/24 → 42456/37563/24；最大非时钟/外部复位扇出 2085→1039。最长链仍在 conv_write 地址加法，级数未变，物理 Fmax 尚未测量。R4 valid/first 最大负载 2050/2048→66/64，fold 1248→40，ACC valid 2085→37，quant valid 663→2，A4 valid 810→2。
实现：本地保留各通道/量化 lane 的控制、相位、零点副本；window/WB/量化装配载荷自由推进，背压沿用 32 对结果预留额度；命令基址和算子描述符本地锁存，描述符选基址/求和分两拍，装载地址改用独立平面基址；PERF 事件与 DOORBELL 清零延后一拍。MAC→accum 新增 32-bit sum_fold 内部接口（协调者 2026-10-31 同意），端到端流水延迟未增加。
APB（SoC 4.3）：setup 寄存 paddr/pwrite/pwdata/pstrb，access 仅用本地值；npu_regs 独立 LUT6 综合后的公共输入负载 paddr[2] 5→1、pwdata[0] 2→1，访问拍数不变。
验证：风格及 top/TB 两分支 lint 0 告警；unit smoke 11/11（accum/mac_array/residual_add/window/descriptor/conv/nonconv/datapath/top/result_quant/regs）；block smoke 22/22，perf 1/1；board_npu smoke 1/1。算子、整网检测头均通过原有 Python 参考逐字节比对，未删减测试项。
NET-02 PERF0 改前→改后（zero / latency94 / BW1.4GB/s）：6010288→6010288 / 6251055→6251055 / 6955048→6955048；doorbell→IRQ：6010285 / 6251052 / 6955045，前后相同。
复现（先 source env.sh，本机仿真加 `flock /tmp/edrv32-sim.lock`）：`python3 verif/block/npu/synth.py [checkout]`；`for u in accum mac_array residual_add window descriptor conv nonconv datapath top result_quant regs; do python3 tools/regress.py smoke --path verif/unit/npu_$u -j 1; done`；`for t in smoke perf; do python3 tools/regress.py $t --path verif/block/npu -j 1; done`；`python3 tools/regress.py smoke --path verif/soc/board_npu -j 1`。网表/扇出：各 checkout 的 `build/npu-opt1/synth/`；仿真日志：`build/regress/{smoke,perf}/` 与 `build/npu/yolo/run_{0,1,2}.log`。
