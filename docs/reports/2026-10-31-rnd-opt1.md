# RND 第 1 档优化测量（2026-10-31）

改前 b3 `7c056b66`；改后 RTL `6fc9b534`；Yosys 0.70+219 / Verilator 5.020；125 MHz，无等待 DDR及读延迟40拍。 方法同 rnd-v2：FPGA_MODE、RAM/变量乘法黑盒、ABC LUT6；非器件映射，PG2L200H-6 原生资源/WNS/布线时间未取得。

参考 LUT6 +857、FF +2618，最长链 −1 级；非时钟/外部复位最大扇出 3569→881。

- R1：geometry/filter 改为自由推进的逐级 valid，8/16 项出口 FIFO 以在途预留额度限流，旁路保持原延迟。
- R2：启动阶段本地锁存模式、圆/边增量，并以不同既有 setup 状态保留模式副本；综合后 8 个 AA 副本独立。
- R3：geometry 的 STEP/子列常数乘改为定宽移位加，常数乘节点 28→0，变量乘节点 108→108（保留双线性权重）。
- R4：window 标签相等先寄存、次级归约并选替换槽；draw 提前寄存跨 beat 判断与下一源 beat 地址。
- R5：COPY 字级移位寄存后再做字节级移位，64 位分片独立锁存字节选择；读写稳态仍每拍一 beat。

验证：风格/lint 0 告警；最终模块 smoke 42/42、改前/后 perf 各33/33、COPY十二项 PASS；五项单元 PASS，board_render PASS（BIOS/IDs/PLIC11/DDR64×4）。 长背压：geometry 原350组 PASS；filter 原TB仅将背压改为每97拍阻塞73拍，2100样本 PASS。
G1：16384/32885=0.498221 px/拍；三种格式双线性 identity 命中各16768/16768=1.000000，改前=改后（排除前12拍、缺失及行边界）。

```sh
python3 tools/check/verilog_style.py rtl/media/rnd rtl/tech; (cd rtl/filelists && verilator --lint-only -Wall -DSIM_MODE --top-module edrv32_rnd -f rnd.f)
for u in rnd_geometry rnd_window rnd_filter rnd_affine rnd_mask; do flock /tmp/edrv32-sim.lock python3 tools/regress.py smoke --path verif/unit/$u -j 1; done
for t in smoke perf; do flock /tmp/edrv32-sim.lock python3 tools/regress.py $t --path verif/block/rnd -j 1; done; flock /tmp/edrv32-sim.lock python3 tools/regress.py smoke --path verif/soc/board_render -j 1
mkdir -p build/rnd-opt1/filter-stress; sed 's/cycle%7 != 0/cycle%97 < 24/;s/cycle > 20000/cycle > 40000/' verif/unit/rnd_filter/tb.sv > build/rnd-opt1/filter-stress/tb.sv; flock /tmp/edrv32-sim.lock bash -c 'verilator --binary --timing -j 1 -DSIM_MODE --top-module tb -Irtl/include --Mdir build/rnd-opt1/filter-stress-obj rtl/media/rnd/edrv32_rnd_filter.v build/rnd-opt1/filter-stress/tb.sv && build/rnd-opt1/filter-stress-obj/Vtb'
flock /tmp/edrv32-sim.lock python3 -c 'import sys,subprocess; from pathlib import Path; sys.path.insert(0,"verif/block/rnd"); from vectors import generate,selections; [subprocess.run(["build/rnd/obj/sim","+CONFIG="+str(generate(Path("build/rnd-opt1/copy")/str(i),*case))],check=True) for i,case in enumerate(c for c in selections("directed") if c[0]==10)]'

python3 -c 'import collections,json,sys; m=json.load(open(sys.argv[1]))["modules"]["edrv32_rnd"]; c=collections.Counter(b for v in m["cells"].values() for p,bs in v["connections"].items() if v["port_directions"][p]=="input" for b in bs if isinstance(b,int)); s={b for p in ("clk_mem_i","rst_mem_n_i") for b in m["ports"][p]["bits"]}; [print(min((v["hide_name"],len(f"{k}[{i}]"),f"{k}[{i}]") for k,v in m["netnames"].items() for i,b in enumerate(v["bits"]) if b==bit)[2],load) for bit,load in [(b,v) for b,v in c.most_common() if b not in s][:10]]' "$NETLIST" # 依次指向前/后 hardnet.json
```
