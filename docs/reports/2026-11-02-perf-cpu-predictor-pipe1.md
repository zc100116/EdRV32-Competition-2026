资源估算（RVC=0 规格字段，不含比较/写译码/检查点/复位逻辑）：BTB 位数 S=B×[(29−log2B)tag+32target+1位置+3类型+1valid]=B(66−log2B)，B=32/64/128/256 → 1952/3840/7552/14848 位；当前 RTL 额外保留压缩长度和位置位，再加 2B 位。
PHT=2G，G=512/1024/2048/4096 → 1024/2048/4096/8192 位；GHR=9/10/11/12 位；RAS 含指针/计数=32R+2log2R+1 → 133/263 位；全 FF 存储估算=S+2G+log2G+RAS（含 BTB valid），默认 3118、256/4096/4 为 23185 FF。
全 FF 读选择 LUT6 估算（N=深度，W=位宽）：W×ceil((N−1)/3)，BTB 约 671/1260/2537/4930 LUT，PHT 约 342/682/1366/2730 LUT，另加写译码/使能与 RAS；不是 PDS 实测。
分布式 RAM 容量估算（假设每 64×1 占 1–2 LUT）：K=ceil(N/64)，LUT≈W×K×(1–2)+W×ceil((K−1)/3)；BTB 数据 W=(S/B−1) → 60–120/59–118/174–290/285–513 LUT，valid 用 B FF；PHT W=2 → 22–38/42–74/86–150/170–298 LUT，另有 GHR/RAS FF；256/4096/4 合计约 455–811 LUT、401 FF。全表复位和端口代价另计，当前 PHT 复位实现不能直接映射此 RAM 估算。
