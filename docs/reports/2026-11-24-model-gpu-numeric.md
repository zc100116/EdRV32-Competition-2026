## 结论

推荐并作为模型默认值：MVP 保留 32bit/s15.16，裁剪坐标 40bit/16 小数，W_NEAR=1/16、G=4，倒数 10bit ROM+1 次 Newton、log2 8bit 索引 ROM。
该组合相对浮点：覆盖异或 276/559772（0.0493%），UV RMS 0.04439 纹素，深度 RMS 0.8187 个 u16 单位，LOD RMS 0.003040 级，光照 RMS 0.3482 个 u8 单位。
结论是数值与位宽建议，尚非用户定稿；研究参数按 Task 要求保留，S-1 确认规格后另开任务删除候选参数。

## 条件与误差口径
固定种子20261124，640×360整图参考目标（物理条带另测）；146 个源三角形：随机共享网格 96，地面/墙面各 2，远处小三角形 32，跨近平面 8，保护带附近 6。
地面、墙面的远近 W 比均为 256；输入矩阵、法线、颜色、UV 见 numeric.py，浮点以同一份已编码输入为理想值。
浮点路径独立实现变换、裁剪、投影、覆盖、商法则导数和属性插值；理想屏幕坐标不量化，log2 用 math.log2。
覆盖为逐源三角形的像素集合异或总数；其余在共同覆盖像素上统计，UV 合并 u/v，光照合并 RGB；下表每格为 最大值 / RMS。
深度单位为 u16 最低位，LOD 单位为 mip 级，光照单位为 u8 最低位；LOD 比较前都夹到 [0,8]。

| 8/0；4 | 2093 | 55.36 / 0.2059 | 107.9 / 56.38 | 0.1856 / 0.03126 | 24.98 / 0.3591 |
| 10/1；4 | 276 | 9.759 / 0.04439 | 19.07 / 0.8187 | 0.2382 / 0.03121 | 6.284 / 0.3482 |

独立单元扫描：8193 个 Q16 W∈[1/256,8192]；两种倒数最大相对误差为 1.953e-3、3.649e-6；UV=65535/256 的未量化恢复误差最大为 0.4782、6.122e-5 纹素。
log2 单元扫描 65536 个 [1,2) 输入：4/8bit 索引的最大误差为 0.08744/0.007299 级；场景 LOD RMS 从 0.03121 降到 0.003040。
成本估算：种子 ROM 每项 30bit，总 ROM（含 log2）为 7808/30848/32768bit；一次 Newton 需两次 31×31 乘法，约 8 个并行或 4 个复用的 18×18 块。
上述乘法块均为抽象 18×18 DSP 分块估算，不是 Pango 综合结果；未计移位、加法、除法器、插值器和流水线复制，不能当作整机 DSP 数。

## 建议补入规格的算术定义

1. 中间加乘与累加精确扩展；MVP 四项完整累加后统一舍入到坐标格式，并按该有符号位宽饱和。矩阵从 s15.16 输入，研究低精度版本先舍入系数并饱和到(16+小数位)bit。
2. 除法/右移统一最近舍入、正负精确半值远离零；有符号输入先处理符号。对象速度/位置按各自 16/24bit 二补码回绕。
3. 裁剪顺序为近、左、右、下、上；交点每分量 (a*db-b*da)/(db-da) 独立舍入，原始 U/V 保持 Q8，颜色保持 Q16；此对称式使共享边方向不影响交点。
4. q：正数归一化到 [1,2) Q30，索引向下取整，ROM 种子取区间中点的倒数并舍入 Q30；每次 r*(2-m*r) 的两个乘法结果分别舍入 Q30，再移位恢复量级。
5. 屏幕 s12.4 明确为 17bit（符号1+整数12+小数4），按视口公式一次舍入并饱和；深度舍入后夹到 [0,65535]。
6. 正面积三角形使用向上边或向右水平边为左上边，边值 0 仅该边包含；退化面积为 0 丢弃；边函数保留全精度，按对齐 4 像素组逐行。
7. 屏幕属性用整数边权/面积精确计算后舍入；q 为 Q30，uq/vq 为 UQ8*q，透视校正再调用同一倒数单元，最终 UV 舍入到 Q8，颜色从 Q16 舍入到 u8。
8. 顶点光照点积保留 Q21，颜色按 c*(ambient*2^21+dot*direction)/(255*2^21) 一次舍入并饱和；颜色在屏幕上仿射插值。
9. 商法则偏导的绝对值舍入 Q16，四个分量取最大跨度；log2 为最高1位置加 floor-index ROM，ROM 值舍入 Q8；跨度=0约定基础LOD=0；LOD加s3.4偏置后夹到级数范围，选级取floor。
10. 双线性以 floor(u),floor(v) 为左上，Q8 小数作权重，无半纹素平移；四项完整累加后舍入。各级先以坐标右移缩放，再环绕，三线性分别双线性后一次加权舍入。
11. 调色板先 E565 和 A4*17 展开，再对非预乘 RGBA 过滤；过滤 alpha 为 0 时丢弃。全局 alpha 只用 d() 相乘，结果为 0 不额外丢弃片元。
12. 调制与混合按 d()，颜色/深度/模板顺序按规格；P565 截断；后处理使用原缓冲邻居和整数 >>2。对象 a 从 Q12 对齐到 Q8 时舍入，位置取整和奇数半宽高均向下取整。

## 规格缺口/变更（工作假设与用户决定，交 S-1 定稿）

视口：API 参数 (VP_X0,VP_Y0,VP_W,VP_H)，默认 (0,0,640,360)；sx=VP_X0+(X/W+1)*VP_W/2，sy=VP_Y0+(1-Y/W)*VP_H/2；Z/W 的 [0,1] 饱和映射 u16。1280×720 整图/条带均显式使用同一视口。
对象：STEP=1 完成推进/寿命/存活区域判定后，仅存活者碰撞及绘制；STEP=0 按用户新决定只统计/绘制存活对象，不做区域判定/碰撞，不写表/列表，HIT/FREE 和溢出清零。碰撞位置取 floor，与绘制一致；半开框严格重叠，接边不命中。写回整32B时只改ALIVE/PX/PY/VX/VY/LIFE，其余字段和保留位原样保留。
计数：PERF1 为处理的源顶点数，PERF2 为裁剪扇形拆分、剔除/退化判定后留下的三角形数，屏外但未被保护带裁掉的也计；PERF3 为提交绘制的四边形数（含活对象，零覆盖也计）。
PERF4 为通过范围、纹理透明、模板和深度测试的片元数，与颜色/深度/模板写掩码无关；CLEAR/RESOLVE 不计；PERF 与 DONE_COUNT 按寄存器位宽回绕。
纹理变更：RAM 192 KiB（两半各96 KiB）；依 7ed45f8e9 §4.8，块宽高为 I4(2,2)/I8(2,1)/565(1,1)，Bx=ceil(Wk/bw)、By=ceil(Hk/bh)，Lk=8*ceil(Bx/2)*ceil(By/2)，Pk=OFFSET+sum(Lj)。h=Pk/2+4*((by>>1)*ceil(Bx/2)+(bx>>1))+(bx&1)+2*(by&1)；bank=h&3。每级补齐完整2x2块，空槽填0，1x1级8B；越界按sum(Lk)。离线交织工具已接入 Scene.texture，TEX_LOAD仅线性拷贝。

目标/时钟变更：115200 像素，TGT_CFG=0/1 对应640x180/1280x90；640x360分2条、1280x720分8条。开发初值180 MHz，本报告只给功能误差与主机时间，不换算GPU周期。
