# 积木塔定点物理：主机验收与指令计数

- 实现提交：`5c00bb6ec`；基线 `zc100116/b3` / `9a6d89307`；首次实现，无旧版对比。
- 工具：主机 GCC 13.3.0；xPack riscv-none-elf-gcc 15.2.0；Spike 1.1.1-dev。
- 配置：C11、`-Wall -Wextra -Werror -O2`；目标 `-march=rv32im -mabi=ilp32`。
- 设备：纯主机/Spike，无 FPGA 器件、速度等级或仿真虚拟机测量。
- 复现：`make -C sw/tests/showcase phys`、`make -C sw/tests/showcase phys-perf`。
- 原始输出：`build/sw/tests/showcase/phys.log`、`phys-perf.log`（同目录）。

算法：24 槽世界，AABB 两两比较；凸多边形 SAT+边裁剪，圆/多边形最近点检测。
复合体汇总部件接触，保留最深点及最远支撑点，每刚体对最多两点且各保留法线。
顺序冲量固定 8 次；相邻平行法线的双点用 2×2 联立求解，其余逐点求解；缓存冲量 warm start。
选 split impulse（位置系数 0.2，容差 0.05 px），避免位置修正注入反弹能量或玻璃撞击数值。
库仑摩擦取几何平均，弹性取最大值；撞击接口返回本步最大单接触法向冲量，不含位置修正。
各线速度分量 <1 px/s、角速度 <0.01 rad/s 持续 30 步，整个接触岛休眠；碰撞、抓取、平台运动唤醒。
抓取用隐式 5 Hz 临界阻尼弹簧，角度用 7 Hz 弹簧；约束点偏心自然产生转矩。

精度：状态与系数为 Q16.16；乘除、面积/质心/惯量积分中间值为 64 位整数。
1024 项正弦表加线性插值；每刚体每步只计算一次旋转基；固定步长为精确整数除以 60。
像素尺寸下应缩放质量单位，使惯量及其倒数均可表示（测试木密度 64/65536 质量/px²）。
有限 Q16.16 动态范围由调用者满足；引擎无浮点、运行时回退或额外输入保护。

| 主机场景 | 实测结果（全部 PASS） |
|---|---|
| 单块 10 s / 十层塔 10 s | 单块漂移 <0.0001 px，0.5 s 休眠；塔顶最大漂移 1.2452 px |
| 斜木板 / 20° 斜坡 | 木板最终 −0.014°；3 s 木块移动 0.059 px，冰块 582.255 px |
| 100 px 落差反弹 / 撞击上报 | 木 0 px、橡胶 76.578 px；5 cm/50 cm 冲量 53.319/159.957 |
| 抓取 / 90° 旋转 | 1 s 目标误差 0.775 px；0.5 s 角误差 0.012° |
| ±20 px、2 Hz 地震 5 s | 平台摩擦 0.1；1×8 塔顶下落 140.049 px，4×2 顶块漂移 0.047 px |
| 四部件半圆拱 / 圆 | 两根动态柱支撑：漂移 0.0797 px、角 −0.0297°；同平台双脚、圆圆/圆地面亦通过 |
| 确定性 / 休眠唤醒 | 重复 600 步整个世界逐字节相同；抓取、碰撞、平台唤醒与休眠重绘/零撞击通过 |

主机 AddressSanitizer+UndefinedBehaviorSanitizer（`-O1 -fsanitize=undefined,address -fno-sanitize-recover=all`）零诊断。
性能场景：23 个动态 20×20 方块竖直堆叠 +1 个静态平台，共 24 刚体，包含休眠，600 步。
Spike：平均 **237592**、最大 **348711** 条/步；前 60 个活动步骤平均 **347502**、最大 **348594** 条。
平均满足 ≤250k；按 125 MHz、IPC=1 估算 1.901 ms/步，最大 2.790 ms；未计真实缓存/总线等待。
接口：`phys_world_init/clear`、`phys_body_add/remove/get`、`phys_grab_create/move/rotate/release`、`phys_step`、`phys_world_stats`。
`body_get` 提供质心位置、角度、AABB、awake/moved、最大法向冲量；运动学速度由其 velocity/angular_velocity 设置。
