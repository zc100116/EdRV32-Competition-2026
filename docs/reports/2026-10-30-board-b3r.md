## 实现

布线一次布通（207 轮，最后 0 未布通、0 overused），pnr 33 min 14 s，峰值内存 6.6 GB。

| 时钟（slow 角） | 周期 ns | WNS ns | TNS | WHS ns | setup 违例端点 |
|---|---:|---:|---:|---:|---:|
| clk_sys | 10.0 | +0.541 | 0 | +0.144 | 0 |
| clk_mem | 8.0 | +0.072 | 0 | +0.110 | 0 |
| clk_pix | 13.468 | +7.098 | 0 | +0.166 | 0 |
| clk_serial | 2.6936 | +1.706 | 0 | +0.346 | 0 |

卡 10（RTL 05088f4b）B3R 综合估算 clk_mem WNS −18.535 ns、布线第 36 轮仍有 8071 个未布通网络。

| 资源 | 卡 10（05088f4b） | 本次 | 变化 |
|---|---:|---:|---:|
| LUT | 51928 | 51663 | −265 |
| FF | 35062 | 41122 | +6060 |
| APM | 138 | 102 | −36 |
| DRM | 110 | 110 | 0 |

RND 本身（post-route 层次）：LUT 18673、FF 14716、APM 0、DRM 82（18K 口径，含 60 个 36K 列见原表）。

## 上板

| 项 | 结果 |
|---|---|
| RND 自检（16 组 CRC，`expect.py`） | 16/16 PASS |
| RN-17 自比对 | PASS：全覆盖区最大差 0 LSB，>1 LSB 像素 1116 ppm（限 1%） |

benchmark 各场景 CPU 占用 92–99%，帧时间主要在 LVGL 软件渲染一侧（render time 占 94%），RND 不是瓶颈。T-RND1 中接受的 COPY 短行 +12%、无等待 GLYPH +14% 的固定开销在此负载下看不出影响。
