# NPU OPT2：POOL 流水与读仲裁（2026-11-02）
RTL `eee575ed`，基于 Q6 `a1658440` / 规格回填 `db905cfb`；PROF 工具由 `38508885` cherry-pick 为 `c8d16d07`。
环境：Verilator 5.020、Yosys 0.70+219、Python 3.12.3；NPU 150 MHz / mem 125 MHz，目标 PG2L200H-6，未测 PDS 时序/物理资源。
按协调者 2026-11-02 收窄验收，仅两个改动模块 unit smoke、相关 block smoke、一次 zero 整网、改动模块 Yosys；未跑 latency94/BW、全 block/board smoke、资源改前对比。
POOL：地址/RAM→像素选择→16 通道有符号 max，边界样本 −128，结束/左右像素/pair 标签随流水；每行连续 in_w×25 个采样，无像素/pair 间空拍，末尾排空 2 拍；四组本地保留控制。
仲裁：残差沿用最高优先级；下一命令必需行→当前所需模型块→其余输入/模型预取轮转，选择寄存并本地复制；首批必需行请求排队后首块模型优先。RAM 数量、DMA/描述符/镜像不变。
输入不饿死：仅当前消费期限内的有限模型可持续先于预取行；当前必需行优先于模型，双方均属预取时轮转；AXI 背压无规格拍数上界，以下报告实测等待。

复现先 `. ~/.local/opt/edrv32/env.sh`，仿真均加 `flock /tmp/edrv32-sim.lock`，串行 `-j 1`。
单元：`python3 tools/regress.py smoke --path verif/unit/npu_{nonconv,conv} -j 1`（两目录分别执行）。
模块：`python3 tools/regress.py smoke --path verif/block/npu/<case> -j 1`，case=op_02/op_03/op_07/op_09/rg_01/er_05。
整网准备：`git submodule update --init third_party/ultralytics`；`python3 verif/block/npu/run.py --test NET-02 --prepare-only`。
整网编译：展开 `verif/block/npu/prof/files.f` 后，`verilator --binary --timing -Wall -j 1 -DSIM_MODE --top-module tb_npu_prof --Mdir "$PWD/build/npu-opt2/obj" -o sim <展开的源文件>`。
整网运行：`build/npu-opt2/obj/sim +CASE_DIR="$PWD/build/npu/yolo" +TEST_ID=NET-02 +MEM_MODE=zero`；监视器仅观察，不改变 DUT。
Lint：在 `rtl/filelists` 执行 `verilator --lint-only -Wall -DSIM_MODE --top-module edrv32_npu -f npu.f`；风格：`python3 tools/check/verilog_style.py rtl/npu/edrv32_npu_{nonconv,conv}.v`。
Yosys：tech 包装 `read_verilog -lib`、其余展开 npu.f 后 `read_verilog`（均 `-DSIM_MODE -Irtl/include`）；conv 先 `blackbox edrv32_npu_datapath`；两 top 分别 `synth -top edrv32_npu_<模块> -noabc; abc -lut 6 -dress; opt_clean; write_json <模块>.json; stat`；FF 为所有 DFF cell 之和。
原始日志/综合脚本：`build/npu-opt2/`（baseline-zero.log、zero.log、*.ys/json、*-synth.log、lint.log、各目录 smoke .log）；逐用例 `build/regress/smoke/`，单元输出 `build/npu_ctrl/operators/*/run.log`。
