# SLIM1 MEDIA（2026-11-13）

基线：`874d4ccd`（含规格 `1d2c4591`）；实现提交为本报告所属提交。
本机工具：Yosys 0.70+219 / 5053d0e26，Verilator 5.020，GCC 15.2.0。

M2 修改前数据流方案：源 DMA 原始 256-bit beat 直接写行 RAM，完整读行后再写目标；
保留反向行序。令 s/d 为源/目标低 5 位，移位量为 (s-d) mod 32 字节。
若 s>=d，先取 raw[0] 到原有 previous_write，再取 raw[1]，输出
`{raw[k+1],raw[k]} >> (8*(s-d))` 的低 256 位；首拍前增加一次 RAM 预取。
若 s<d，直接输出 `{raw[k],raw[k-1]} >> (8*(32+s-d))` 的低 256 位。
首拍缺失的 raw[-1] 字节由目标首拍 strobe 屏蔽；尾拍无效源字节由尾拍 strobe 屏蔽。
最大 4096 像素 ARGB 行可能有 513 个原始 beat：前 512 个入原有 RAM，
最后一个保存在原有 previous_read 中，读索引 512 时选它，不增加存储寄存器。
同步 RAM 在每次输出握手时预取下一 beat，背压时地址与前拍寄存器保持；
输入与输出活动流均维持 1 beat/拍，不增加流水级，移位网络仅保留一组五级字节选择。
旧捕获尾拍被取消；s>=d 时写前预取 1 拍，整行固定开销相对原实现变化 −1～+1 拍。

M3：每 kernel 的 min/max 两套 5→3→2→1 归约合并，用 OP=5 选择最小，否则选择最大；
保持原 advance 与 4 拍 Y 窗口延迟（early RGB 到输出 8 拍）、每拍 2 像素吞吐。
PERF：PIX 删除 1–3 的事件/计数；GEO 删除 1–5 及 DDR 字节使能人口计数；
DISP 删除 2–6、三个 32-bit Gray CDC、相应采样/借位/基线及 6 个专用复位副本。
PIX/GEO/DISP PERF0、DISP PERF1 及 STATUS.BUSY 的 PERF0 路径保留，删除项通过默认读支路返回 0。
