# R-3r 单元验证与流水线

这三个目录共用 `gpu_perspective/vectors.py` 生成期望值，全部生成物放在 `build/`。
`raster` 调用 `PixelArithmetic.at()`、`edge()`、`top_left()`；`quad` 调用
`GPU.quad()` 与 `GPU.object_quad()`，纹理探针记录坐标；`perspective` 调用
`PixelArithmetic.normal/multiply/subtract/inverse/shade()`，在 log2 前比对 Q16 跨度。

```sh
python3 tools/regress.py full --path verif/unit/gpu_raster -j 1
python3 tools/regress.py smoke --path verif/unit/gpu_quad -j 1
python3 tools/regress.py smoke --path verif/unit/gpu_perspective -j 1
python3 verif/unit/gpu_perspective/logic_depth.py
```

仿真在用户提供的仿真主机执行；本机只做风格检查和 lint。
`raster` 包含较长的整目标遍历，归入 full；另外两个目录支持 smoke/full。
测试包含停顿、finish 排空、stop 丢弃及新命令重启，并保持每组四 lane 的逐位比较。
quad 的 PERF3 每项计数（含空项）；同一命令两路记录源互斥，由外部集成选择 fragment。

## 扫描流水线

| 阶段 | 周期 | 寄存器边界与最长数据进位 |
|---|---:|---|
| render_state | 2 | 目标末端加法、矩形求交分别寄存；18 位 |
| 平面首值符号 | 5 | 70 位符号变换按 20/20/20/10 切片，再回写 |
| 规范起点偏移 | 17×6 | 每位三操作数 CSA 1、切片加法 4、回写 1；不舍入 |
| 四相位行首 | 16 | 顺序求 base、base+4gx、base+8gx、base+12gx，再装入 |
| 组反馈 | 4 | 四相位交错，各相位加 16gx；同相位回写沿转发 |
| lane 展开 | 4 | 并行加 0/gx/2gx/3gx；gx 与输出组同步延迟 |
| 覆盖 | 2 | 边符号/非零先寄存，再与左上偏置、裁剪 mask 合并 |

`edrv32_gpu_raster_add` 的每条进位链只有 20、20、20、10 位，保留完整 70 位结果。
行首预建复用每属性一个切片加法器，20 拍生成下一行四个相位；长行隐藏此开销，
短行在最后一组等待行首完成。只有本行仍需复用的相位回写，因此不会覆盖下一行的种子。
四边形预建占 3 拍；列/行相对位置、翻转、加 UV 原点各占 1 拍，最长加法 19 位。
四边形的 q、h、RGB 为规定常量，u/v 直接进入 s70 合同，没有像素乘法或倒数。

## 透视流水线（累计周期从输入槽出队计）

| 阶段 | 单段/累计 | 实现 |
|---|---|---|
| 三平面符号与 N | 4+10 / 14 | 20 位切片绝对值；前导移位树及舍入 |
| P18 种子 | 3 / 17 | 地址寄存、同步 ROM、输出寄存 |
| 牛顿第一积、舍入、减法 | 3+1+1 / 22 | 18×18 全 36 位积；舍入不丢保护位 |
| 牛顿第二积、舍入、w | 3+1+2 / 28 | r1 只需 17/18 位规范化；无低位 ROM |
| U/V | 3+10 / 41 | 完整积再 N，Q8 不用于偏导 |
| U/V×Gq、N、对齐减法 | 3+10+25 / 79 | 三保护位；20/3 位符号、减法、绝对值切片 |
| 偏导乘 w、N | 3+10 / 92 | 每 lane 四个偏导并行 |
| Q16 跨度、max | 9+2+2 / 105 | 分层移位、舍入；96 位 max 先并行分段比较 |

每个乘法器都有输入、乘积、输出三个寄存边界。N 的 10 拍为：64 位零检测、
64 位选择、32/16/8/4/2/1 六级选择、18 位舍入、舍入进位校正。
对齐减法的 25 拍为：指数选择/差值 2、移位 5、舍入 2、符号 2、减法 2、
绝对值 2、N 10；零操作数恒等式保留独立对齐旁路。
Q8 取值及符号转换在累计 52 拍完成，深度/RGB 在第 2 拍完成，均对齐至 105 拍。
quad 的 Q8 原始位和零跨度走独立数据旁路，同样对齐至 105 拍。
两端各有两槽队列；整体停顿时所有数据、控制和 ROM 使能同步保持，稳态 II=1。

`logic_depth.py` 对实际三顶层做 Yosys 展开、通用门映射及 LUT6 深度统计。
APM 三拍模块和 DRM 包装作为技术边界；通用映射把进位及 CE 选择也算作 LUT。
因此该数字是逻辑参考，不是 Pango LUT/专用进位链级数、资源结论或 200MHz 时序实测。

## 分段预算的核对口径

专用进位链以外，寄存器间局部逻辑按以下不超过 3 级 LUT 组织；这是结构预算，非 PDS 实测。

| 单元 | 每个寄存段的局部组合逻辑 |
|---|---|
| raster add/absolute | 20 位输入选择/异或、进位单元及和位；后续段只接本段操作数和登记的 carry |
| raster prepare | 三输入 CSA 独占一段，随后进入四段加法；禁止把三项写成两串 70 位加法 |
| raster seed/phase | 最多分层输入选择加一个 20 位切片；相位和组控制独立寄存 |
| quad | 矩形加法/比较、相对坐标减法、翻转减法、UV 加法分段；每段最长 19 位 |
| normal | 64 位 OR 独占一段；32/16/8 位 OR 至多 2 级，再接 1 级选择；其余选择更短 |
| multiply/ROM | 输入、运算或阵列、输出分别寄存，不把两次乘积或乘积与 N 串在一段 |
| subtract | 指数比较与差分、五层对齐各自寄存；舍入/符号/减法/绝对值分别按 20+尾段登记 carry |
| scale/sign | 每段一个固定移位选择，末端舍入为 19 位；符号恢复按 20/12 位分段 |
| maximum | 20/20/20/20/16 位比较并行登记；下一段最高不同片选择不超过 2 级，再接数据选择 |
