Run from repository root:

  python3 sw/apps/ember_isles/tools/art/verify_sample.py

Generation is performed with the built-in imagegen tool, one call per recorded prompt.
For edits, use the recorded reference PNG, inspect it, and request identity preservation.
New imagegen runs are nondeterministic; the saved PNG inputs make normalization replayable.
The script does not call an external image service or depend on an API key.

normalize_atlases.py detects source cluster-edge projections near the logical grid,
samples each square center (no interpolation or individual silhouette rescaling),
removes isolated alpha specks, repairs bright exposed outer edges with navy,
and quantizes to a per-sheet RGB565/A4 palette (48/64/192 entries, all <=256).
Hero sheet logical grid 288x144, front/back 288x96, cells48x48.
Enemy grid320x256, cells64x64; terrain448x192, cells64x64.
Props192x128, cells48x64; effects256x128, cells32x32; upgrade640x360.
Source cluster sizes are approximate because imagegen does not emit exact logical PNGs.
Recorded grid-measurements.json reports source dimensions, inferred pitch and output grid.
No high-resolution painted illustration is used as a source for the character animation.

hand-anchors.json records feet, per-frame hands and staff grip; left uses x'=47-x.
The eight-direction fireball preview rotates the AI fireball with nearest-pixel sampling.
The radial 128-square mask uses sixteen A4 transparency steps, encoded as GPU I4.

texture_sample.py trims transparent margins and packs power-of-two pages <=256 square.
GPU swizzle is imported directly from tools/gpu/model/layout.py, no alternate layout.
I8/I4 .bin, .pal and packed PNG previews go only to build/ember_isles/art_sample/.
texture-measurements.json records exact packed sample bytes and explicit level estimates.
Palette banks occupy separate GPU palette RAM; texture limits apply only to texture bytes.
compose_sample.py writes 640x360, exact2x1280x720, 40-frame/10fps APNG and embedded HTML.
The upgraded UI bitmap is a separate review screen, not co-resident with combat textures.
The HTML embeds /tmp/refcmp/ref_35.png for comparison only; reference imagery is not tracked.
No game source, GDD, tech, hardware specification or platform implementation is modified.
