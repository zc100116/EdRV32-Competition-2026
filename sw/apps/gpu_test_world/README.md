# 云脊漫游

原创2048×2048米岛屿探索GPU demo。操纵白青勘测器沿地表悬浮，可跨海，寻找
风页塔、折光庭、云轮风车，收集24枚带加色光晕的光种；收集至少12枚且发现三地标后显示探索完成，
仍可继续自由移动。没有存档、战斗或成长，面向约5～10分钟上板展示。

## 按键

板上bit0/bit1转向，默认前进；bit2短按停驻/继续，长按0.5秒进入控制菜单；bit3回开机菜单。
ETH/PC方向键转向/前后行驶，Z/Enter/VI_A停驻，X/VI_B切LOD着色，Esc/VI_START/VI_ESC返回。
控制菜单左右选择、确认应用：模式、负载、LOD颜色、昼夜时刻、继续、重开。
时刻依次自动/白天/黄昏/夜晚；自动180秒一个周期。右上小地图标玩家与三地标。

## 地图与GPU

固定种子`0x264b42`值噪声+岛屿衰减，32×32个64m区块；17×17高度缓存81块，
每帧最多新生成2块，首次初始化81块。CPU距离与五平面视锥剔除，地形LOD0/1/2
分别4/8/16m网格，距离112/300m切换；8m裙边处理接缝。LOD可视化青/金/紫。
材质按高度/坡度选择草、沙、岩、雪，不宣称单像素多纹理混合。CPU展开无索引顶点、
顶点色融雾，GPU做MVP、透视、纹理mip、深度、光照和混合。重复物件复用网格构造，
没有硬件instancing。水最后绘制、alpha混合、深度写关闭；天空渐变和云层，昼夜改变
天空、雾、顶点亮度与SET_LIGHT方向。没有实时阴影、反射或后处理bloom。

正常视距512m、每块2个候选物件；压测384/576/768m、每块2/4/6候选物件；远块每块1个候选，树冠LOD分别6/4/3面。
正常截图约2万提交三角形、约110可见块，具体数随镜头变化；HUD显示真实提交量。
不自动降档或截断负载。相机后退42m/抬高28m，以读清地形与地标。
CPU/模型耗时不是板端测量，60fps仅为设计目标；模型PERF无周期样本时显示0us。

单独预算沿用185792B公共布局：I8主图集65536B、I8云/水/HUD图集65536B、
草/沙/岩/雪各10944B（有效mip10928B+对齐16B），物件灰度皮肤10944B。
总驻留185792/196608B；进入时一次TEX_LOAD，**每帧纹理流式装入0B**。
区块是程序生成，不从磁盘/网络加载；纹理常驻，不宣称区域纹理流式。
高度缓存46818B+索引4096B，实例即时生成；复用公共顶点缓冲，60000 TRI容量。
原始材质源图及字体来源见assets/SOURCES.md；完整概念提示词见DESIGN.md。

## 复现

```sh
. ~/.local/opt/edrv32/env.sh
make -C sw/apps/gpu_test board linux windows -j1
make -C sw/apps/gpu_test_world state-test -j1
python3 sw/apps/gpu_test_rogue/tools/capture.py world
```

先完成肉鸽capture，再跑world。可用内存至少2GiB，一次只跑一个编译/headless。
`outputs/gpu-test-games-20261126/`含world-day、world-dusk、world-coast、world-landmark、
world-lod、world-stress的png/csv与world-3s.zip（180连续tick）。白天/黄昏是不同
时刻真实渲染，海岸与地标是不同坐标，LOD是实际着色分支。状态测试验证缓存高度、
三个LOD、每帧生成数、拾取、发现提示、昼夜重复。未跑RTL/SoC仿真。

## G-5 画面精修

草/沙/岩/雪使用新的imagegen像素细节材质，并以真实三角面高度梯度做CPU方向明暗；
近中景采样RGB565七级mip，最远LOD直接使用同材质基色融雾，避免纹理调制再次染暗远雾。
第五个10944B槽用于灰度像素物件皮肤，所有185792B仍在进入时一次装入，每帧TEX_LOAD=0B。
相机缩到后42m/上28m；启动及白天镜头同时面对云轮风车、风页塔和遗迹拱门。
山脊高度与背景雪山剪影加强，云片用重叠椭圆衰减的4bit alpha软边；雾与天空共用日夜颜色。
海水为alpha10/15的低饱和青绿色，8m地形小格按海平面交点生成连续浅白浪花带。
树冠用六面分层网格、2～3阶阴影、真实树干和纹理，包含宽冠、长冠、双冠；岩石用18三角形
削顶多面体，保留宽顶部与不规则尺寸。风页塔增高到94m并增加横向风页、交错梁；风车叶片
按tick连续旋转；遗迹由石柱/拱顶/台基构成。光种按同一条弯曲函数排列，持续浮动和加色发光，
拾取碰撞与渲染共用坐标。悬浮勘测车184三角形，白青壳体/深色框架/驾驶舱/双翼/天线/
双橙色推进器，推进器带独立加色光晕。

截图预热到第三帧，使HUD读取上一帧真实CPU和墙钟FPS计数，避免首帧0值；未伪造GPU周期。
G-5对照图：`outputs/gpu-test-games-20261126/compare-world.png`，左设定图、右GPU实机渲染。


相机按后方实际地面抬高并调整俯角，勘测器以地表/海平面较高者为悬浮基准。
树冠封闭底面后每个网格为6N−2个三角形，所有DRAW_TRI批次自然保持32B地址对齐；
曾出现的沿岸三角缺口和载具破面由奇数三角网格导致下一批地址丢失低5位引起，
已用海岸真实渲染和HUD回归中的顶点批次地址检查覆盖，没有改GPU参考模型。
