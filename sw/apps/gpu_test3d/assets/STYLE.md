# Candy Canyon / G-3

共用画风、调色板、尺寸和处理参数见 [公共 STYLE](../../gpu_test_common/assets/STYLE.md)。materials.png 是 2×2 原始材质图，分别为沙地、橙色岩层、紫色矿岩、飞行器/无人机表面。全部缩为 64×64、RGB565、7 级 mip；地形共用沙地材质，岩石使用紫色矿岩。

玩家飞船为项目自建 176 三角形模型（机身 64、双引擎 72、双翼 24、驾驶舱 8、尾翼 8），代码在 canyon.c；无人机为 48 三角形模型。无需导入外部 OBJ。
