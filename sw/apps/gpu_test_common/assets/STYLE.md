# Cartoon Pixel / Low-poly：共用画风与处理规范

G-3 于 2026-11-26 经用户确认（style2-2d / style2-3d 设定图）。后续 2D 肉鸽、3D 开放世界 demo 可复用此处的调色板和处理函数。

- 明亮、饱和的大色块；材质主体 2～3 阶明暗；实体深海军蓝描边；背景压暗。
- 主角白/青，敌人珊瑚/紫/金，亮芯特效，3D 暖橙岩壁、金色沙路、蓝紫天空、青色水晶。
- 共用颜色：[palette.json](palette.json)，72 色；前 64 色为 8 组色阶，最后 8 色补足深色星云。GPU I8 中 0 透明，1～15 HUD 语义色，16～31 发光强度，32～103 共用颜色。
- 工具：[art.py](../tools/art.py)，只用 Python 标准库；提供 PNG 读写、分格、裁切、面积缩小、调色板量化、描边，供其他 demo 直接 import。
- 缩小：面积平均，RGB 按 alpha 加权；实体 alpha >= 128 转不透明，4 邻域孤立杂点去除，外扩 1 像素描边（#101329）。最近颜色按 RGB 欧氏距离量化。效果保留 4-bit alpha、不加实体描边。
- 飞船/敌人 32×32；Boss 128×96；旋转部件 32×32；尾焰 12×24×4；护盾 64×64；掉落物 16×16；弹光 8×8；激光 8×32；爆炸 32×32×8；背景 256×128；行星 96×96；陨石 32×32；云 96×32；面板 32×16，图标 12×12。
- 发光图由生成素材的颜色亮度与 alpha 映射到 16 档；调色板把高强度最后 5 档逐渐混到白色，三种弹幕分别珊瑚、紫、金。护盾只留外圈，中心透明。3D 另用 16×16 的同源图，alpha 乘径向衰减 `(1-r)^1.4`（r 为归一化半径），避免透视放大后出现方块状亮芯。
- 3D 材质 64×64，先量化共用颜色、转 RGB565，再逐级 2×2 平均，至 1×1，共 7 级；所有纹理共 185792 / 196608 B。启动一次装载，不逐帧换纹理。
- 原始 imagegen PNG 入库，处理产物和预览仅写 build/gpu_test/generated/；最终验收截图必须来自真实 headless 渲染。

独立处理一张实体素材：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 sw/apps/gpu_test_common/tools/art.py source.png build/sprite.png --width 32 --height 32
# 发光/透明效果额外加 --effect
```

内置 imagegen 生成，不使用 CLI/API fallback。具体提示词见各应用 assets/STYLE.md。
