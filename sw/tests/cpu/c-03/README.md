# C-03

事件0–31逐个精确计数，保留事件不计数。

档位：`full`。

检查：程序逐项比较 observed_hpm 与B1独立计算 expected_hpm，事件0和17–31必须为0；窗口以HPM3 inhibit实际生效为边界，CSR写优先规则处理边界冲突；B1按7.1独立观察debug/退休/请求响应，5>6>7>8优先级后逐周期累计；每个1–16事件必须有非零覆盖。

B1 激励：每个事件窗口内给一次 I$缺失、D$缺失和设备延迟，制造IB仅一条并按case配对冲突；每个窗口在HPM使能后注入3个分离的 dc_wb_event_i 单拍脉冲；hpm_N_freeze 生效后将参考计数写 expected_hpm[N]，在程序load前完成。

Spike：仅冒烟（`SPIKE_SMOKE`），仅 B1 的检查见上述判据；该运行不能替代 B1 通过结果。

可执行配置约定、符号解析与构建见 [公共说明](../README.md)。

HPM周期类事件依赖实际发射和接口时序，B1观察器独立累计窗口内事件，软件读取参考值并与硬件CSR逐项比较；不能把硬件HPM或debug的同一个计数字段抄成期望值。事件1–16均须出现非零参考值，否则场景覆盖失败。
