# P-01

全类型配对矩阵，覆盖无相关、RAW、WAW及系统指令串行化。

档位：`smoke`（full包含smoke）。

检查：按 cases 解码真实源/目的寄存器，检查 4.2 允许/禁止的配对及 debug[23:21] 原因优先级；所有 4 种失败原因和一次双发射必须被观测；第二条未取到由 IB 单条激励产生。

B1 激励：每个 wfi PC 到达 M 后拉高已使能 MSIP；程序 MIE=0，mie.MSIE=1，由唤醒后 PC 清除；pair_single_next_block 所在取指块延迟20周期，pair_single_entry 位于8字节块后半部，制造IB仅一条。

Spike：仅冒烟（`SPIKE_SMOKE`），仅 B1 的检查见上述判据；该运行不能替代 B1 通过结果。

可执行配置约定、符号解析与构建见 [公共说明](../README.md)。

`cases` 为17种槽0类型 × 17种候选槽1类型 × 3种相关关系。观察器必须按真实操作数解码：无目的/源寄存器的类型不产生RAW/WAW；跳转、MRET、异常会跳过后继，不能要求其后继退休。
