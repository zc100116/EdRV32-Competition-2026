# E-02

异常在候选对第一/第二位置，检查老 ALU 精确提交。

档位：`smoke`（full包含smoke）。

检查：first_fault 的年轻 ALU 不提交；second_fault 前的 older_alu 恰好提交一次；4.2 禁止非法指令进入实际槽 1。

B1 激励：无额外激励，I$/D$ 全命中。。

Spike：运行同一 B1 ELF，产生可供退休序列比对的提交日志；周期与 debug 检查仅 B1。

可执行配置约定、符号解析与构建见 [公共说明](../README.md)。

协调者已确认：规格4.2使实际槽1异常不可达，本项检查第二位置的异常拆对并在槽0执行，实际槽1异常覆盖不适用。
