# R01

Independent ALU pairs: 256 iterations, 32 pairs per iteration. Both accumulators must reach 8192.

Run `python3 tools/cpu/b2_run.py r01` from the repository root after sourcing
`~/.local/opt/edrv32/env.sh`. See `verif/block/cpu_b2/README.md` for windows,
HPM counters, latency, logs and the C-I3 measurement scope.
