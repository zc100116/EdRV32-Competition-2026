# R02

Dependent ALU chain: 256 iterations, 64 additions per iteration. The accumulator must reach 16384.

Run `python3 tools/cpu/b2_run.py r02` from the repository root after sourcing
`~/.local/opt/edrv32/env.sh`. See `verif/block/cpu_b2/README.md` for windows,
HPM counters, latency, logs and the C-I3 measurement scope.
