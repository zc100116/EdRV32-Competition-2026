# Render frame control

运行 `make case-sim CASE=vision/render-frame`。用真实命令执行器、合成 DMA 和 AXI 内存模型验证 APB 提交及非法/忙时写入拒绝、IRQ 清除、无前景旁路、绘制后自动合成、待处理底图替换、三个目标缓冲耗尽后等待退役复用，以及失败绘制后的底图旁路。另验证保留已合成底图后，只绘制 UI 即自动重新合成；新底图替换、关闭保留模式、合成过程中收到新底图时的释放与地址归属。命令列表内的填充或合成写 HDMI 目标槽被拦截；正式合成 stride 越过分配槽时返回错误，不覆盖相邻槽、不发布，并能在错误后执行合法绘制。显示端行为模型模拟完整帧的接收和后续旧 token 退役；此 case 不实例化 HDMI 串行输出。

`CONTROL`（0x08）bit 0 启用前景合成，bit 1 启用底图保留；控制写入在绘制或合成忙时返回 APB 错误。保留只针对完成合成的底图，无前景旁路的底图仍在显示端退役后释放。启用保留后，下一次成功合成将持有其底图；前景绘制成功且无新底图时自动使用它重新合成。新底图成功合成后替换旧保留底图；关闭保留、关闭前景或修改显示尺寸会释放它。`STATUS`（0x0c）bit 11/12/13 分别表示保留模式、当前持有底图和待重新合成。
