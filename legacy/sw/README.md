# EdRV32 软件源码

`sw/` 只放运行在 EdRV32 CPU 上的软件源码，按用途维护：

- `hal/`：寄存器映射、公共硬件接口和驱动；公开头文件在 `include/`，驱动实现在 `drivers/`。
- `lib/`：可被多个程序复用的软件库；每个库独立维护自己的 `include/` 和 `src/`。
- `test/`：验证程序，按 `cpu/`、`soc/`、`peripheral/`、`isa/` 分类。
- `demo/`：完整或可交互的演示程序。
- `script/`：软件镜像转换等通用工具，不放各项目专用构建脚本。

每个 test/demo 作为独立项目，保留其 `src/`、现有 `link/` 和板级专用的
`board/`；这些子目录按项目需要使用，不要求空目录占位。仅在代码确实被多个
项目复用时才提取进 `hal/` 或 `lib/`；
不要用开发阶段编号作为长期目录分类。
