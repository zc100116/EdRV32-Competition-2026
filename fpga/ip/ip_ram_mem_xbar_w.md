# ip_ram_mem_xbar_w

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → DRM（块 RAM）简单双口 RAM（Simple Dual Port） |
| 模块名 | `ip_ram_mem_xbar_w` |
| 包装模块 | `rtl/tech/edrv32_ram_mem_xbar_w.v` |
| 使用者 | mem_xbar；每个写端口的 W 缓冲：256 位数据、32 位 WSTRB；共例化 6 块 |
| 器件 | PG2L200H，速度等级以工程为准 |

## 选项

| 选项 | 取值 |
|---|---|
| 数据位宽 | 写端口和读端口都为 288 |
| 深度 | 16（地址 4 位） |
| 字节写使能 | 不勾选；WSTRB 作为数据保存，不用于本 RAM 的字节写使能 |
| 读时钟使能（读使能） | 勾选；读使能为 0 时输出保持 |
| 输出寄存器 | 不勾选；同步读延迟 1 个周期 |
| 读写同址冲突 | 读出旧数据（Read First / 读优先）；与行为模型一致 |
| 写端口和读端口时钟 | 同一时钟 clk_mem |
| 复位 | 不复位内容或输出；若 IP 带复位端口则在包装中接无效电平 |
| 初始化 | 无初始化文件；上电内容和输出未定义，由控制有效位保护 |

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `wr_clk`、`rd_clk` | in | 1 |
| `wr_en`、`rd_en` | in | 1 |
| `wr_addr`、`rd_addr` | in | 4 |
| `wr_data` | in | 288 |
| `rd_data` | out | 288 |

## 生成后需要回传的信息

PDS 生成的端口名由 IP 决定，不能手动改名。请在 Windows 任务卡的
`result.md` 记录模块名、实际端口列表和选项最终取值截图（放 `artifacts/`）。
实际端口与期望端口不一致时，由协调者修改包装模块 FPGA 分支，不修改生成文件。
