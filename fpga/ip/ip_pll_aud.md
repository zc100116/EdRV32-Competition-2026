## 用户 GUI 生成步骤

1. 在已创建的 GPU 工程打开 IP Compiler，新建 Clock → 28nm PLL，实例名填 `ip_pll_aud`。
2. Basic 页输入频率填 **27.000 MHz**，输入选择 CLKIN1，来源 **No Buffer**。
   不使能第二输入、输入动态切换、APB、SSC、动态相移、门控、互补输出或外部反馈。
3. 输出按下表勾选；其余 CLKOUT 全部不勾选。相位单位是度，占空比单位是百分数。
4. 输出缓冲选择 **No Buffer**（与厂商配置一致）；由 PDS 自动插入全局缓冲，
   内部复位 `RST_INNER_EN=false`，
   不生成 reset 端口；保留 lock，锁定模式保持 0，其余高级选项保持默认。
5. 点击计算分频后生成，保留生成的 IP 源及其本地依赖在 FPGA 工程中；不提交 git。
   实际频率、端口及相位在 Windows result.md 回传；按下文的 1000 ppm 判据验收。

| 输出 | 频率 MHz | 相位 ° | 占空比 % |
|---|---|---|---|
| CLKOUT0 | 12.288 | 0 | 50 |

## 分频和 Windows 回传

输入固定 27.000 MHz；点击“计算分频”，使用 PDS 对 PG2L200H-6 计算的合法
VCO、输入/反馈/输出分频配置，不从其他器件的配置文件抄分频参数。
手头资料没有 Logos2 PLL 用户手册，不能声称已经证明配置可行或误差最优。
在 Windows `result.md` 回传实际频率、VCO、全部分频参数、端口及 GUI 截图。
初始化文件：无；读写延迟：不适用；lock 参与板级异步复位，本域释放由 SoC reset_ctrl 完成。

音频单独使用一个 PLL：12.288 MHz 与现有系统、视频、GPU 频率没有简单的共同
整数输出分频组合；缺少手册时不推断可合并。共新建 GPU、AUD 两个 IP 模块，
替换视觉 NPU PLL 后，相对视觉完整工程净增加一个 PLL 实例（DDR IP 内 PLL 不变）。
MCLK 从同一 clk_aud 输出到 V21；BCLK = clk_aud/4，LRCK = clk_aud/256。
ES8156 配置为从机；这三个时钟同源，误差只按比例改变采样率和音高，
不会产生异步收发丢样；软件仍必须按 FIFO 水位补充样本以避免欠载。

验收：`ppm = (实际 MHz / 12.288 - 1) × 1000000`，要求 `|ppm| ≤ 1000`
（0.1%，48 kHz 时不超过 ±48 Hz，音高约 ±1.73 音分）。
实际值未取得，不能预先报告 ppm；若 PDS 不能满足，在 result.md 报告实际值交协调者处理。
FDC 暂按目标 12.288 MHz（27 × 512/1125）定义，Windows 取得实际值后由协调者同步约束；
不得保留与实际频率不一致的时钟约束进入 G-T1 测量。
