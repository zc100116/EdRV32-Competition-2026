# ip_rom_boot

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → DRM（块 RAM）ROM |
| 模块名 | `ip_rom_boot` |
| 包装模块 | `rtl/tech/edrv32_rom_boot.v` |
| 使用者 | Boot ROM（16 KiB，bootloader 和启动 logo，系统子系统规格 2.2） |
| 器件 | PG2L200H |

## 选项

| 选项 | 取值 |
|---|---|
| 数据位宽 | 64 |
| 深度 | 2048（地址 11 位，共 16 KiB） |
| 时钟使能（读使能） | 勾选。使能为 0 的周期读数据输出保持 |
| 输出寄存器 | 不勾选（读延迟 1） |
| 初始化文件 | 必须加载：`build/sw/boot/rom.hex` 转换得到的 PDS 初始化文件（格式见 `fpga/ip/README.md`"初始化文件"一节） |
| 复位 | 不需要 |

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `clk` | in | 1 |
| `en` | in | 1 |
| `addr` | in | 11 |
| `rd_data` | out | 64 |

bootloader 修改后需要重新生成初始化文件并更新 IP（或使用 PDS 的存储初始化内容更新流程），不需要改 RTL。

## 生成后需要回传的信息

PDS 生成的端口名由 IP 决定，不能手动改名。生成后请在 Windows 任务卡的 `result.md` 中记录：
1. 生成的模块名（必须为上面的模块名，在 IP Compiler 中填写实例名/模块名时设置）；
2. 生成文件中模块的实际端口列表（名称、方向、位宽）；
3. 各选项的最终取值截图（PNG，放 `artifacts/`）。

实际端口名与"期望端口"不一致时，由协调者统一修改包装模块的 FPGA 分支，不要改生成的文件。
