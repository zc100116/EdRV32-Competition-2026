# ip_ram_sram

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → DRM（块 RAM）单口 RAM（Single Port） |
| 模块名 | `ip_ram_sram` |
| 包装模块 | `rtl/tech/edrv32_ram_sram.v` |
| 使用者 | 片上 SRAM（256 KiB，系统子系统规格 2.2） |
| 器件 | PG2L200H |

## 选项

| 选项 | 取值 |
|---|---|
| 数据位宽 | 64 |
| 深度 | 32768（地址 15 位，共 256 KiB） |
| 字节写使能 | 勾选，8 位 |
| 时钟使能（端口使能） | 勾选。使能为 0 的周期不读不写，读数据输出保持 |
| 输出寄存器 | 不勾选（读延迟 1） |
| 写时读出 | 写周期的读数据不使用，取任意模式 |
| 初始化文件 | 勾选，使用 `build/sw/<应用程序>/sram.hex` 转换得到的 PDS 初始化文件（格式见 `fpga/ip/README.md`"初始化文件"一节）；不需要上电内容时可以不加载 |
| 复位 | 不需要 |

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `clk` | in | 1 |
| `en` | in | 1 |
| `wr_en` | in | 8（每字节一位写使能；PDS 若为 1 位写使能 + 8 位字节使能两个端口，请记录实际端口） |
| `addr` | in | 15 |
| `wr_data` | in | 64 |
| `rd_data` | out | 64 |

## 生成后需要回传的信息

PDS 生成的端口名由 IP 决定，不能手动改名。生成后请在 Windows 任务卡的 `result.md` 中记录：
1. 生成的模块名（必须为上面的模块名，在 IP Compiler 中填写实例名/模块名时设置）；
2. 生成文件中模块的实际端口列表（名称、方向、位宽）；
3. 各选项的最终取值截图（PNG，放 `artifacts/`）。

实际端口名与"期望端口"不一致时，由协调者统一修改包装模块的 FPGA 分支，不要改生成的文件。
