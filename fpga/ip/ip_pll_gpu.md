| 项 | 内容 |
|---|---|
| IP | IP Compiler → Clock → 28nm PLL（Logos2，v1.5；B1 已生成的同族 PLL） |
| 器件 | PG2L200H-6，FBB676；PDS 2022.2-SP6.4 或兼容现有 B1 的版本 |

| 初始化文件 / 读写延迟 | 无 / 无，连续时钟输出；lock 为锁定状态 |

## 用户 GUI 生成步骤

1. 在已创建的 GPU 工程打开 IP Compiler，新建 Clock → 28nm PLL，实例名填 `ip_pll_gpu`。
2. Basic 页输入频率填 **27.000 MHz**，输入选择 CLKIN1，来源 **No Buffer**。
   不使能第二输入、输入动态切换、APB、SSC、动态相移、门控、互补输出或外部反馈。
3. 输出按下表勾选；其余 CLKOUT 全部不勾选。相位单位是度，占空比单位是百分数。
4. 输出缓冲选择 **No Buffer**（与厂商配置一致）；由 PDS 自动插入全局缓冲，
   内部复位 `RST_INNER_EN=false`，
   不生成 reset 端口；保留 lock，锁定模式保持 0，其余高级选项保持默认。
5. 点击计算分频后生成，保留生成的 IP 源及其本地依赖在 FPGA 工程中；不提交 git。
   实际频率、端口及相位在 Windows result.md 回传，实际不符就明确报错并交协调者处理。

| 输出 | 频率 MHz | 相位 ° | 占空比 % |
|---|---|---|---|
| CLKOUT0 | 180.000 | 0 | 50 |

## 分频和 Windows 回传

输入固定 27.000 MHz；点击“计算分频”，使用 PDS 对 PG2L200H-6 计算的合法
VCO、输入/反馈/输出分频配置，不从其他器件的配置文件抄分频参数。
手头资料没有 Logos2 PLL 用户手册，不能声称已经证明配置可行或误差最优。
在 Windows `result.md` 回传实际频率、VCO、全部分频参数、端口及 GUI 截图。
初始化文件：无；读写延迟：不适用；lock 参与板级异步复位，本域释放由 SoC reset_ctrl 完成。

目标必须为 180.000 MHz（G-T1 开发初值）；实际分频由 PDS 计算。
保留独立 GPU PLL，沿用视觉项目 180 MHz 域的划分，不修改系统/视频 PLL 的 IP 契约。
180/125 = 36/25、180/74.25 = 80/33，不能直接复用现有固定 VCO 的整数输出分频。
GPU 的最终频率仍需 G-T1 全 SoC 布局布线后定稿，不降低约束目标掩盖拥塞。
