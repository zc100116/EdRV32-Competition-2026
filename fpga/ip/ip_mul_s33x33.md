# ip_mul_s33x33

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Arithmetic → APM 乘法器（Multiplier） |
| 模块名 | `ip_mul_s33x33` |
| 包装模块 | `rtl/tech/edrv32_mul_s33x33.v` |
| 使用者 | CPU 乘法器（cpu-spec 4.8：MUL/MULH/MULHSU/MULHU 共用 33×33 有符号乘法） |
| 器件 | PG2L200H |

## 选项

| 选项 | 取值 |
|---|---|
| A 输入 | 33 位，有符号 |
| B 输入 | 33 位，有符号 |
| 输出 P | 66 位（全精度） |
| 流水级数 | 2 级：输入寄存器 + 输出寄存器（从输入有效的时钟沿起，第 2 个时钟沿后输出有效） |
| 时钟使能 | 勾选，所有流水寄存器共用一个时钟使能 |
| 复位 | 不需要 |

APM 单个乘法单元的位宽不足 33×33 时，由 IP 自动级联多个 APM；在 `result.md` 中记录实际占用的 APM 数量。

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `clk` | in | 1 |
| `ce` | in | 1 |
| `a` | in | 33 |
| `b` | in | 33 |
| `p` | out | 66 |

## 生成后需要回传的信息

PDS 生成的端口名由 IP 决定，不能手动改名。生成后请在 Windows 任务卡的 `result.md` 中记录：
1. 生成的模块名（必须为上面的模块名，在 IP Compiler 中填写实例名/模块名时设置）；
2. 生成文件中模块的实际端口列表（名称、方向、位宽）；
3. 各选项的最终取值截图（PNG，放 `artifacts/`）。

实际端口名与"期望端口"不一致时，由协调者统一修改包装模块的 FPGA 分支，不要改生成的文件。
