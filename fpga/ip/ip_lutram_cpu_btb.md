# ip_lutram_cpu_btb

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → 分布式 RAM（Distributed RAM）→ 简单双口 RAM（Simple Dual Port） |
| 模块名 | `ip_lutram_cpu_btb` |
| 包装模块 | `rtl/tech/edrv32_ram_cpu_btb.v` |
| 使用者 | `edrv32_cpu_predictor` BTB ×1 |
| 依据 | cpu-spec v0.15 4.4（BTB 128 项）；CLAUDE.md 8 |
| 器件 | PG2L200H，速度等级以工程为准 |
| 状态 | 待生成（CPU v0.15 进入 PDS 工程时） |

## 选项

与 `ip_lutram_npu_quant`（卡 21 已生成）相同的模式，只改宽度和深度。

| 选项 | 取值 |
|---|---|
| 实现资源 | 分布式 RAM，不选 DRM |
| 端口模式 | 简单双口：独立写地址、读地址，同宽读写 |
| 数据位宽 | 写端口和读端口都为 58 |
| 深度 | 128（地址 7 位） |
| 写入方式 | 同步写；单一时钟 clk_sys，上升沿，写使能有效时写整项 |
| 字节写使能 | 不勾选 |
| 读出方式 | 组合读；不注册读地址，不选读时钟使能 |
| 输出寄存器 | 不勾选；读延迟 0 拍（F1 当拍查询） |
| 复位 | 不复位内容或输出；生成的 `rst` 端口由包装接 1'b0 |
| 初始化 | 无初始化文件。有效位在 IP 之外，由复位清 0（cpu-spec 4.4），所以内容上电值无关 |

## 数据格式

`{tag[21:0] = PC[31:10], target[31:0], position = PC[2], type[2:0]}`，共 58 位（高位在前）。

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `wr_clk`、`rd_clk` | in | 1（包装都接 clk_sys） |
| `rst` | in | 1（包装接 1'b0） |
| `wr_en` | in | 1 |
| `wr_addr`、`rd_addr` | in | 7 |
| `wr_data` | in | 58 |
| `rd_data` | out | 58（组合输出） |

## 时序

同址写读：写沿之前读出旧值，写沿之后读出新值；包装的行为模型与此一致。
