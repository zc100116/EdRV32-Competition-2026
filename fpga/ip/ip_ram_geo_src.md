# ip_ram_geo_src

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → DRM（块 RAM）简单双口 RAM（Simple Dual Port），读写端口位宽不同 |
| 模块名 | `ip_ram_geo_src` |
| 包装模块 | `rtl/tech/edrv32_ram_geo_src.v` |
| 用途 | GEO 源缓冲的一个 bank：写口每次写 8 个 RGB565 像素，读口每次读 1 个像素 |
| 使用者 | GEO 源缓冲，2 组 × 4 bank（行、列奇偶），共 8 实例 |
| 依据 | GEO 规格 5.2、7、9 第 1、2 项 |
| 器件 | PG2L200H，速度等级以工程为准 |

## 选项

| 选项 | 取值 |
|---|---|
| 写端口 | 位宽 128，深度 256（地址 8 位） |
| 读端口 | 位宽 16，深度 2048（地址 11 位） |
| 地址对应 | 读地址 `r` 对应写地址 `r[10:3]` 那一项的第 `r[2:0]` 个 16 位，即写数据位 `[16·r[2:0] + 15 : 16·r[2:0]]`（低位在低地址）。生成后请在 IP 文档或仿真模型中确认这个顺序，与此不同时写进 `result.md` |
| 字节写使能 | 不勾选 |
| 读时钟使能（读使能） | 勾选；读使能为 0 时输出保持 |
| 输出寄存器 | 不勾选；同步读延迟 1 个周期 |
| 读写同址冲突 | 同拍同址读写的读出值不确定。GEO 不依赖该读出值 |
| 写端口和读端口时钟 | 同一时钟 clk_mem |
| 复位 | 不复位内容或输出；IP 带复位端口时在包装中接无效电平 |
| 初始化 | 无初始化文件 |

PDS 不支持这组读写位宽时，停下并在 `result.md` 中记录 PDS 支持的位宽组合，不要改用其他配置。

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `wr_clk`、`rd_clk` | in | 1 |
| `wr_en`、`rd_clk_en`（读使能） | in | 1 |
| `wr_rst`、`rd_rst` | in | 1（包装接 `1'b0`） |
| `wr_addr` | in | 8 |
| `rd_addr` | in | 11 |
| `wr_data` | in | 128 |
| `rd_data` | out | 16 |

## 生成后需要回传的信息

PDS 生成的端口名由 IP 决定，不能手动改名。请在 Windows 任务卡的 `result.md` 记录模块名、实际端口列表、读写地址对应顺序、实际占用的 DRM 块数和选项最终取值截图（放 `artifacts/`）。实际端口与期望端口不一致时，由协调者修改包装模块 FPGA 分支，不修改生成文件。
