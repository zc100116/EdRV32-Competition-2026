# ip_lutram_cpu_direction

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → 分布式 RAM（Distributed RAM）→ 简单双口 RAM（Simple Dual Port），带初始化文件 |
| 模块名 | `ip_lutram_cpu_direction` |
| 包装模块 | `rtl/tech/edrv32_ram_cpu_direction.v`（例化 4 份：查询读、更新读各一份，每份按地址第 10 位分成 2 个 bank；写端口相同） |
| 使用者 | `edrv32_cpu_predictor` gshare 方向表 |
| 依据 | cpu-spec v0.15 4.4（4096 个 2 位计数器，上电 01，复位不清除）；CLAUDE.md 8 |
| 器件 | PG2L200H，速度等级以工程为准 |
| 状态 | 待生成（CPU v0.15 进入 PDS 工程时） |

## 选项

| 选项 | 取值 |
|---|---|
| 实现资源 | 分布式 RAM，不选 DRM |
| 端口模式 | 简单双口：独立写地址、读地址，同宽读写 |
| 数据位宽 | 写端口和读端口都为 4（每字两个计数器：低 2 位为索引最低位 0，高 2 位为索引最低位 1） |
| 深度 | **1024**（地址 10 位）。PDS 2022.2-SP6.1 的 Distributed Simple Dual Port RAM v1.3 只支持 ADDR_WIDTH 4–10，不能直接生成 2048 深。逻辑上的 2048 字（gshare 索引 [11:1]）由包装按地址第 10 位分成两个 1024 字 bank：写使能只给对应 bank，读出按地址第 10 位二选一（2026-11-05 修订，卡 56 回报） |
| 写入方式 | 同步写；单一时钟 clk_sys，上升沿，写使能有效时写整字 |
| 字节写使能 | 不勾选 |
| 读出方式 | 组合读；不注册读地址，不选读时钟使能 |
| 输出寄存器 | 不勾选；读延迟 0 拍 |
| 复位 | 不复位内容或输出；生成的 `rst` 端口由包装接 1'b0 |
| 初始化文件 | 使能，HEX 格式，选择 `ip_lutram_cpu_direction.dat`：**1024 行**，每行 1 个 HEX 字符 `5`（两个计数器都为 01）。两个 bank 用同一个 IP、同一个初始化文件 |

初始化文件生成（Windows 或 Linux 均可）：

```sh
python -c "open('ip_lutram_cpu_direction.dat','w').write('5\n' * 1024)"
```

如果 PDS 的分布式 RAM 不提供初始化文件选项，停止生成并回报，不要改用复位清零或其他初值。上电值是规格要求，需要协调者另定方案。

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `wr_clk`、`rd_clk` | in | 1（包装都接 clk_sys） |
| `rst` | in | 1（包装接 1'b0） |
| `wr_en` | in | 1 |
| `wr_addr`、`rd_addr` | in | 10 |
| `wr_data` | in | 4 |
| `rd_data` | out | 4（组合输出） |

## 时序

同址写读：写沿之前读出旧值，写沿之后读出新值。更新时，包装用读地址等于写地址的那一份读出整字，替换其中一个计数器后写回；查询和更新两份的写端口完全相同，所以内容始终一致；同一份的两个 bank 地址互不重叠。

## 生成后需要回传的信息

实际模块名、端口、资源（LUTRAM 数，4 份合计）、初始化选项截图。端口名不一致时只改包装模块 FPGA 分支的连接，并回报。
