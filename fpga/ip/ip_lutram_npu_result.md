## 选项

| 选项 | 取值 |
|---|---|
| 实现资源 | 分布式 RAM，不选 DRM |
| 端口模式 | 简单双口：独立写地址、读地址，同宽读写 |
| 数据位宽 | 写端口和读端口都为 512 |
| 深度 | 32（地址 5 位） |
| 写入方式 | 同步写；单一时钟 clk_npu，上升沿，写使能有效时写整项 |
| 字节写使能 | 不勾选 |
| 读出方式 | 组合读；不注册读地址，不选读时钟使能 |
| 输出寄存器 | 不勾选；IP 内部读延迟 0 拍，读寄存器由包装模块实现 |
| 复位 | 不复位内容或输出；若实际生成额外复位端口，包装模块接无效电平 |
| 初始化 | 无初始化，不选择初始化文件；上电内容及包装寄存器未定义 |

## 包装模块时序

包装模块实现 2 拍读寄存器：第一级受 `rd_en_i` 控制，第二级一直使能；禁读后输出在晚一拍跟随第一级后保持。
同址读写时，包装模块在写入沿采样组合读的旧值，存储在该沿后更新，因此读出旧值。
不在 IP 内增加读寄存器，否则会改变包装模块对上层的读延迟。

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `wr_clk` | in | 1（clk_npu；唯一时钟） |

| `wr_addr`、`rd_addr` | in | 5 |
| `wr_data` | in | 512 |
| `rd_data` | out | 512（组合输出） |
