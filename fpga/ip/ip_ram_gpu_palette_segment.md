# ip_ram_gpu_palette_segment

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → True Dual Port DRM |
| 模块名 | `ip_ram_gpu_palette_segment` |
| 包装模块 | `rtl/tech/edrv32_ram_gpu_palette_segment.v` |
| 用途 | 完整调色板 2 副本各 4 段；每段 1024×36 原生配置使用 20 位，共 8 个实例 |
| 依据 | gpu-spec 2.6；2026-11-24-gpu-microarch 4.8 |
| 器件 | PG2L200H，速度等级以工程为准 |

## 固定配置

| 选项 | 取值 |
|---|---|
| 深度 / 位宽 | 1024 × 20；地址 10 位，两端等宽 |
| 时钟 | 单一 clk_gpu，上升沿 |
| 复位 | 不复位内容或输出；IP 复位接 `1'b0` |
| 初始化 | 无，不选择初始化文件 |
| 端口模式 | True Dual Port；A/B 独立地址，两端接同一 clk_gpu |
| 输出寄存器 | 打开；阵列同步读 1 拍 + 输出寄存 1 拍，共 2 拍 |
| 时钟使能 | 两端均打开，控制阵列读取；输出寄存器每拍更新 |
| 写模式 | A 端装入；B 端只读，wr_en_b 固定 0 |
| 读写同址冲突 | 不依赖：装入/取样由 command 串行互斥 |
| 字节写使能 | 关闭，整项写 |

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `clk_a`、`clk_b`、`rst_a`、`rst_b` | in | 1 |
| `clk_en_a`、`clk_en_b`、`wr_en_a`、`wr_en_b` | in | 1 |
| `addr_a`、`addr_b` | in | 10 |
| `wr_data_a`、`wr_data_b` | in | 20 |
| `rd_data_a`、`rd_data_b` | out | 20 |

行为模型内容和数据寄存器不初始化、不复位。读使能控制阵列寄存器，输出寄存器
每拍更新；同址读写模型返回旧值，业务不依赖该值。
