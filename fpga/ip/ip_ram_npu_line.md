# ip_ram_npu_line

| 项 | 内容 |
|---|---|
| IP 类型 | IP Compiler → Memory → DRM（块 RAM）简单双口 RAM（Simple Dual Port） |
| 模块名 | `ip_ram_npu_line` |
| 包装模块 | `rtl/tech/edrv32_ram_npu_line.v` |
| 用途 | 行缓存一个 bank：每项两个像素 × C16 |
| 使用者 | edrv32_npu_line_cache（2 实例，每 bank 一个） |
| 依据 | NPU 规格 5.2；设计记录 `docs/design/2026-10-27-npu-datapath.md` 4.5、4.9 |
| 器件 | PG2L200H，速度等级以工程为准 |

## 选项

| 选项 | 取值 |
|---|---|
| 数据位宽 | 写端口和读端口都为 256 |
| 深度 | 1024（地址 10 位） |
| 字节写使能 | 不勾选（每次写完整的一项） |
| 读时钟使能（读使能） | 勾选；读使能为 0 时输出保持 |
| 输出寄存器 | 勾选；同步读延迟 2 个周期（阵列读 1 拍 + 输出寄存器 1 拍）。若生成了输出寄存器的时钟使能端口（如 `rd_oce`），在包装中接 1 |
| 读写同址冲突 | IP 无冲突模式选项；同拍同址读写的读出值不确定（20261027-02 ModelSim 实测有旧值、新值和两者都不是三种情况）。NPU 数据通路不发生同址读写（`verif/unit/npu_datapath` 12 个用例实测 0 次），不依赖该读出值 |
| 写端口和读端口时钟 | 同一时钟 clk_npu |
| 复位 | 不复位内容或输出；IP 带复位端口时在包装中接无效电平 |
| 初始化 | 无初始化文件 |

## 期望端口

| 端口 | 方向 | 位宽 |
|---|---|---|
| `wr_clk`、`rd_clk` | in | 1 |
| `wr_en`、`rd_clk_en`（读使能，PDS 实际端口名） | in | 1 |
| `wr_rst`、`rd_rst` | in | 1（包装接 `1'b0`） |
| `wr_addr`、`rd_addr` | in | 10 |
| `wr_data` | in | 256 |
| `rd_data` | out | 256 |

## 生成后需要回传的信息

PDS 生成的端口名由 IP 决定，不能手动改名。请在 Windows 任务卡的 `result.md` 记录模块名、实际端口列表、实际占用的 DRM 块数和选项最终取值截图（放 `artifacts/`）。实际端口与期望端口不一致时，由协调者修改包装模块 FPGA 分支，不修改生成文件。
